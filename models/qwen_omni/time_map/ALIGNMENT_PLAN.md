# Independent word-alignment plan

The current `row_map.json` is an exact map of **model tensor rows to mel chunks and placeholder positions**. It is not a word aligner. The tested Qwen model's cross-attention, hidden states, or generated text must not define the word intervals used to validate those same states.

1. Use only the frozen fit WAVs and their original `audio_input.script` values. The [CPU ASR audit](../../../eval/tts/ASR_AUDIT.md) found no severe omissions but flagged `association:code-h` for human listening. Resolve that clip's spoken words manually before relying on forced alignment; do not rewrite its frozen source script or regenerate it silently.
2. Fit an **external** forced aligner to the known script. [Montreal Forced Aligner's `mfa align_hf`/`align_one_hf`](https://montreal-forced-aligner.readthedocs.io/en/latest/user_guide/workflows/alignment.html) can produce independent word/phone intervals from its acoustic model and dictionaries. Before running it, pin the MFA software version, `english_mfa` model revision, dictionary/G2P files, and exact input WAV/text hashes. Archive TextGrid or JSON outputs and the aligner's OOV/quality report. The MFA docs note that the `align`/`align_hf` command interface changes around version 4; use a pinned command, not an unversioned example.
3. Convert aligned `[start,end)` seconds to 16 kHz sample indices and then to nominal mel-frame bins using the recorded 160-sample hop. Keep both source seconds and rounded frame indices, plus a confidence or manual-check flag. Use the `row_map.json` chunk intervals to find which encoder rows' **attention scopes** overlap a word. Do not call an encoder row a word detector merely because its nominal conv center falls inside that interval.
4. Validate the external alignment independently: inspect word boundaries for at least one short and one long item from **each** TTS engine, plus every flagged/OOV item. Report word-onset/end errors or explicit uncertainty against human annotation; if alignment is weak, exclude timing claims while keeping the observational tensors. Reserve development/test clips untouched until a later locked evaluation gate.
5. When a lexical readout is eventually scored, predeclare words, time windows, and negative windows using only the external aligner and frozen fit labels. Use held-out audio to evaluate selectivity. A high token score or a pretty UI is only a hypothesis; matched activation interventions and complete-output checks are required for causal claims.

Kokoro's pinned ONNX file reports no duration output (`has_timings=False`), so engine-internal timing is unavailable for the current render. Piper can expose duration alignments only with a model patch, which was not used in the frozen render. The external MFA path avoids depending on either TTS engine's altered model and on Qwen's own attention.
