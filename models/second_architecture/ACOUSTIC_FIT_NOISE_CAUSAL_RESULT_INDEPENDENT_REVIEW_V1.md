## What this experiment establishes

The selected synthetic Kokoro/teal clip was already known to change from clean `TIL` to word-slot-noise `TEAL` in the prior FIT run; it was selected **after that observation**. At the Wav2Vec2 feature-projection output, swapping only the nominal word rows `[105,179)` from the other recording changed the **complete CTC transcript** to the donor transcript in both directions. Clean recipient became `TEAL`; word-noise recipient became `TIL`. The original clean `TIL` is wrong relative to the intended spoken `teal`; the noisy `TEAL` is a correction of that error. This is sufficiency of the *actual donor word-row state* for this selected transcript switch at this one intervention site.

Both zero-edit `self_W` runs reproduced recipient logits bit for bit. Both `full_donor` runs reproduced donor logits and complete frame-ID paths bit for bit. Neither `C_donor` arm nor any of the four word-region and four complement-region random controls switched the complete transcript. The clean→noise `W_donor` frame path differs from the clean recipient at 7 of 286 IDs and from the noisy donor at 1 ID (frame 140: patched ID 4, donor ID 0). The noise→clean `W_donor` path differs from the noisy recipient at 8 IDs and exactly equals the clean donor path. The causal claim concerns the complete decoded transcript, not universal frame-level equivalence. Some control frame paths changed while decoded words did not.

## Limits and next inference

The intervention replaced internal FP32 activations in a white-box ASR model. It is not an attacker-suppliable waveform, an unmodified assistant decision, a tool call, or a security finding. The word window is a nominal receptive-field alignment, not a proven phonetic boundary. This single post hoc selected synthetic FIT pair does not estimate a rate, generalize to other speakers, words, models, or languages, or show that the same mechanism explains audio assistant behavior. A fresh sealed corpus with human-checked wording and an unmodified consequential endpoint is needed before making a broader or security claim.
