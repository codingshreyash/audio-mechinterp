**Executable-freeze blocker: circular SHA binding.** The source is intended to embed the exact external admission hash in `FROZEN_ADMISSION_SHA256`, while `verify_admission()` requires the admission to contain `pilot_worker_sha256=SHA256` of the *whole same source file*. Editing the source to insert the admission hash changes the worker hash; editing the admission to bind that new worker hash changes the admission hash. The two files cannot be straightforwardly finalized as exact mutually bound byte hashes. Break this cycle prospectively, for example by an independently frozen launcher that pins both finalized hashes, before any executable pilot admission.
