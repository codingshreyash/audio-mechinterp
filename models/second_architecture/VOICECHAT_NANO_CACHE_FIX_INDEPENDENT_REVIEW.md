## Decision on the two reported blockers

**Both are closed for remote staging and the one-shot `ready` preflight.** The Nano repository cache root must now contain exactly `refs`, `snapshots`, and `blobs`. Synthetic extra root weight file and directory cases fail. Immediately before the [Transformers 4.56.0 dynamic-code import](https://github.com/huggingface/transformers/blob/v4.56.0/src/transformers/dynamic_module_utils.py#L281-L455), `ready` requires `HF_HOME/modules` to be absent or empty, which prevents reuse of a preseeded commit-named module. After the offline resolver, it requires the two copied custom `.py` files to match the pinned hub-source SHA-256 values, empty package initializers, and no extra module files or directories outside its allowlist. The ready path then rechecks the six-file Nano hub cache. The local `--self-test` returned `self_test_passed_no_model_or_network`; it includes negative cases for a preseeded module, changed copied source, extra executable `.py`, and root extras.

## Remaining blocker before model load or fixture inference

The post-import allowlist permits any `.pyc` under an allowed `__pycache__` directory without validating its bytes. In an independent synthetic cache, adding `__pycache__/modeling_nemotron_h.cpython-312.pyc` with arbitrary unverified bytes still produced `nano_dynamic_module_files_verified=2`. The clean-before-import gate means this does **not** demonstrate an initial preseeded-code execution path. It means the post-import receipt does not bind all executable bytes for a **later** load using the preserved cache. The [pinned loader](https://github.com/huggingface/transformers/blob/v4.56.0/src/transformers/dynamic_module_utils.py#L229-L278) hashes the `.py` text before `SourceFileLoader.exec_module`, which can use a valid cached bytecode file. This is a **model-load blocker** while the validated cache is reused. Run the resolver/model process with `PYTHONDONTWRITEBYTECODE=1`, reject or purge every `__pycache__`/`.pyc` before reuse, and rehash the two source `.py` files immediately before fixture inference. `PYTHONDONTWRITEBYTECODE=1` alone does not prevent reading an existing bytecode cache. Retain exclusive control of the dedicated cache between checks and use.

The full VoiceChat load and no-hook/passive-hook identity pilot remain separate gates. This review does not claim either has passed or that a fixture produced a security finding.
