## Original blocker: control norms were self-referential

`verify_row` checks each pre/post/padding/random control's `effective_bf16_norm` against that **same row's** `target_bf16_norm`. It does not compare this target with the corresponding whole-word patch's effective norm for the same `(record, recipient, site, arm)`, nor require the four control targets to agree with each other. A changed control edit and refreshed self-consistent scalar fields could therefore satisfy the auditor despite violating the frozen equal-whole-word-norm rule. Before freezing the auditor, require for each direction/site/arm that the whole-word row is a valid generation with `alpha == 1`, finite positive `target_bf16_norm`, and `effective_bf16_norm` equal to that target within a BF16-appropriate numerical tolerance; then require every pre/post/padding/random control's target to match this whole-word norm and retain the existing 5% effective-norm check. Check all 96 directions and both sites/arms, including cases that ultimately fail an effect gate. Add a synthetic regression in which one control's target, alpha and effective norm are all altered consistently while its whole-word row is unchanged; the auditor must reject it.
