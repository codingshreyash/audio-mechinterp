# Wav2Vec2 FIT outside-word causal assay — prospective plan v1

19 November 2026. **Design only. No model inference under this plan has run.** The [reviewed word-window assay](WAV2VEC2_FIT_CAUSAL_RESULT_INDEPENDENT_REVIEW_V1.md) showed complete donor-transcript transfer for a donor word-window patch at feature projection and post-block 11. The [reviewed baseline](WAV2VEC2_FIT_BASELINE_V2_RESULT_INDEPENDENT_REVIEW_V1.md) and [GroupNorm reconstruction](WAV2VEC2_FIT_GROUPNORM_RECONSTRUCTION_INDEPENDENT_REVIEW_V1.md) showed that donor-minus-recipient differences outside that window arise before transformer attention under stock normalization and, with shared input normalization, at the first convolution's time-wide GroupNorm. This follow-up asks whether **those outside-word hidden rows are sufficient** to transfer the paired recording's complete transcript in a patched run. The question was chosen after seeing the FIT results; this is posthoc exploratory work on known words, with a prospectively fixed intervention matrix. It is not a held-out or security test.

## Active rows and complete 192-forward matrix

For each pair/voice, take the previously frozen nominal direct-acoustic-overlap word rows **W**: `color_05` Piper `[95,156)`, Kokoro `[105,179)`; `object_02` Piper `[95,134)`, Kokoro `[105,170)`. The source sample slot `[s,e)` and seven-convolution receptive field/stride define W as `[ceil((s−399)/320), floor((e−1)/320)+1)`. Use the baseline's unpadded captured frame length `T` for both sites: Piper color `271`, Kokoro color `286`, Piper object `249`, Kokoro object `278`. The active-audio complement **C** is exactly `[0,W_start) ∪ [W_end,T)`. These unpadded CTC inputs have **no padded rows**; C includes all other audio frames, including quiet regions and other spoken words. Reject a direction if the paired time lengths or W disagree. Report `||donor−recipient||` separately in W and C; require nonzero, finite C norm before the run, but do not select directions by its size or outcome.

For each of the 16 directed mode cells and two sites, run exactly six arms in the frozen order **W, C, self-C, full-donor, R1-C, R2-C**:

1. **W:** replace recipient W rows with donor W rows; replay the prior result as a positive reproducibility control.
2. **C:** replace *all* recipient C rows with donor C rows while leaving W bitwise unchanged.
3. **self-C:** replace C with its own recipient values; the complete logits and frame IDs must equal the clean recipient baseline exactly.
4. **full-donor:** replace all `[0,T)` rows with donor state; complete logits and frame IDs must equal the clean donor baseline exactly.
5. **R1-C/R2-C:** add two independent Gaussian edits only in C, each with whole-C Frobenius norm matched to that direction/site's natural donor-minus-recipient C tensor. Set `seed = 18470111 + 4*d + 2*s + r`, where directed mode index `d=0..15`, site index `s=0,1`, and random index `r=0,1`; use NumPy `Generator(PCG64(seed)).standard_normal(C_shape)` in float64, scale to the natural C norm, cast to float32 and add to the cloned recipient C. Require 64 distinct seeds and nonzero finite source and realized norms. Record both norms and the exact edit/state hashes.

The matrix is **16 × 2 × 6 = 192 patched forwards**, with 1 preflight and 1 completion row when successful. Keep all 16 directions and all 192 arms even if a self, full-donor or W replay control fails; a complete run with a failed control must be marked **HOLD for interpretation**, with every failed control listed. An execution error writes an append-only failure row with completed arms and cannot count as a complete matrix. No arm or direction can be dropped after observing output.

The W replay control must reproduce the **prior saved W logits and complete argmax IDs exactly** for the same direction/site, in addition to the prior donor transcript. A self-C control must reproduce recipient baseline logits/IDs exactly, and full-donor must reproduce donor baseline logits/IDs exactly. These three gates must pass for a direction/site before interpreting its C or random-C outputs; failed gates remain in the denominator. Verify each partial patch differs from the recipient state only on its named rows, even if some donor rows happen to be numerically equal. C is much wider than W, and its natural donor delta may have a different norm; a C/W contrast is **not** a pure effect of location. The random-C arms match the C edit norm, not the W norm, and can cause collateral errors.

## Saved outcomes and decision rule

Save for every arm: the complete float32 `[1,T,32]` CTC logits and SHA-256, all argmax frame IDs, full greedy CTC-collapsed transcript, normalized words, exact patch tensor and SHA-256, W/C bounds, changed-frame count, L2 distance to recipient and donor logits, patch delta norm, hook count and per-arm resource receipt. CTC has no EOS. An independent saved-data auditor must rehash every sidecar, rebuild the 192-row matrix and all patches from baseline states/windows/seeds, recompute greedy CTC from saved logits using the pinned vocabulary, verify all control equalities and prior W replay, and reject missing/duplicate/partial/failure runs as a scientific completion. Source and auditor require independent review and fake-model/no-weight tests before the freeze. Reproduce a no-weight preflight byte for byte, then commit and independently review a separate freeze receipt before one real-model run.

Report these **distinct** complete-transcript outcomes for every arm and site: (a) exact equality to the paired model donor's baseline transcript across all 16 directed mode cells; (b) exact equality to the recipient baseline transcript; (c) another full transcript with collateral changes; and (d) strict intended-word target-only transfer on the **four** independently fixed eligible cells per site. Eligibility requires both clean endpoints to contain exactly one own intended word, exclude the paired alternative, and differ only in that word; only Piper `plate`↔`cup` under S/C qualifies. The other 12 per site stay descriptive and include donor model spellings **TEEL, TIL, CUB**. A changed frame path, logit margin, or apparent donor substring cannot substitute for a complete-transcript outcome. Report counts for every condition, including random-C changes to unrelated words; the prior random-W controls changed a complete transcript in 11/64 arms despite 0/64 strict donor transfers.

The primary *mechanism* comparison is whether natural donor C alone makes the full output equal the paired model donor transcript, compared with W replay, under passing controls. A positive C result would show **sufficiency of the off-word state in this exact patched context**, not its natural origin or necessity. A negative result would show only that this particular C transplant did not suffice; it cannot prove absence of word information in C, that W is uniquely necessary, or that GroupNorm spread is unused. Such information could require W/C interactions or a different intervention magnitude. S and C preprocessing modes are correlated measurements of the same eight WAVs; do not treat them or the 32 site-direction cells as independent samples. This remains one English CTC ASR checkpoint and two already-inspected synthetic FIT word pairs, with no human speech, multilingual generalization, speech output, tool action, attacker-reachable waveform, or security-property violation.

Use a **30-minute wall clock, 4-GiB process peak RSS, 512-MiB new-output cap** with headroom checks before and after each forward; one forward is not interruptible by operator-level checks. Run on CPU only. Keep large tensor sidecars locally, bound by a committed SHA-256 inventory. Publish the complete raw JSONL, independent audit and result review without retroactively changing this matrix. After this FIT mechanism check, the next transfer study should use fresh word pairs and independent voices with a separate quality gate, rather than reusing these FIT outcomes as held-out evidence.
