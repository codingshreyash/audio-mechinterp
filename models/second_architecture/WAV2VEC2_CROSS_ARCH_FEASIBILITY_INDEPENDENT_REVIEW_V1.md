# Independent source and no-weight review: Wav2Vec2 cross-architecture feasibility

18 November 2026. Reviewed `WAV2VEC2_CROSS_ARCH_CAUSAL_FEASIBILITY_V1.md`, its committed input-locality script and JSON from `852846d`, and the pinned local Transformers/checkpoint files. **Decision: GO for source-level and preprocessing feasibility only.** I did not load model weights, run a neural forward, inspect held-out corpus v2, or establish clean CTC eligibility.

The cached `facebook/wav2vec2-base-960h` revision, checkpoint, config, and preprocessor hashes match the note. The installed `feature_extraction_wav2vec2.py` and `modeling_wav2vec2.py` hashes also match. Source inspection confirms per-utterance zero-mean/unit-variance normalization on unpadded input, a first feature-convolution `GroupNorm` selected by `feat_extract_norm="group"`, positional convolution before encoder blocks, and a framewise 32-label CTC head. With one GroupNorm group per output channel, its statistics span time; this is a *possible* spread mechanism, not an observed model activation under this note.

A fresh no-weight run of `wav2vec2_input_locality_preflight_v1.py` produced JSON byte-identical to `WAV2VEC2_INPUT_LOCALITY_PREFLIGHT_V1.json`. I separately called the pinned cached `Wav2Vec2FeatureExtractor` on the eight full WAVs, without weights or padding. Its outside-slot maximum absolute normalized differences matched the saved values exactly in float32: `0.26646137` and `0.22046661` for the Piper/Kokoro color pair; `0.18251419` and `0.26614094` for the object pair. The paired raw PCM is identical outside each word slot, and common-statistic normalization makes the compared outside-slot values identical. Thus the stock input already has off-word differences *before* any model layer; the source supports the note's warning against assigning every later off-word difference to transformer attention.

The proposed Mode C uses shared outside-slot normalization statistics and is explicitly labeled as a counterfactual, not a stock-model result. The note correctly gates any live causal intervention on complete clean CTC transcripts and an independently reviewed runner. Its nominal convolutional stride/receptive-field calculation is consistent with the pinned seven-kernel configuration (`320` samples total stride, `400` samples receptive field). No Wav2Vec2 transcription, causal intervention, cross-model transfer, or security finding has yet been measured.
