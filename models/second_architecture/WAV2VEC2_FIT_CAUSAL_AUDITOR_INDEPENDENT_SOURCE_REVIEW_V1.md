# Independent source review: Wav2Vec2 FIT causal saved-data auditor

18 November 2026. **Decision: GO for the committed saved-data auditor source; HOLD for a result claim until a complete run is audited.** I reviewed `wav2vec2_fit_causal_patch_audit_v1.py` SHA-256 `c62c54cb1ea117353befd63407865bd638c40056450d2147a6e96ca69695609d` from amended source commit `6ff1020`, the V1/V2 plan and baseline, and reran its no-weight tests. No real-model patch inference was run.

The auditor verifies the frozen preflight and reviewed freeze receipt, requires exactly 226 ordered records (preflight, 224 patches, completion), rejects a failure row or an incomplete matrix, and checks the entire output directory against the declared sidecar inventory. It rehashes every saved patch and logits array, rebuilds each W/P/Q or seeded Gaussian patch independently of the runner's patch function, recomputes its effective norm, greedy CTC frame IDs, full decoded transcript and target-only outcome, and checks logit distances and changed-frame counts. It recomputes exact self and full-donor controls against independently reviewed clean logits. A false target-only claim for a changed `cub` transcript is rejected by the actual auditor outcome gate in the fake test.

A complete run with failed self/full-donor controls receives `saved_data_verified_controls_hold` rather than a scientific pass; the completion row must list those exact failures. The auditor checks the checkpoint load report, resource receipts and final output cap. Its source shares baseline loading, text normalization and preflight functions with the runner, so its independence rests on separate patch reconstruction, sidecar hashes and output recomputation rather than an entirely independent implementation of every utility. A saved-data pass verifies the saved evidence; it cannot alone prove that a model forward occurred or that internal patches represent attacker-controllable audio.
