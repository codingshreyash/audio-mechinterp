# Independent source review: Wav2Vec2 FIT baseline and stage capture

18 November 2026. **Decision: GO for the frozen 16-case clean baseline and eight paired stage traces only.** This review covers the committed prospective plan (`bc07b4b`), runner (`3fe010f`), saved-data auditor (`4b38c7e` with follow-up in `96699b9`), and no-weight receipt (`96699b9`). I did not load Wav2Vec2 weights, run a model forward, inspect held-out corpus v2, or establish a causal or security result.

The frozen receipt is reproducible before weights are loaded: an independent invocation of the runner's `preflight` command produced byte-identical JSON with SHA-256 `bf6db18d379d649905c7cfb37ebad572bd5de0d773ec479e33e69f67edfcd30b`. The independent auditor's `audit_preflight` accepted that receipt against the eight actual FIT WAV/PCM hashes and installed source hashes. The local pinned snapshot contains exactly the six expected assets, including checkpoint `8aa76ab2243c81747a1f832954586bc566090c83a0ac167df6f31f0fa917d74a`. The runner loads the processor and model from that exact snapshot directory and makes no network request.

Source inspection confirms the fixed pair/voice/word/mode order gives 16 complete baseline forwards. Each records all ten planned float32 stages, including the first convolution output before GroupNorm and the GroupNorm output before activation, a prehook at encoder block 0, posthooks at blocks 0/5/11, and full frame logits. The stage hooks correspond to the pinned Transformers implementation. Full logits argmax, full CTC decode, normalized words, and the exact intended-word-once/alternative-absent eligibility flag are recorded for every case; no favorable cases are selected before the denominator is known. The runner computes the complete argmax before decoding and retains already computed CTC fields in a failure row when a later check fails.

Mode S calls the stock processor on each unpadded full waveform. Mode C applies one shared outside-slot float32 mean and variance to both complete waveforms, and the runner checks bitwise equality outside the slot. The auditor independently recomputes each captured input and all eight pair/mode trace rows. Its saved-data checks require the 26-row success matrix, exact capture shapes and SHA-256 hashes, complete CTC decode and eligibility, exact float32 trace sidecars, Mode C off-slot equality at input and first-conv raw output, positive stock input off-slot contrast, and the complete output-file inventory. I cross-compared runner and auditor trace arithmetic on synthetic arrays for the input, first-conv, final-conv, late-block and logit layouts; results were bitwise equal.

All 13 committed no-checkpoint/fake/corruption tests passed in `reproductions/audio_prior/.venv` (four runner and nine auditor tests). The runner checks 30-minute elapsed time and 4 GiB peak process RSS at admission and after each forward, reserves 1 GiB RSS and 128 MiB output headroom before a forward, and checks the 2 GiB output limit before each lossless `.npy` write. A single neural operator is not interruptible by these checks, as the receipt explicitly states; a process killed inside a forward cannot produce a failure row. The auditor checks saved receipts and the final actual output inventory, but saved files alone cannot prove a faithful model forward. A successful live run therefore still requires an independent saved-result audit before any scientific conclusion. This GO does not authorize a causal patch, locked-test run, or security claim.
