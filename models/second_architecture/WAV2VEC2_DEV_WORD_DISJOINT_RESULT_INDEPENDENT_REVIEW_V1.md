The strict, full-template rule accepts **74/96 clean model/mode outputs**, corresponding to **37/48 distinct WAVs** and **14/24 pair/voice cells** with both words correctly transcribed. This yields **56/96 eligible directed mode cells**, repeated across the correlated S/C modes. Within those 56, W and full donor make the **intended-word-only complete transcript in 56/56**, while O and self do so in **0/56**. Across all 96 planned directions, W exactly matches the model's donor transcript in **96/96**; this descriptive count includes wrong clean spellings such as `gray`→`GREY`, `fox`→`VAUC` and `mirror`→`MIRA`. It must not be called 96/96 correct intended-word transfer.

The W versus O pattern holds in every **12-pair × 2-voice × 2-mode** stratum: for each engine/mode, W matches donor in **24/24** and O preserves recipient in **24/24**. Strict intended-word eligibility is **16/24** for Piper S and Piper C, and **12/24** for Kokoro S and Kokoro C. Both engines and both modes use the same pair list, so these are correlated checks, not 96 independent linguistic trials. The paired S/C clean transcript strings are identical for all 48 WAVs. Random W caused collateral, non-donor transcript changes in **13/96** arms (7 S, 6 C), including **2/56** strict-eligible arms; random O preserved the recipient transcript in **96/96**. Neither random arm produced the donor transcript.

The natural donor-minus-recipient W edit has L2 range **38.579–61.097** and median **49.474** across directed cells; the outside O edit has range **9.459–36.137** and median about **18.45**. Region size and edit magnitude differ. The result establishes relative sufficiency of these exact internal transplants for this checkpoint and corpus, not absence of word information in O, a unique word circuit, or a route by which an outside speaker can create the same state. Corpus-v1 development had already been inspected in earlier Qwen work, and these are the same two synthetic TTS engines as FIT. This run is a useful cross-word **exploratory** replication, not a sealed word-and-voice generalization test. There is no speech-assistant action or security-property violation in this result.
