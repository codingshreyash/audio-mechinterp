# What the matched acoustic-noise pilot shows

19 November 2026. This is a synthesis of two independently audited, **already inspected FIT** ASR attempts, not a new model run or a security finding: [Whisper](ACOUSTIC_FIT_NOISE_WHISPER_RESULT_INDEPENDENT_REVIEW_V1.md) and [Wav2Vec2](ACOUSTIC_FIT_NOISE_WAV2VEC2_V2_RESULT_INDEPENDENT_REVIEW_V1.md). Both used the same four synthetic English source recordings (Piper/Kokoro × silver/teal) and the same fixed noise recipe with clean, exact-repeat, full-noise, word-slot-noise, and outside-slot-noise arms. The first Wav2Vec2 attempt failed in a capture hook before any case; its [diagnosis](ACOUSTIC_FIT_NOISE_WAV2VEC2_ATTEMPT_001_DIAGNOSTIC_V1.md) and raw failure remain in the record. A separately reviewed V2 capture produced the Wav2Vec2 result.

| Question | Whisper Tiny English | Wav2Vec2 English CTC |
| --- | --- | --- |
| Complete transcript after 12 noisy variants | 9 identical to own clean transcript; 3 changed punctuation/case or pause rendering. All 12 retained the intended word. | 10 identical to own clean transcript; one corrected clean `TIL` to intended `TEAL`, and one changed preceding `IS` to `ISE` while retaining `SILVER`. Clean teal was already wrong in both voices. |
| Full-recording noise | All four complete transcripts unchanged. | All four complete transcripts unchanged. |
| Word-slot-only noise: first **measured** outside-word difference | Zero outside change in saved mel and pre-block state; nonzero after encoder block 0. | Raw PCM outside the word was identical, but stock whole-recording normalization changed model `input_values` outside it before any network layer. |

The central lesson is about **where a known acoustic edit enters each computation**. In Whisper, this word-local edit stayed local through the saved front-end states and spread at the first observed encoder block. In Wav2Vec2's stock path, preprocessing itself couples all samples through utterance-level statistics, so an identical raw-PCM outside region is no longer identical at the network input. This is an architectural and preprocessing distinction on these exact clips, not a claim that one model is generally safer or more robust. The state coordinates, temporal resolutions, tasks, and norm scales differ, so the measured L2 values cannot be compared directly across models.

The output results also prevent a common interpretability mistake: a large internal state difference did not generally change the lexical transcript. Conversely, Wav2Vec2's one target-word correction arose from a **post hoc selected** FIT case where the clean model was wrong. Neither numerical spread nor that correction identifies which state caused the changed transcript. The [prospective causal follow-up](ACOUSTIC_FIT_NOISE_WAV2VEC2_V2_RESULT_INDEPENDENT_REVIEW_V1.md#prospective-causal-follow-up-separate-from-this-result) proposes matched clean/noisy state transplants in both directions, word-window versus outside-window versus full-state patches, and equal-norm random controls. That will test sufficiency only for the selected case. Fresh, word- and speaker-disjoint recordings with human intelligibility judgments are needed to assess transfer. A security finding would further require an attacker-suppliable waveform changing a consequential decision in an unmodified assistant, with raw action and spoken branches preserved.
