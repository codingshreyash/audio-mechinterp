# Independent review: controlled acoustic mechanism follow-up

19 November 2026. Reviewed `ACOUSTIC_MECHANISM_NEXT_EXPERIMENT_DESIGN_V1.md` at commit `9e1d5c5` against the linked completed FIT/development audits and the fresh-word V2 fixture. **GO as a research direction; HOLD as an executable candidate-model protocol.** This review adds no model run or security result.

The memo correctly separates the existing Voxtral Track B internal answer-link assay from the broader question of what ordinary acoustic variation does to audio pathways. Its numerical claims match the local independent reports: Whisper's first *observed* outside-window spread follows encoder block 0; Wav2Vec2's stock waveform normalization or shared-statistics GroupNorm spreads a local PCM difference earlier; Wav2Vec2 word-row swaps matched the model donor transcript in 16/16 per site while only 4/16 planned directions met the intended-word rule; the Voxtral development projector random arm failed its 18/96 ceiling at 56/96. These are correlated, previously inspected cases, as the memo says.

The proposed split and controls address the main leakage and attribution risks. The 32 V2 WAVs and their render recipe are already exposed, so they cannot become a new sealed cross-model test. Keeping derivatives with their source clip and holding out a separate speaker or engine is appropriate. Blinded human complete-word judgments are necessary for a same-word acoustic comparison; ASR agreement alone would be insufficient. Whole-output scoring, parity checks, full-state and equal-norm random controls, and a separate unmodified-assistant security threshold avoid interpreting a logit movement or white-box patch as an attack.

An executable freeze must resolve four points before candidate inference:

1. Pin exact utterances, speakers, transformation code and parameters, processor/model revisions, seeds, sample counts, exclusions, and stopping/decision rules. State whether the held-out voice is a new engine or merely a new voice within an engine, and do not pool correlated transforms as independent observations.
2. Define the observable for **earliest meaningful divergence**. Noise, channel filtering and rate changes alter the waveform or processor output by construction; calling that first difference a discovered mechanism would be tautological. Predeclare aligned sites, thresholds, active-window geometry, and the criterion that separates numerical spread from a decision-relevant causal boundary. Rate alignment needs verification after the actual transformation.
3. Separate a **changed-output rescue** analysis from a **stable-output invariance** analysis. If clean and transformed recordings already yield the same full answer, patching clean state into the transformed run cannot be scored as a decision rescue. Report such cases in the full denominator and use a separately frozen sensitivity/representation measure if invariance is a target.
4. Specify task-matched endpoints per model. Whisper and Wav2Vec2 produce transcripts; Voxtral generates an answer, so raw output rates are not directly comparable. Freeze each model's complete-output rule and the within-model comparison, including how clean recognition/answer errors enter the denominator. The later security assay must independently demonstrate an attacker-suppliable intelligible waveform changing a consequential unmodified-assistant decision with raw branches and dispatcher evidence.

The current memo is therefore a sound next-study map, not authorization to run candidate weights or a demonstration that acoustic variation creates a security vulnerability.
