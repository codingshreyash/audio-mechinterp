# Independent review: Voxtral Track B V6 resource pilot amendment

19 November 2026. **Decision: GO for the corrected V6 prospective resource-admission design only; HOLD for any model weight load or Track B inference until the specified QA, executable-source, pilot and post-pilot review gates pass.** I reviewed V6 at final correction commit `282ecca` against the [V5 HOLD](VOXTRAL_FP32_TRACK_B_ANSWER_LINK_PROSPECTIVE_V5_INDEPENDENT_REVIEW_HOLD.md), the V3+V4 design GO and V5 sequential-alias equations. I ran no model, inspected no Track B listening answers or model outputs, and did not alter V6.

V5's short-generation timing flaw is addressed by one synthetic zero-PCM input whose no-weight processor shape, audio-placeholder count, implied projector row count, attention-mask length and sample count must each meet or exceed every selected Track B clip under the frozen prompt. The search starts at the selected maximum sample count, tries at most 512 increments of 128 samples, freezes the *first* satisfying input and its hashes, and fails closed otherwise. It cannot use a measured answer or gradient to select geometry. A fixed maximum-length alias including EOS is reused in all pilot score calls. Source implementation must still demonstrate that the processor outputs and call path match these declared geometries; this review approves the rule, not a future receipt.

The pilot requires the full independently audited **32/32 blinded human-listening GO before any model weight load**. It then makes two old-FIT natural clean/zero plumbing generations and two synthetic maximum-geometry `min_new_tokens=max_new_tokens=32` generations. The forced pair is now unambiguous: first unpatched with a read-only source capture, then an exact-zero hook using that state; both must produce 32 suffix tokens with identical suffix hashes and prepatch source hashes, and the zero arm must be bitwise unchanged at the projector. Both forced times enter the generation maximum. The protocol seals their text and tokens from study selection. Its 72 no-grad singleton scores and 12 singleton forward/backward calls use the same maximum-geometry synthetic audio/prompt and the fixed longest alias. Thus the pilot times the maximum planned score-call counts per Track B context at the declared geometry; it does not rely on a short old-FIT response as a 32-token bound.

The V5 singleton class score remains `L_c=logsumexp_a q_a`; the sequential gradient sum `Σ_a exp(q_a−L_c)∂q_a/∂H` is the correct derivative, and 112 generations + 1,152 no-grad scores + 192 clean forward/backward calls = **1,456 maximum core Track B projector calls** before alias deduplication. V6's pilot has **2 old-FIT natural + 2 forced + 72 no-grad + 12 backward** calls, with no separate capture call. Its admission arithmetic is explicit: with `W=7t_g+72t_s+12t_b`, require both `1.2W≤240 s` and `1.2(P+16W)≤3,840 s`, where `P` includes measured setup and every pilot call. `t_g`, `t_s` and `t_b` are maxima from the specified 2/72/12 relevant calls, with missing, zero or nonfinite times rejected. The 20% margin is an engineering screen, not proof that every live call will fit; live 240-second, 3,840-second, 30-GiB, disk/output and host/clock caps remain in force.

V6 also resolves V5's post-pilot freeze gap: before the first Track B answer or score, a separate frozen auditor must issue a content-addressed measured pilot receipt and an independent reviewer must give a GO bound to that exact receipt. It binds QA, selected WAV/processor and synthetic input geometry, alias IDs, source/model hashes, full planned/attempted/missing call ledger, timing and MPS peaks, host logs and clock checks. Any failed parity, absent call, invalid host transition, exceeded cap, interrupted pilot or infeasible projection is a retained HOLD with **no retry or substitute input under V6**. The pre-pilot no-weight receipt cannot stand in for this measured review.

This is a design GO, not a feasibility result. The 32/32 human QA, executable pilot/Track B runner and auditor source reviews, real pilot and its independent post-pilot admission review have not been established by this document. Any eventual result remains a per-recipient internal projector answer-link assay, not a reusable lens, time-localized mechanism, attacker-reachable audio effect or security finding.
