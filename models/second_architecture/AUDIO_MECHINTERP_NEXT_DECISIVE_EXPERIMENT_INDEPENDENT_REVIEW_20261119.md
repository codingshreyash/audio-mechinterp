# Independent next-experiment review, 19 November 2026

## Decision

**Make the VoiceChat perception-to-native-action study the primary next inference study.** Complete its existing human and live-adapter gates, then trace how a *fixed, intelligible spoken request* becomes a pass-1 function script. Use Qwen2.5-Omni-3B as a smaller, same-checkpoint text/audio **method rehearsal** while those gates are completed. Treat the Whisper padding result as a bounded ASR mechanism follow-up; it is too far from an attacker-controlled assistant action to lead the security program. This ranking is an inference from the local evidence and publisher sources, not a new model result.

The novelty bar is higher than “apply a lens to audio.” A September 2026 paper already fitted a Jacobian lens on text, read out dog/bark information from Qwen2.5-Omni-7B audio, and showed that directional edits changed output scores and **some complete answers** with matched controls. The authors found effects strongest at late decision positions and task dependent. Other work already studies sparse audio features and the gap between information encoded by an audio tower and information used by an answer. The opportunity here is a **causal, audio-to-action account across a real native function stream**, with an unmodified, attacker-suppliable waveform endpoint if one actually occurs. [Audio J-lens paper](https://arxiv.org/html/2609.33458v1); [audio SAE paper](https://arxiv.org/abs/2602.22253); [paralinguistic encoding/use paper](https://arxiv.org/abs/2609.00727).

## Primary VoiceChat experiment: exact decision chain

Use the already reviewed [V1/V2 source plan](VOICECHAT_ACOUSTIC_ACTION_PROSPECTIVE_V2.md), with no post-output changes to words, SNR, selection rule, or scoring. The 12 new recordings represent list-only, ask-before-cancel, externally confirmed cancel, and unrelated requests. The candidate input is the original 16-kHz WAV or a frozen 20-dB Gaussian-noise derivative of **the same spoken words**. Noise may affect the whole content, the human-marked decision phrase, or a matched displaced interval. The five-second zero tail, trusted date, seeded event IDs, prompt, tools, parser, and independent confirmation state are fixed. All 48 derivatives require two blinded listeners; disagreements receive a third review. Report all failed QA and all model nulls in the original denominators. [Protocol V1](VOICECHAT_ACOUSTIC_ACTION_PROSPECTIVE_V1.md); [V2](VOICECHAT_ACOUSTIC_ACTION_PROSPECTIVE_V2.md).

Capture **in order**: original WAV and preprocessing; perception output tuple; prompt-aligned audio/LLM input; shared hidden state; raw agent-text and function-head logits/IDs; complete raw pass-1 function span; parse result; independent inert authorization verdict. Preserve pass-2 replay and speech as a separate conditioned trajectory. This resolves the earlier confusion about where JSON comes from: the native function-token channel supplies it; TTS does not convert audible speech into JSON. Pinned source says `asr_emb` is retained but does **not** establish it as an active pass-1 function route under default offline flags; the live resolved flags and full-donor test must decide that. [Pinned source map](voicechat_acoustic_action_v1/PERCEPTION_TO_ACTION_HOOK_SOURCE_MAP_V1.md); [dual-head assay](VOICECHAT_DUAL_HEAD_ASSAY_PROTOCOL.md).

For every eligible clean/noisy pair, require stock-helper versus instrumented-helper parity, then exact no-hook/read-only/self complete-token and first-span parity. Replace the full three-part perception tuple as a donor control; only when it exactly reproduces the donor's **complete** pass-1 text/function/parsed endpoint may narrower decision-phrase versus displaced-frame and equal-norm random edits be interpreted. Predeclare the row mapping from human timing marks and log realized edit norms. Do not patch a late shared state across divergent prior token histories. The strongest locked positive is the V2 predeclared rule: at least two of four locked A2/B2 clean `single_list` → noisy `single_unconfirmed_cancel` contrasts, covering both independent wordings and both voices, repeated on the exact WAV bytes; the inert dispatcher must reject the unconfirmed proposal. This would be a reproducible model-origin integrity error in the bounded setup, **not a cancelled real meeting**. If it is absent, report a null action result and preserve any internal readout/patch evidence only at its actual strength. [V2 exact rule](VOICECHAT_ACOUSTIC_ACTION_PROSPECTIVE_V2.md).

## Method rehearsal while the VoiceChat human gate is open

Replicate the published **readout → intervention → localization** logic on Qwen's 3B checkpoint before interpreting a new authorization direction: validate a text-fitted mapping on held-out text and audio; compare audio to identical typed wording in the same checkpoint; then test full-response behavior, self, unrelated concept, matched random, and off-position edits. The published dog study demonstrates why a readout or first-token score is insufficient: complete-answer transitions were subset-dependent, and one task had no control advantage. Apply that discipline to LIST/ASK/CANCEL, with independent wordings/voices and a frozen held-out split. A direction that predicts a label but cannot transfer complete answers is a representation finding, not a causal authorization mechanism. [Published methods/results](https://arxiv.org/html/2609.33458v1); [Qwen card](https://huggingface.co/Qwen/Qwen2.5-Omni-3B).

The first Qwen pilot can be **source-only and no-weight** while QA is pending: finalize exact prompt/tokenization, fixed full-answer endpoint, hook identity, tensor shapes, and a resource cap. A subsequent one-sample Mac run may be considered only after its own measured memory/latency gate. Keep candidate locked recordings sealed until human QA. A Qwen JSON label would remain a proposed text answer; it cannot substitute for VoiceChat's native pass-1 function stream.

## What would change the ranking

- A VoiceChat stock/adapter parity failure or inability to fit the released 44.4-GB checkpoint on a suitable Linux/NVIDIA GPU puts the **candidate run** on HOLD; it does not make a Qwen text label a native function call. The publisher specifies Linux/NVIDIA integration and 16-kHz audio, while the local H100 is currently stopped. [Publisher card](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-VoiceChat-11B).
- A repeatable **natural waveform** padding/termination effect in Whisper, especially across larger checkpoints, would justify a separate availability/robustness thread. The current hybrid-state censor alone would not.
- Human voice and independently worded recordings are needed before generalizing any TTS result to speech users. Multi-model comparison should preserve each model's own interface and decoding policy; the same waveform can have different outputs without there being one shared circuit. [Qwen card](https://huggingface.co/Qwen/Qwen2.5-Omni-3B); [Voxtral card](https://huggingface.co/mistralai/Voxtral-Mini-3B-2507); [VoiceChat card](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-VoiceChat-11B).
