# Bounded parent handshake V3

19 November 2026. Source-only repair of the [independent V2 executable HOLD](TYPED_PILOT_INDEPENDENT_EXECUTABLE_REVIEW_HOLD_V2.md). A directly invoked V2 worker could reach MPS with a GO and pre-host receipt without a live bounded parent. V3 uses a new fixed attempt and requires a parent-created `start.json` after pre-host validation. It binds the exact GO, committed source identity, pre-host hash, parent PID, fresh 256-bit nonce digest and 300-second monotonic deadline. The parent passes the nonce on an inherited pipe and keeps that pipe open with heartbeats while sampling process-tree RSS, evidence bytes and elapsed time. The worker verifies receipt and pipe nonce before torch import, checks parent PID/deadline before model load, exits on pipe loss or missed heartbeat, and arms its own wall alarm. A direct `--worker` process with only GO and pre-host cannot reach torch. Neither this file nor no-weight tests authorize candidate loading. V1/V2 HOLD artifacts are preserved.
