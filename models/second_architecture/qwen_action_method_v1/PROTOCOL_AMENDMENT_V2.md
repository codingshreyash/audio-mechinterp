# Qwen action-label method V2: endpoint and target-restricted Jacobian freeze

19 November 2026. **Source-only amendment; candidate inference remains on HOLD.** The independent [V1 HOLD review](INDEPENDENT_SOURCE_REVIEW_HOLD_V1.md) found two output-classification errors and an unspecified readout. This V2 adds [`endpoint_v2.py`](endpoint_v2.py), a restricted numerical estimator in [`readout_v2.py`](readout_v2.py), and machine-readable [`READOUT_FREEZE_V2.json`](READOUT_FREEZE_V2.json). The V1 spec, its 30 scripts, its [source schedule](plan.py), the original endpoint and the V1 HOLD review remain unchanged. V2 does not repair a V1 result: **there has been no candidate-model run**.

## Exact target and tokenizer binding

The local-only [source audit](source_audit_v2.py) rehashed the unchanged V1 script spec, pinned modeling and processing code, config, and three tokenizer files. It loaded no model weights. Under that exact tokenizer, the **canonical no-leading-space** labels each have one ID: `LIST=22852`, `ASK=7384`, `CANCEL=88493`; EOS is `151645`. The label-plus-EOS paths therefore each have two tokens. The audit's local-only tokenizer load also confirms that EOS belongs to its special-ID inventory. Any future tokenizer or processor mismatch is HOLD, not a new alias chosen from outputs. Whitespace in a generated surface is accepted by the endpoint only after the raw token path is preserved; the *teacher-forced* target always uses these canonical IDs.

For each prompt `i` and class `c`, define the full, two-token target

`S_c(i) = log P(label_id[c] | prompt_i) + log P(EOS | prompt_i, label_id[c])`.

Teacher forcing evaluates all three classes on **every** FIT, development and later locked prompt. Save both full-vocabulary logit vectors, both selected token log probabilities, all candidate IDs, prompt IDs, attention/position metadata, and the actual complete greedy output. The class-score diagnostic is not an observed answer. [`complete_label_log_score`](readout_v2.py) computes the sum with a stable log-sum-exp; a first-token margin cannot replace it. The pinned `max_new_tokens=12`, deterministic generation, and strict complete-label+EOS endpoint remain the primary behavioral outcome. V2 endpoint precedence is: invalid metadata/IDs raise; empty or ordinary missing-EOS output is **censored**; any early/repeated EOS or unexpected special ID is **malformed**; terminal EOS with a single exact label is **complete**; other terminal text is **malformed**. All raw IDs and all three classes remain in the denominator. The V1 endpoint must not be used for a candidate result. Generated labels can use leading-space or multi-token aliases even though the canonical targets are single tokens. V2 records a separate `canonical_label_path` flag; a canonical-path score is **not** the total probability of all surfaces that mean the label.

## Restricted Jacobian readout, fixed before activations

The [2026 Qwen2.5-Omni-7B audio study](https://arxiv.org/html/2609.33458v1) estimated full cross-layer Jacobian maps from 1,000 text prompts before testing audio and then used directional, norm-matched causal controls. **Eighteen** typed prompts here are not enough to validate a general `2048×2048` map. This V2 instead freezes a **three-target VJP readout**, not a full Jacobian Lens. Its narrower question is whether a text-fitted *local sensitivity to the complete LIST/ASK/CANCEL responses* transports to spoken prompts on the same checkpoint. The previous Qwen rank-16 map's [failed development gate](../../../eval/audio_jlens/corpus_v1/STAGE_A_RESULT_INDEPENDENT_REVIEW.md) remains failed and contributes no fitted tensor or hyperparameter to V2.

Use only the 18 balanced `fit_text` scripts. At each fixed shared Thinker post-block site `text.residual.17` and `text.residual.34`, capture `h_{i,l}` at the **final prompt token before generation**. For each of the three teacher-forced label paths compute `g_{i,l,c}=∂S_c(i)/∂h_{i,l}` at that same prompt position. The three suffix passes must have byte-identical prompt IDs and prompt-last states with maximum absolute FP32 difference **≤1e-5** at each site; otherwise HOLD. Use the `LIST` suffix pass as the canonical saved `h_i` after this check; keep all three states in the raw record. One forward/backward for each `(script,class)` can capture both site gradients, so the planned FIT is **54 scalar VJPs**, not a full-width Jacobian. Save all 18 × 3 × 2 score/gradient/state records, their hashes, dtype, hook call count, and failures; no sample can be silently skipped. FP32 is required for model arithmetic and float64 for saved-tensor fitting. The live runner must verify hidden width 2048; fake arithmetic tests use smaller shapes.

For each site, set `h̄=mean_i h_i`, `S̄_c=mean_i S_c(i)`, `ḡ_c=mean_i g_{i,c}` and predict on an unchanged typed or audio prompt state `h`:

`Ŝ_c(h) = S̄_c + ḡ_c · (h - h̄)`.

This is an affine first-order, target-restricted mean-Jacobian estimator of **rank at most three** in output target space. There is no ridge coefficient, learned class label probe, audio-domain fit, per-item local derivative, input-dependent router, or site selection. `text.residual.34` is the fixed **primary** site and `text.residual.17` a named secondary depth comparison; neither site can replace the other after seeing development. A top class is the argmax over the three predicted `Ŝ_c` values, with ties broken by frozen `LIST,ASK,CANCEL` order. Report all three raw predicted and actual scores, MAE over all `6×3` cells per modality, top-class accuracy against intended labels, and actual complete generation. A correct target-score readout without a complete answer is only a representation/score result.

Two fixed comparators use the **same 18 FIT text contexts and three full-sequence score targets**:

- **Constant:** predict the three FIT mean scores `S̄_c` for every development/locked item. The balanced six-script development truth makes its fixed top class correct on exactly 2/6.
- **Centered dual ridge:** with FIT `X_i=h_i-h̄`, `K=XXᵀ/2048`, and `λ=trace(K)/18`, fit `A=(K+λI)^{-1}(S-S̄)`. Predict `S̄ + ((h-h̄)Xᵀ/2048)A`. No hyperparameter search, audio fitting or held-out selection. If `λ≤0`, HOLD. This is a small task-specific supervised score predictor, **not** a Jacobian Lens. Report its MAE and top-class accuracy beside the restricted VJP; do not claim VJP superiority unless the paired comparison actually supports it.

The [no-weight arithmetic module](readout_v2.py) implements the target score, affine VJP, ridge and constant baselines. It cannot generate candidate states; a separately reviewed runner must supply those states under the frozen source path. A full `2048×2048` map, generic concept direction or cross-model readout would require a different and much larger protocol.

## Development gate and causal controls

The existing V1 task gate remains **at least 5/6 exact label+EOS** for development typed and **5/6** for its same-word Piper audio. To keep the three canonical teacher-forced paths representative of actual generation, V2 also requires **at least 5/6 canonical full paths** separately for typed and audio. Other exact decoded labels still count toward V1 task accuracy and remain visible; they do not satisfy this target-validity gate. V2 adds, at the fixed primary site 34, a VJP predicted intended class on at least **5/6 typed and 4/6 audio**, both strictly above the constant top-class count, plus `MAE(VJP)/MAE(constant)≤0.9` separately for typed and audio. A zero constant MAE is a failure, not an automatic pass. [`development_gate`](readout_v2.py) computes this on all six script IDs in fixed manifest order; V1's `fit_text` contexts never enter development metrics. Site 17, ridge scores, score correlations and subtype rows are reported without a promotion role. If any gate fails, report the exact null and do not open locked candidate outputs or alter estimator settings. A pass permits a separately reviewed, one-shot locked assay; it does not establish a security finding or a general-purpose lens.

Two **separate** causal questions follow only after baseline/parity and the development readout gate:

1. The V1 [audio-junction schedule](plan.py) remains 90 all-planned edited forwards: self, full projected donor, same-label donor and two equal-L2 random edits in 18 predeclared directions. All sources must have equal processor/projected shape and placeholder counts. Exact no-hook/read-only/self and full-donor **complete-token** parity must pass before a class transfer is credited. This is a conditional full-route transplant, not a naturally supplied attack.
2. V2 adds a text-fitted **target-score direction** at `text.residual.34`, final prompt token in **prefill only**. The [source-only schedule](directional_schedule_v2.py) fixes every cell and seed. For each six-script development item in typed and same-word audio form, use the intended class `r` and a frozen target rotation `LIST→ASK→CANCEL→LIST` as `c`. Define `u=(ḡ_c-ḡ_r)/||ḡ_c-ḡ_r||`; a zero or nonfinite norm is HOLD. Add `Δh=0.03||h||u`, one zero edit, and two independent `PCG64` random unit vectors orthogonal to `u` with **the same realized edit norm**. This is 12 development source/modal cells × four arms, and later 18 locked source/modal cells × four arms, with no output-based case selection. Seeds are SHA-256 of `qwen_action_method_v2|case_id|target_label|control_index` first 16 hex as an unsigned integer. The hook must edit only the one prefill state and preserve all prompt/token histories; inspect hook count and exact no-hook/read-only/zero-edit complete-token parity. Save full generated IDs, EOS, exact labels, all target scores, edit norms, RNG seeds and failures. If target edits move a score but fail to change complete labels beyond matched controls, report a score-only result. A direction intervention is a white-box test and cannot establish an attacker-supplied audio exploit.

The fixed `0.03` dose mirrors one published full-response injection setting; it is **not calibrated to Qwen 3B**. A null at this dose is a null. Future dose changes require a new version before locked outputs. Off-position/local time-row edits need model-blind phrase timestamps and an independently verified audio-to-row map; V2 does not claim them.
