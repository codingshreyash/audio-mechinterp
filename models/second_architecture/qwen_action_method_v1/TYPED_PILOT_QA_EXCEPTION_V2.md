19 November 2026. **Prospective source amendment, not an executable GO.** The [runner contract V1](RUNNER_SOURCE_HANDOFF_V1.md) requires the 18/18 two-listener speech QA receipt before candidate model loading. The [independent typed-pilot V1 HOLD](TYPED_PILOT_INDEPENDENT_EXECUTABLE_REVIEW_HOLD_V1.md) identified that this requirement also blocked a strictly typed resource/VJP pilot. This amendment permits an independent reviewer to approve **exactly one** `F_L1__typed` resource and three-target teacher-forced VJP pilot under the fixed V2 attempt and host/resource/evidence gates, before speech QA is complete. It makes no exception for any audio input, the other 17 typed FIT prompts, development, locked items, model-directed task selection, or a claim about audio behavior.

The pilot uses only the already-frozen system prompt and `F_L1` wording. Its generated answer is recorded for parity and feasibility, but cannot be used to change the class labels, wording, voice, splits, method, dose, future case selection or development gate. If the model output is malformed, censored, wrong, or the intervention/host audit fails, preserve that result as such. A later FIT or audio job still requires the independently audited 18/18 human speech receipt, an executable runner review and a separate bound GO. The Qwen text label is never a native function call or calendar operation.

`typed_pilot_backend_v2.py` binds this exact amendment in its reviewed source list and requires the independent GO receipt to state `qa_policy=typed_F_L1_only_no_audio_QA_exception` and carry this file's SHA-256. Both parent and worker recheck GO before any weight load. No GO exists merely because this amendment exists.
