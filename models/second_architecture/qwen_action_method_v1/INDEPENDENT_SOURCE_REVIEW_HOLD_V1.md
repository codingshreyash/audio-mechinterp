# Independent source review: Qwen action-label method V1

19 November 2026. **HOLD for candidate-model inference.** I reviewed commit `ba95c8e` without loading model weights or opening old or new locked answers. The source-only corpus and schedule are useful, but the complete-answer endpoint has two failure-classification errors and the planned Jacobian Lens mapping is not yet specified sufficiently to run or claim. This is a review of an unexecuted protocol, not a Qwen result.

## Checks that passed

- `python -m unittest models.second_architecture.qwen_action_method_v1.test_endpoint -q` passed **6/6 no-weight tests**. The pinned modeling, processing and config SHA-256 values match the installed local files and `models/qwen_omni/pins.json`; the test imports no model or processor.
- The frozen JSON has **30 unique scripts**, balanced by label: 18 typed FIT, six development, six locked. No normalized full script is repeated. Development is one Piper voice; locked uses Samantha and Kokoro. The new calendar-label task is separate from the earlier one-word lexical corpus. Its prior Qwen Stage A failed gate remains explicitly failed; no old locked output is reused or opened here.
- The source-only schedule has **18 audio cases**, 90 edited-forward rows, 30 development and 60 locked. Each inter-label pair has both directions, one same-label source from the other wording, and two independently seeded random arms. The 36 random seeds are unique. The `audio.to_language` hook name resolves in the existing adapter to `audio_tower.proj`; the pinned source places its projected output into audio-token positions before the shared Thinker language path. Whether the live helper actually takes that path with the intended shapes, and whether a full-donor edit reproduces a complete donor answer, remain **contingent runtime checks**.
- The protocol correctly says Qwen's `CANCEL` is a **text classification label**, not a native function call or a cancelled event. It requires all 18 speech sources to pass blinded two-listener wording review, live shape/parity checks and a separate memory/time gate. It makes no first-audio-Jacobian novelty claim; [published Qwen2.5-Omni-7B audio J-lens work](https://arxiv.org/html/2609.33458v1) already exists.

## HOLD findings

1. **An early EOS followed by tokens is misclassified.** `score_complete_answer([LIST, EOS, junk])` returns `censored`. The protocol says extra words and special tokens are `malformed`. The scorer checks only whether the **last** ID is EOS before deciding whether to inspect earlier EOS. A terminal EOS followed by anything should be recorded as malformed, with the complete raw token path retained. The current fake test expects `censored` for this case, so it enshrines the error.
2. **An empty continuation can disappear from the denominator.** `score_complete_answer([])` raises `ValueError`. A zero-token candidate output should be a recorded censored/failed outcome, not a scoring exception that may abort a batch or invite omission. Keep exceptions for invalid IDs or an impossible over-cap record, and add fake tests for empty output, early EOS plus trailing token, repeated EOS and unexpected non-EOS special IDs. An ordinary cap-reached output without EOS remains censored.
3. **The readout method is not frozen.** The protocol defers the estimator, target, regularization, comparison baselines and held-out promotion rule to a future amendment. Eighteen typed FIT prompts can support a small task-specific diagnostic; they do not by themselves validate a general 2,048-dimensional cross-layer Jacobian map. A Jacobian average, restricted direction, or regularized map could be legitimate, but its exact construction and development-only success criterion must be fixed **before** any candidate answer or activation is read. Distinguish a text-fitted Jacobian Lens from a separately trained linear probe and from the prior failed rank-16 Qwen map. A readable class label or a shifted likelihood is not a complete-answer causal result.
4. **No executable candidate runner or bound WAVs exist.** The 16-second recordings, voice engines/versions, source hashes, model-blind timing marks, 18/18 human QA receipt, resolved tokenizer/generation settings, hook call count, full-donor and stock/instrumented parity, and one-sample resource admission are pending. The current source map and schedule alone do not authorize a Qwen batch or locked-test reveal. In particular, fixed WAV duration does not prove equal projected row counts.

## Clearance conditions

Version the endpoint and its no-weight tests so all generated paths receive an explicit complete, malformed or censored record. Freeze the Jacobian/readout estimator and a development-only gate in a separate source amendment. Render and independently byte-audit the 18 WAVs; obtain the planned blinded listener and timing records. Then independently review a live parity/resource pilot and a bounded candidate runner before any development or locked model inference. Preserve this HOLD, the earlier Qwen Stage A failure, and any future failed attempts as separate records.
