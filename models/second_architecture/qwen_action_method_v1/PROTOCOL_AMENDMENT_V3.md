# Qwen action-label V3: source-bound development gate

19 November 2026. **Source-only correction; candidate inference remains on HOLD.** The [independent V2 review](INDEPENDENT_METHOD_V2_REVIEW_HOLD_20261119.md) reproduced a false promotion: caller-supplied class lists said all six examples were correct while the supplied VJP score rows had the wrong argmax on every example. It also found that caller-supplied canonical flags could be detached from raw token paths. This V3 fixes only the gate interface. V1 and V2 source and HOLD memos remain unchanged; no candidate weights, activations, or answers were loaded.

[`gate_v3.py`](gate_v3.py) accepts exactly 18 FIT records and six typed plus six audio development records. Each FIT record contains its frozen `F_*__typed` case ID and three class scores. Each development record contains its frozen `D_*__typed` or `D_*__piper_en_US_amy_medium` case ID, raw continuation IDs, and three actual and predicted complete-label score values. It checks exact case IDs **and manifest order** against the byte-hashed V1 script spec, and binds the byte-hashed V2 readout freeze. It rejects missing, extra, nonfinite or wrong-shaped score rows. The class column order is the frozen `LIST, ASK, CANCEL`; a future model runner must independently bind every score to the correct teacher-forced label-plus-EOS path and raw logits.

The V3 gate derives each complete label, censor/malformed status and canonical-path flag by running the [V2 endpoint](endpoint_v2.py) on the raw token IDs with the pinned tokenizer. It derives VJP and constant top classes by argmax of their **actual score matrices**. The constant matrix is recomputed from the 18 FIT score records, not supplied as a development list. An optional supplied `status`, `label`, `canonical_label_path`, `predicted_label`, or `actual_score_top` is accepted only if it equals the derived value; a contradictory assertion aborts. A canonical flag on a censored or malformed path cannot pass. The complete generated label may legitimately differ from the argmax of the three **canonical teacher-forced** score paths; V3 records both and does not silently identify them.

After these bindings, V3 calls the unchanged V2 numerical rule on the **derived** values: exact label+EOS and canonical counts, typed/audio VJP top-class counts, constant comparison, and each modality's VJP-to-constant MAE ratio. All six development script IDs remain in each denominator. A failed rule stays failed; no alternate class list, source order, or subset may promote it. The 30-source V1/V2 corpus, 16-second WAV plan, human review, tokenizer/source audit, target-restricted VJP estimator, fixed site, resource cap, directional arms, and sealed locked test are otherwise unchanged.

The [no-weight V3 regression](test_gate_v3.py) includes the exact V2 false-promotion score pattern: expected `LIST, LIST, ASK, ASK, CANCEL, CANCEL`, score argmax wrong on all six, and a VJP/constant MAE ratio of `0.04`. V3 returns **zero** VJP correct and `pass=false`. Tests also reject a claimed canonical flag on an empty continuation, a claimed complete label on repeated EOS, a predicted label contradicting score argmax, and shuffled FIT/development IDs. A valid synthetic record can pass, proving the gate has not been made trivially always false.

This is a gate-integrity correction, **not** a Qwen audio result or a full candidate runner. Before any development inference, independently review the V3 source, the 18-WAV byte and human-QA receipts, the exact tokenizer/teacher-forced logit alignment, stock/instrumented parity, a measured resource pilot, and a bounded executable runner. Locked outputs remain sealed until the independently reviewed development gate passes.
