# Qwen2.5-Omni-3B action-label method: source-only pathway map

19 November 2026. This map is for the pinned **Thinker text output**. It is a source reading, not a loaded-model trace or proof that a hook is causally active. [Exact existing model and Transformers pins](../../qwen_omni/pins.json) are bound by `frozen_spec_v1.json`; `endpoint.validate_local_source` hashes the installed implementation and config without importing or loading weights.

| Stage | Pinned implementation | Readout/intervention consequence |
| --- | --- | --- |
| Typed input | The same `Qwen2_5OmniProcessor.apply_chat_template` accepts system and user text. The existing [adapter](../../qwen_omni/adapter.py) records audio inputs through this processor. | A typed request and its spoken version can use the same words and system prompt. Their prompt lengths and positions differ; align at the final prompt token, **not** a numeric token index copied across modalities. |
| Audio processor | [`processing_qwen2_5_omni.py`, `_process_audio`](https://github.com/huggingface/transformers/blob/e7e568dc7673ac99a87660c7c50e84830268285c/src/transformers/models/qwen2_5_omni/processing_qwen2_5_omni.py#L202-L218) uses max-length feature padding, a feature attention mask, and expanded audio placeholders. | Save raw WAV hashes, processor feature values/mask, expanded input IDs, and placeholder counts. A fixed-duration WAV does not itself prove equal projected shapes; verify them before donor patches. |
| Audio encoder | [`modeling_qwen2_5_omni.py`, `Qwen2_5OmniAudioEncoder.forward`](https://github.com/huggingface/transformers/blob/e7e568dc7673ac99a87660c7c50e84830268285c/src/transformers/models/qwen2_5_omni/modeling_qwen2_5_omni.py#L862-L906) chunks/pads features, applies two convolutions and 32 encoder blocks, pools and projects to text width. Existing [adapter hooks](../../qwen_omni/adapter.py) resolve encoder layers 0/15/31 and `audio_tower.proj`. | Read out audio-time states at these predeclared sites. `audio.to_language` is the first full-route donor site, contingent on a live shape/placeholder check and exact complete-output donor parity. A row-to-waveform time map still needs source-only derivation and human timing marks before local patches. |
| Audio-to-text junction | [`Qwen2_5OmniThinkerModel.forward`](https://github.com/huggingface/transformers/blob/e7e568dc7673ac99a87660c7c50e84830268285c/src/transformers/models/qwen2_5_omni/modeling_qwen2_5_omni.py#L1887-L1900) obtains the audio tower's final state and writes it into audio-token placeholders with `masked_scatter`. | Donor and recipient prompts must have identical placeholder counts for a full projected-feature transplant. The downstream language prompt remains recipient; a full-donor effect is conditional on that controlled context. |
| Shared answer path | The Thinker has one 36-block `language_model`, final norm, and `lm_head`; [forward output](https://github.com/huggingface/transformers/blob/e7e568dc7673ac99a87660c7c50e84830268285c/src/transformers/models/qwen2_5_omni/modeling_qwen2_5_omni.py#L2087-L2122) includes text logits and optional hidden states. Existing hooks name `text.residual.0/17/35`. | Fit a text-only readout at the final prompt position, then evaluate its transfer to audio at the corresponding final prompt position. Save complete generated token paths and terminal EOS. A readable state or first-token margin is not a complete-answer mechanism. |

The [publisher card](https://huggingface.co/Qwen/Qwen2.5-Omni-3B) describes a Thinker/Talker model with text and speech output. The local task uses **only the Thinker**, and the pinned Thinker source exposes text logits through `lm_head`. This map does not establish a separate native function-token channel or an action executor. A `CANCEL` answer in this study is a **classification label**, not a tool call and not a calendar change. VoiceChat's separately planned native function stream is the primary action study.

## Live checks still required

1. Verify tokenizer EOS ID `151645`, exact rendered chat prompts, input features, audio placeholder counts, projected row count and tensor dtype on a *development* item before any patch.
2. Verify stock `generate` against an instrumented no-hook/read-only call with exact complete IDs; then exact self and full projected donor parity under the same generation settings. A shape mismatch or failed full-donor parity stops audio-junction interpretation.
3. Inspect the resolved model source and hook call counts at runtime. The hashes above bind the local installed bytes, but source reading alone does not prove runtime routing or timing alignment.
4. Do not patch a shared text residual after divergent generated histories. Later prompt-last residual interventions need a separate reviewed causal question, because they are not full audio-route replacement.

The [2026 audio Jacobian Lens study](https://arxiv.org/html/2609.33458v1) already used Qwen2.5-Omni-7B audio readouts and directional interventions that changed some complete answers. This project must claim novelty only for a separately verified mechanism, evaluation, or security endpoint.
