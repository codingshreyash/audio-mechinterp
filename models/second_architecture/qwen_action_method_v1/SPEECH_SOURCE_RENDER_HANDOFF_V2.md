# Qwen action speech source render V2 — source-only handoff

19 November 2026. **HOLD until independent V2 source review and a separately committed GO.** This version responds to the preserved [V1 independent HOLD](INDEPENDENT_SPEECH_RENDER_SOURCE_REVIEW_HOLD_V1.md). V1 code and the fake reviewer evidence remain untouched. No real TTS has been run by this V2 handoff, no Qwen model weights have been loaded, and no human review has been fabricated.

The fixed production attempt is `runs/source_render_v2/attempt_001`. `render_sources_v2.py` checks a separately committed `SPEECH_RENDER_GO_V2.json` and `INDEPENDENT_SPEECH_RENDER_SOURCE_REVIEW_GO_V2.md` before it creates the directory. The GO must name all exact committed source SHA-256 values returned by `reviewed_sources()` and hash the review memo. Dirty or untracked source, a missing GO, or a changed reviewed byte stops before TTS. The GO is produced by an independent reviewer after inspecting this source; self-generated admission does not suffice.

The production run is limited to 900 seconds, 200 MiB of saved evidence, and a **sampled** process-tree RSS maximum of 8 GiB. The RSS sampler checks the parent and descendants every 0.25 seconds; it records the samples and signals the renderer to fail if a sample exceeds the bound. A short transient between samples can be missed, so this is a sampled resource gate. The run records pre/post AC, lid-open and sleep/thermal-free power-log evidence. Its `manifest.json` is pending until a separate `terminal.json` is written and fsynced afterward. The terminal hashes the start and manifest and is checked against the full 900-second deadline after its own write. Any failure, including a late terminal write, leaves a `failure.json` and no acceptable terminal. The original failed attempt remains immutable.

`audit_sources_v2.py` rejects `failure.json`, wrong fixed path, missing/late/hash-invalid terminal, source/GO mismatch, invalid RSS samples, host gate failures, wrong 18-case plan, or any raw-to-converted-to-16-second-final reconstruction mismatch. It checks 54 audio files and no extra WAV/AIFF. The V1 `id` versus `case_id` mismatch is corrected by comparing the shared fields and separately requiring `case_id == id`.

`listening_bundle_v2.py` uses only a technically passing source. It builds two independently shuffled opaque queues at fixed `runs/source_render_v2/review_bundle_001`. Its **read-only `--audit-only` path** rehashes all 36 copied WAVs, reconstructs both queue permutations, compares both reviewer HTML forms byte for byte with the expected blind template, and checks the technical mapping outside the reviewer directories. A copied WAV or modified form fails. The forms collect 18 verbatim transcriptions, intent, date, event, phrase timing and notes from each reviewer; no answer is generated by the builder. The technical mapping must not be sent with the reviewer directories. The separate Qwen candidate inference HOLD remains in force until V2 method and human/listening gates pass.

No-weight fake tests in `test_render_sources_v2.py` cover a complete 18-source fake render-to-audit, copied-file tampering, a failure receipt next to a complete manifest, missing/late terminal proof, and missing GO before attempt creation. They patch TTS and host observations and therefore make **no** claim about real speech or live host state.
