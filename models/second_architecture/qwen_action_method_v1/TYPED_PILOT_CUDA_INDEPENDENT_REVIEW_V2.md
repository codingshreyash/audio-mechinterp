## Decision and limits

**GO for the 180-second load-only stage**, subject to the validator's fresh source/snapshot/binary/runtime/idle-GPU checks at execution time. The parent must cap total GPU use and framework peak reservation below 56 GiB, process-tree RSS below 24 GiB, and evidence below 64 MiB; it must preserve a durable terminal and pass the separate saved audit. The stage only loads the pinned FP32 Thinker, validates model dtype/tokenizer and records CUDA telemetry. It performs no forward, generation or VJP. Any failed or partial attempt consumes `load_001` and cannot be rerun under this GO.

The driver is older than the CUDA 12.8 toolkit's corresponding driver, while NVIDIA's [CUDA 12.x minor version compatibility](https://docs.nvidia.com/deploy/cuda-compatibility/minor-version-compatibility.html) includes driver branch 565. The no-weight CUDA availability query succeeded, but it does not prove every model kernel will work; that is part of this bounded load feasibility test. The saved audit, not this review, determines whether the load stage passed. A passing load audit would support a **separate** independent pilot review and GO. No security or audio transfer conclusion follows from this load authorization.
