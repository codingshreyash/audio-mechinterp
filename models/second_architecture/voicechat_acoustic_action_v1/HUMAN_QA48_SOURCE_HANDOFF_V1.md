# VoiceChat acoustic action: 48-WAV human QA source handoff

19 November 2026. **Source-only implementation; production 48-WAV QA and VoiceChat inference remain HOLD.** This implements the human wording and source-eligibility rules in the [V1 protocol](../VOICECHAT_ACOUSTIC_ACTION_PROSPECTIVE_V1.md) and [V2 amendment](../VOICECHAT_ACOUSTIC_ACTION_PROSPECTIVE_V2.md). It uses synthetic manifests and fake reviewer records only. No 48-WAV corpus, human review, ASR result, or VoiceChat answer is claimed.

## Workflow fixed in source

1. The variant validator checks the planned 12 source recordings × four arms, exact 48 file hashes, spec, order, source/arm labels and no extra files. Its public production path **raises before building a queue** until a separate independent variant-byte admission is added and reviewed. The synthetic branch requires a manifest labelled synthetic_test_only=true.
2. The private/queue builder derives 24-character opaque IDs from the variant-manifest hash, source, arm and WAV hash. It makes two independently shuffled, full 48-clip queues. The listener-facing first form receives only opaque IDs, anonymous WAV names and hashes. References, source IDs, voices and arm labels stay in a separate private map.
3. Each first listener records full verbatim words, uncertain spans, blind date/event/authorization notes, clarity and confidence. The form locks each response in browser local storage and exports only after the entire queue is complete. Browser storage and ID strings cannot prove that two people listened independently; the coordinator must verify that.
4. Only after **both** complete initial exports are supplied does the post-blind builder reveal reference scripts, source/arm labels, each reviewer’s locked transcript and their locked clean-source transcript. Each reviewer marks whether date, event, authorization and critical meaning versus clean match. The auditor validates those fields and the exact first-export hash. It does not use automatic semantic matching to replace human judgment.
5. A disagreement in initial clarity, blind critical notes or post-reference critical marks creates a sparse third-listener queue of only the flagged opaque clips. The third listener begins without references; the separate comparison form follows their locked first export. Third review resolves the record but **cannot rescue** a source unless both initial listeners judged every derivative clear and unchanged.
6. The pure auditor retains all 48 attempted arms and all 12 planned sources. A source is eligible only if its clean, full, decision and displaced arms each pass both initial listeners. If any of the four locked A2/B2 sources is ineligible, locked_ab_all_eligible=false; the denominator never shrinks. Two raw ASR diagnostic streams, 48 records each, are hash-bound in the report but their transcript content does not score human QA.

The report schema is voicechat_acoustic_qa48_audit_v1; it includes the exact variant/private/queue/export/ASR digests, every case result, source eligibility and all raw review documents. Its candidate_inference_authorized flag is always false. A future independent reviewer must authenticate the actual human identities, raw exports, form bytes, variant WAVs and receipt before a production preflight can use its SHA-256 as an exact grant binding. The current receipt writer only writes reports explicitly labelled synthetic.

## Source test and remaining implementation

Run the six fake unittest cases in test_human_qa48.py, node syntax checks on both JS files, and Python compilation on human_qa48.py. The fake tests cover the 48/12 denominator, two distinct blind orders, absence of scripts in the first form, complete first exports before reference reveal, a locked-source failure, sparse third review, tampered WAV/export/ASR and a nonauthorizing synthetic receipt.

The source slice is not yet a production CLI. Before real QA, bind an independently audited variant manifest and all 48 WAVs in a versioned admission receipt, add a production bundle/auditor entry point that reconstructs the exact rendered pages and reviewer exports from those admitted bytes, and independently review that final source. The 12 clean sources have been rendered and byte audited; the human timing marks and noise variants needed for this QA population do not yet exist. The older 12-WAV VoiceChat calendar QA and the 32-word Voxtral listening forms cannot certify this new corpus.
