## Blocking censored/no-span misclassification

V2 declares `censored` a mutually exclusive first-span label and retains incomplete generations in the planned denominator. `classify_first_pass` chooses `no_span` before it checks `censored` (`action_endpoint.py`, label branch near the return). With valid case and hash arguments, `classify_first_pass([], censored=True)` returns `first_span_label='no_span'`, identical to an ordinary completed no-call turn. This loses the censor reason at the endpoint and can make incomplete generations appear like stable no-call outcomes. I independently reproduced `censored_empty → no_span` and `no_span → no_span` using the exact committed source. Make censor status take precedence even when there is no extracted span, while retaining `all_raw_spans=[]`, `pass2_function_injection=false`, and `response_step=0`; add a regression for both censored and completed empty outputs. If the implementation needs to distinguish a true model stop from a harness timeout, the caller must supply that separately in the live evidence.

## Checks that passed within the source-only slice

All **10/10** fake `unittest` cases passed and `py_compile` passed. The classifier selects the first raw span and does not fall through from malformed first JSON to a later valid call. It strips the same tags as the pinned helper, keeps successfully appended entries in a partial array, records full-span replay IDs, and sets pass-2 injection only when the resulting IDs are nonempty. The source rejects multi-batch extractor output rather than silently treating a different batch's span as the first. The source-only grant logic binds a C1/C2 test grant to script, exact WAV/QA hashes, trusted controller, date and `DR19`; a model-written `confirmed` value does not authorize A/B/D. Valid entries receive separate inert verdicts and a multi-call cancellation is reported outside the single-call security endpoint. These are parser/fixture claims from fake inputs, not stock-versus-adapter parity.

For malformed JSON, `first_json_shape` is `null`, while the cleaned raw text and parse error are preserved. An invalid JSON value has no parsed shape; this is not a separate blocker. The later live recorder still must retain the complete function-token stream, verify the extractor output and tokenizer against stock on the same WAV, independently authenticate the WAV/QA/controller grant bytes, and keep all external actions inert.

**Decision:** correct the censored/no-span precedence and obtain an independent rereview of the exact new source before integrating this classifier into a candidate runner. Human QA, official-sample/adapter parity, a bounded resource run, and a VoiceChat action outcome remain absent.
