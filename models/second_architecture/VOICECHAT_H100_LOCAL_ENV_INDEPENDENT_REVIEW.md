The 75,000 MiB threshold is a local policy; the hook workload has no published memory guarantee. The card gives no exact trailing-silence duration.
- At the pinned [checkpoint revision](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-VoiceChat-11B/tree/443794ea956ef0065f001967ffd00e77f519cb39), `config.json` hashes to `2e0b67b56fefeb4815e436d66ad84f2f94be192b1d543054c810ed239a28cff5`, names `nvidia/NVIDIA-Nemotron-Nano-9B-v2`, enables `use_function_head`, and sets `duplex_function_channel_weight=2.0`. Published metadata lists `model.safetensors` as 44,382,749,892 bytes with SHA-256 `d553750c29434a6bb524377e17634c6cafdbf621892e643a77f406e51570354b`. This checks metadata, not locally downloaded weight bytes.
- The five preflight source hashes match the files at pinned [NeMo Speech commit `097dfe9`](https://github.com/NVIDIA-NeMo/Speech/tree/097dfe9e2f55baf653b83035868bdc89849f1b47). `--self-test` returns `self_test_passed_no_model_or_network`. The code enforces the 6×2 case keys, 16 kHz mono PCM16, more frames than trailing padding, exact zero padding, and full-file hashes. `ready` also checks pinned package versions, actual checkpoint size/hash, one selected H100/A100 with at least 75,000 MiB, and 60 GiB free on the checkpoint filesystem. Exceptions exit nonzero. None of these checks imports NeMo or executes a model.
- The 150 GiB staging, 60 GiB residual disk, and dated Brev prices are planning estimates, not measured consumption or current offers. A one-sample load/identity/memory pilot remains necessary before the fixture matrix.

## Blockers before a meaningful `source` or `ready` receipt

1. **Unclean NeMo tree can pass `source`.** `check_source()` tests `git rev-parse HEAD` and five file hashes, but not `git status`. Any changed tracked file outside the five, or an untracked importable Python file, leaves those checks unchanged while altering the runtime source. Require an explicit clean tracked/untracked policy for the entire NeMo checkout and report it in the receipt. This applies before trusting `source`, not merely before inference.
2. **One WAV can impersonate every declared voice.** `check_fixtures()` deduplicates `(script_id, voice_id)` but does not deduplicate resolved path or SHA-256. In a synthetic temp fixture, all 12 TTS cases plus the declared human `A` case pointed to the same 16 kHz PCM16 `one.wav` (one nonzero sample and 16,000 zero samples). With the required hashes and flags, `check_fixtures()` returned `wav_fixtures_verified=13`, `human_wavs=1`; there was **one unique path**. Require unique resolved paths and unique SHA-256 values across all declared WAV cases. Unique bytes still do not establish a human recording or intelligible speech.
3. **Absolute paths inside the fixture directory pass.** Replacing each prompt/schema/stub and WAV `path` with its absolute path under the manifest directory still returned `wav_fixtures_verified=13`. The current `(base / path).resolve().is_relative_to(base)` checks containment only. Enforce normalized relative paths with no absolute, `.`, or `..` segments, then resolved containment. This keeps the frozen manifest relocatable and consistent with the plan.
4. **Listening and independent ASR are self-attested booleans.** The synthetic WAV above contains no intelligible sentence but passes with `listened: true`, `independent_asr_checked: true`, and arbitrary nonempty transcript. Require separate listening and independent-ASR receipts tied to each final padded WAV SHA-256, including reviewer/source identity, ASR model/revision or service and settings, transcript, and assessment. Verify those receipt hashes before treating `ready` as fixture-ready. A human provenance receipt is additionally needed for any claimed human case; bytes and a `human_voice_id` cannot prove origin.
5. **Nano initialization files are a mandatory pin, despite the “optional text comparator” label.** The pinned [NeMo loader](https://github.com/NVIDIA-NeMo/Speech/blob/097dfe9e2f55baf653b83035868bdc89849f1b47/nemo/collections/speechlm2/models/duplex_stt_model.py#L227-L245) calls `load_pretrained_hf(self.cfg.pretrained_llm, pretrained_weights=self.cfg.pretrained_weights)` and `AutoTokenizer(self.cfg.pretrained_llm, use_fast=True)`. With VoiceChat's `pretrained_llm` set to Nano 9B v2, at least its architecture/config and tokenizer are runtime dependencies even if separate Nano weights are unnecessary. The plan pins a Nano revision for an optional comparator, but neither setup command nor preflight binds the loader to that snapshot or hashes the files it resolves. Stage and verify the exact required Nano config/tokenizer files, and ensure initialization resolves the pinned local snapshot; keep separate Nano weights optional unless a loader test proves they are required.

## Synthetic counterexample recipe and scope

With the reviewed script imported as `m`, create a temporary directory containing three hashed text files and one `one.wav` with `wave` settings `(channels=1, rate=16000, sample_width=2)` and frames `b'\x01\x00' + b'\x00\x00' * 16000`. Set manifest status `frozen_voicechat_dual_head_fixture`, TTS voices `v1,v2`, human voice `human`, human script IDs `[A]`, trailing silence `16000`, and all 13 expected case keys from `m.SCRIPT_IDS`. Give **every** WAV entry `path='one.wav'`, the same `m.sha256(one.wav)`, `transcript='speech'`, `listened=true`, `independent_asr_checked=true`. The observed call `m.check_fixtures(manifest)` passed with 13 cases and one unique WAV path. Replacing every relative artifact path with its resolved absolute path under the same directory also passed. These are source-only, synthetic counterexamples; they say nothing about VoiceChat model behavior.

**Re-review gate:** fix the five issues, add a negative self-test for duplicate WAV paths/hashes, absolute/unnormalized paths, dirty NeMo source, and absent QA/Nano receipts, then run `source` and `ready` against the final staged files. The official one-sample no-hook/passive-hook identity pilot still gates any assay result.
