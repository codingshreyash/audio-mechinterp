# VoiceChat 11B: pinned Nano 9B v2 metadata dependency

Scope: the `nvidia/NVIDIA-Nemotron-Nano-9B-v2` name embedded in [VoiceChat's pinned config](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-VoiceChat-11B/blob/443794ea956ef0065f001967ffd00e77f519cb39/config.json), loaded by [NeMo at `097dfe9e2f55baf653b83035868bdc89849f1b47`](https://github.com/NVIDIA-NeMo/Speech/tree/097dfe9e2f55baf653b83035868bdc89849f1b47). Nano revision: **`6533e8de2c68e4536bf7c411d7a3ce5734111476`**. This is a source and CPU metadata audit, not a successful VoiceChat model load or inference run.

## What the pinned loader actually requests

- VoiceChat constructs `DuplexSTTModel` and `DuplexEARTTS` in that order. The STT config names Nano as `pretrained_llm` with `pretrained_weights=false`; [STT construction](https://github.com/NVIDIA-NeMo/Speech/blob/097dfe9e2f55baf653b83035868bdc89849f1b47/nemo/collections/speechlm2/models/duplex_stt_model.py) passes this name to `load_pretrained_hf` and to NeMo `AutoTokenizer` with `use_fast=True`. [The loader](https://github.com/NVIDIA-NeMo/Speech/blob/097dfe9e2f55baf653b83035868bdc89849f1b47/nemo/collections/speechlm2/parts/pretrained.py) uses `AutoConfig.from_pretrained(..., trust_remote_code=True)` followed by `AutoModelForCausalLM.from_config(...)` when weights are false. The combined VoiceChat checkpoint subsequently supplies its learned weights. **The STT path does not require Nano's 9B weight shards.**
- [DuplexEARTTS](https://github.com/NVIDIA-NeMo/Speech/blob/097dfe9e2f55baf653b83035868bdc89849f1b47/nemo/collections/speechlm2/models/duplex_ear_tts.py) also loads a fast tokenizer by the same `pretrained_lm_name`. Its optional full Nano model load is conditional on `tts_config.context_hidden_size is not None`; the pinned VoiceChat config sets that value to `null`, so this branch is skipped. The `cas_config.pretrained_tokenizer_name` field is removed before construction in [RVQEARTTSModel](https://github.com/NVIDIA-NeMo/Speech/blob/097dfe9e2f55baf653b83035868bdc89849f1b47/nemo/collections/speechlm2/modules/ear_tts_model.py). These conclusions depend on the **exact pinned VoiceChat config** and source; changing either requires re-audit.
- STT chooses Nano-specific behavior using the case-sensitive test `'Nemotron' in self.cfg.pretrained_llm`. It sets BOS to `<s>`, EOS to `</s>`, and PAD to `<SPECIAL_12>`. Keep the **original repository ID string** in the config; a local-path substitution could change this branch and other name-based behavior. The [NeMo tokenizer wrapper](https://github.com/NVIDIA-NeMo/Speech/blob/097dfe9e2f55baf653b83035868bdc89849f1b47/nemo/collections/common/tokenizers/huggingface/auto_tokenizer.py) delegates to Hugging Face `AutoTokenizer.from_pretrained`.

## Offline pin without changing the model config

Use a dedicated Hugging Face cache. Fetch only the six recommended small files by **commit hash**, using `hf_hub_download(repo_id="nvidia/NVIDIA-Nemotron-Nano-9B-v2", filename=..., revision="6533e8de2c68e4536bf7c411d7a3ce5734111476", cache_dir="<dedicated-cache>/hub")`. Verify every byte against the table. Confirm that the cache snapshot is under `models--nvidia--NVIDIA-Nemotron-Nano-9B-v2/snapshots/6533e8de2c68e4536bf7c411d7a3ce5734111476/`; pin its `refs/main` file to that exact commit and verify it. This ref step is necessary because NeMo supplies the **name only**, with no `revision=` argument. Do not rely on a mutable network `main` reference.

Run the unmodified VoiceChat config with `HF_HOME=<dedicated-cache>`, `HF_HUB_OFFLINE=1`, and `TRANSFORMERS_OFFLINE=1`; keep `pretrained_llm` and `pretrained_lm_name` as `nvidia/NVIDIA-Nemotron-Nano-9B-v2`. Check offline `AutoConfig.from_pretrained(repo_id, trust_remote_code=True)` and `AutoTokenizer.from_pretrained(repo_id, use_fast=True)` before the large load. Record the cache ref, snapshot path, file hashes, package versions, and eventual full-load trace. This pins the bytes while preserving NeMo's name-dependent branches.

## Validation and limits

In an isolated local Transformers **4.56.0** / tokenizers **0.22.0** / huggingface-hub **0.34.4** environment, metadata-only `AutoConfig` and fast `AutoTokenizer` resolved offline by the unchanged repository ID from a cache whose `refs/main` pointed at the pinned commit. The config had hidden size 4480 and 56 layers; tokenizer length was 131,072, with BOS ID 1. After the STT overrides, EOS ID was 2 and PAD ID was 12. Removing `special_tokens_map.json` did not change these tested values; removing `tokenizer_config.json`, `config.json`, or `configuration_nemotron_h.py` broke its respective tokenizer/config path. The custom **model class was not instantiated**: this Mac lacks `mamba_ssm`, which [the pinned modeling source](https://huggingface.co/nvidia/NVIDIA-Nemotron-Nano-9B-v2/blob/6533e8de2c68e4536bf7c411d7a3ce5734111476/modeling_nemotron_h.py) imports. The full CUDA VoiceChat load must confirm that no additional dynamic imports or assets are needed. Other VoiceChat dependencies (ASR encoder, codec, combined checkpoint) are outside this Nano metadata audit.
