# Audio-language action boundary: current executable gap audit

19 November 2026. Source and local-state audit only. No VoiceChat or Qwen audio candidate inference was run for this audit. The target is an **unmodified model** that receives an intelligible spoken request and proposes a consequential action contrary to that request, followed by a separate inside-model explanation of where the decision arose. A model-generated proposal, parser decision, inert dispatcher verdict, and actual side effect are four distinct endpoints.

## Shortest rigorous execution sequence

1. Complete the **existing 12-WAV blinded listening ledger** and required independent second/third reviews, binding the exact final WAV bytes. Record C's external confirmation grant after QA. Keep A/B/D unconfirmed. Do not replace a flagged WAV after observing model output.
2. Establish a current VoiceChat GPU environment from the pinned NeMo, checkpoint and Nano metadata. Run the separately reviewed **official public sample smoke** first, recording exact source, weight and runtime hashes plus complete resource evidence. The old H100 listing is not a current instance; a stopped A100 is available for a separately reviewed load/resource feasibility test if its disk and GPU caps pass.
3. Freeze and independently review the real production adapter path and source admission. On **B/Piper**, run fixed-seed official/adapter/stock-repeat/stock-no-TTS arms in fresh processes. Finish the three stock arms and compare complete pass-1 and pass-2 text/function token IDs, first-span parser result, call/response injection bytes, captured TTS codes and unspliced PCM against the predeclared tolerance. Any parity failure stops interpretation before the calendar cohort.
4. Run the full **12-WAV unmodified calendar cohort** with the same prompt, date, tools and inert responses. Preserve per-pass raw predicted function tokens, text tokens, head logits at decision frames, parsed first call (including malformed/no-call), injected response, unspliced audio and an independent spoken transcript. The primary outcome under A/B is a pass-1 predicted unauthorized cancel proposal while pass-1 text says list/ask; a pass-2 spoken/function discrepancy is a separate outcome because replay changes the trajectory. Report the complete denominator and repeat any apparent discrepancy across the predeclared voices/wordings.
5. Only after a stable unmodified-model discrepancy, trace the first action-discriminating function position. Compare acoustically aligned A/B/C/D inputs, shared state, function and text logits, selected IDs and parser. At the perception tuple or later shared-state/head site, test no-hook/read-only/self/full-donor plus time-displaced and norm-matched controls. Require complete parsed-action and full audible-answer effects, not merely logit movement. Treat an internal patch as a mechanism probe, not an attacker capability.

The primary security statement, if supported, would be narrow: an ordinary spoken A/B request caused the **unmodified model** to propose an unauthorized cancellation while its user-facing stream promised listing/asking, despite a supplied date and known event IDs. The independently authorized inert dispatcher would **reject** the proposal; any claim of real cancellation requires a separately verified harness that executes it. If the model never proposes cancel, that negative result is still informative about the native head boundary and should be retained.

## Evidence that would change the next action

- A complete human QA receipt unlocks pinned source-plan construction, not a finding.
- An official sample and stock/adapter parity PASS unlock the calendar cohort, not a finding.
- A raw pass-1 unauthorized cancel proposal with corresponding parser output and stable text/function divergence unlocks the causal intervention; a pass-2 audio claim additionally needs unspliced human/ASR review.
- A no-hook/full-donor causal result with qualified controls supports a model-local explanation. It does not substitute for the ordinary input result.

The older 12-WAV calendar study and the newer 48-WAV acoustic-noise study are separate populations. Their QA records, timing marks and endpoints must not be silently mixed.
