# Voxtral Track B V6 pre-pilot admission and launcher source

**Source-only, live HOLD.** The [admission contract](voxtral_track_b_v6_pre_pilot_admission_contract_v1.py) and [launcher gate](voxtral_track_b_v6_pre_pilot_launcher_source_v1.py) express the acyclic freeze order: worker **W**, external admission **A** binding W and the other frozen artifacts, independent review **R** binding A, then a later launcher **L** pinning the exact W/A/R SHA-256 digests. A and R do not bind L; the worker does not embed A's hash. Neither new file issues an admission, loads a checkpoint, or provides a CLI. `FROZEN_PINS=None` makes the public launcher reject before a loader is called.

The prospective external A must have the worker's `voxtral_track_b_v6_external_pilot_admission_v1` schema and `pilot_go` status. It must bind the worker, study runner and pilot auditor source hashes; V3–V6+V6-GO protocol hashes; the separately audited 32/32 human QA audit, QA GO receipt and independent QA review hashes; the frozen no-weight preflight; model checkpoint tree and installed Transformers source; synthetic and old-FIT batches; exact maximum geometry and longest alias; and one `campaign_attempt_id` with a stable absolute `campaign_claim_path` outside any output directory. The external R has schema `voxtral_track_b_v6_pre_pilot_independent_review_v1`, decision `GO_for_pilot_only`, and must repeat exact A/W hashes and campaign identity. It requires independent provenance review beyond this schema check. The future launcher must pin W/A/R as constants in its own reviewed source and verify their bytes before any load.

`verify_pre_pilot` calls the actual `candidate_common.fixture_cases()` and `candidate_common.qa_gate()` to re-audit human exports, then reruns the frozen **no-weight** Track B preflight with the host probe enabled. It compares the preflight's stable source, installed Transformers, model snapshot, selected WAV, processor, and synthetic geometry fields with A's bound receipt. It checks fresh host collection time and the compressed/raw power-log hashes. The underlying preflight independently checks AC, lid, recent power events and bounded output; this launcher does not add an independent raw-log parser. A changed QA result, source or processor fingerprint, stale host observation, altered A/R bytes, or missing campaign binding is a HOLD. No result from this path is a measured pilot or post-pilot GO.

The private worker schedule exclusively creates the externally bound registry claim before an output directory, preventing a retry at a second output path under the same A. The registry parent must exist. Different admission/claim paths require separate external review; an unpinned or self-asserted A is not executable. The future launcher must verify the campaign registry and claim semantics before delegating to the worker.

## Blocking implementation before model load

- Obtain and independently review the real 32/32 QA GO, no-weight preflight, A and R. The supplied fake fixtures are tests only.
- Review a final launcher with frozen W/A/R hashes and an actual FP32/eval/MPS model loader and runtime fingerprint. The current public launcher never calls `worker._execute_after_admission`.
- Implement a process-level hard watchdog for model load and each call, a measured MPS driver high-water sampler, independent fresh host-log verification through the attempt, and a saved-data pilot auditor. The existing worker's post-call allocation check cannot prove the 30-GiB peak bound; its 240-second check cannot interrupt a hung call. Its `schedule_complete_resource_unverified` receipt cannot authorize Track B.
- Obtain independent post-pilot GO bound to the exact measured receipt and call ledger before the study runner starts.
