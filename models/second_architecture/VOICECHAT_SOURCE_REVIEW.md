# Independent source review: NemotronLabs VoiceChat-11B

**18 November 2026.** This reviews the VoiceChat claims in [SPEECH_BRANCH_MODEL_MAP_AND_ASSAY.md](SPEECH_BRANCH_MODEL_MAP_AND_ASSAY.md) against NVIDIA's published model card, checkpoint configuration, and the `nemotron-labs-voicechat` NeMo branch. It is a source audit, not a model run or a reproduced security finding.

## Finding that changes the assay

**VoiceChat does have a separate neural function head.** The pinned NeMo branch initializes `function_head = copy.deepcopy(self.lm_head)` when `use_function_head` is true, then applies both heads to the same LLM `last_hidden_state` to obtain `text_logits` and `function_logits`. The [released checkpoint configuration](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-VoiceChat-11B/blob/main/config.json) sets `model.stt.model.use_function_head: true` and `model.stt.model.duplex_function_channel_weight: 2.0`. Thus the memo's “may be a tagged text protocol rather than a separate head” is too skeptical for this named implementation. The separate head shares the text vocabulary and backbone; it is not an independent model or a proof of independent decisions. [NeMo head creation, source lines 295–311](https://github.com/NVIDIA-NeMo/Speech/blob/nemotron-labs-voicechat/nemo/collections/speechlm2/models/duplex_stt_model.py#L295-L311); [NeMo forward, lines 495–535](https://github.com/NVIDIA-NeMo/Speech/blob/nemotron-labs-voicechat/nemo/collections/speechlm2/models/duplex_stt_model.py#L495-L535).

The offline path provides distinct `tokens_text`, `tokens_function_pred` (predicted function tokens), `tokens_function` (including injected tool response in a replay), audio codec tokens, and decoded audio. Validation code decodes the predicted and replay function streams separately and extracts function-call positions against `tokens_text`. This is direct evidence for a model-level text/function branch to instrument. [VoiceChat branch source](https://github.com/NVIDIA-NeMo/Speech/blob/nemotron-labs-voicechat/nemo/collections/speechlm2/models/nemotron_voicechat.py#L2441-L2499).

## Exact offline boundary

1. The [function-call example](https://github.com/NVIDIA-NeMo/Speech/blob/nemotron-labs-voicechat/examples/speechlm2/offline_voicechat_fc_infer.py#L676-L766) supplies a WAV, text system prompt/tool schema, and **prewritten** `--api-response-json`. Its default prompt says a tool must be called for matching requests and that missing required arguments must be asked for. The [template](https://github.com/NVIDIA-NeMo/Speech/blob/nemotron-labs-voicechat/examples/speechlm2/function_calling/template.jinja#L25-L40) tells the model to format the function stream as `<TOOLCALL>[...]</TOOLCALL>`.
2. Pass 1 runs model inference with `decode_audio=False`, reads `tokens_function_pred` (falling back to `tokens_function`), extracts call positions, strips special tags, and uses `json.loads` to parse the generated script. The parser stores the original `call_text` as `raw`. **No live tool is executed here.** [Offline helper, lines 1177–1285](https://github.com/NVIDIA-NeMo/Speech/blob/nemotron-labs-voicechat/nemo/collections/speechlm2/inference/utils/offline_voicechat.py#L1177-L1285); [model card offline note](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-VoiceChat-11B#offline-inference).
3. The helper re-tokenizes the parsed call, serializes the supplied canned response as `<TOOL_RESPONSE>`, then **runs inference again** with call/response tokens injected at recorded steps. If no call was parsed, it still runs pass 2 to decode audio. The saved JSON contains parsed calls, `raw`, responses, and the pass-2 agent text. The saved agent waveform has the tool-call interval spliced out. Therefore a claimed spoken/tool mismatch from this script must specify **which pass** produced each observation and retain unspliced/raw intermediate outputs; the packaged WAV and JSON alone can obscure timing and branch changes. [Helper, lines 1288–1379](https://github.com/NVIDIA-NeMo/Speech/blob/nemotron-labs-voicechat/nemo/collections/speechlm2/inference/utils/offline_voicechat.py#L1288-L1379); [output writer, lines 1382–1493](https://github.com/NVIDIA-NeMo/Speech/blob/nemotron-labs-voicechat/nemo/collections/speechlm2/inference/utils/offline_voicechat.py#L1382-L1493).
4. The live [NeMo-Speech.cpp WebSocket API](https://github.com/NVIDIA/NeMo-Speech.cpp/blob/main/docs/api.md#voicechat-websocket-v1realtime-and-realtime) exposes `response.function_call_arguments.done` with `name` and JSON `arguments`, plus output audio/transcript events. These are **transport events**, not raw model predictions. The model card says an on-hold message can be spoken when a tool-triggering text is generated; an audible on-hold phrase must not automatically be treated as the full semantic commitment of the function head. [Model card architecture and on-hold description](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-VoiceChat-11B#model-overview).

## Constraints and correction requests

- **Correct the memo's VoiceChat row and final decision gate:** the released config enables a dedicated `function_head`; add it to the hook map, along with `tokens_function_pred` versus `tokens_function`. Pin the `nemotron-labs-voicechat` source branch rather than linking `main`, which may differ. Keep the distinction between the neural function head, its tagged-token serialization, the JSON parser, and the WebSocket event adapter.
- **Revise the VoiceChat assay:** record pass-1 input WAV/hash, system prompt/tool definitions, `text_logits`, `function_logits`, token IDs and decoded strings for both streams, function-call positions, parser input/output/errors, then pass-2 text/codec tokens, unspliced and saved audio, and canned-response injection. Compare the same pass or explicitly label cross-pass comparisons. An offline script result establishes a proposed call, not an executed action.
- **Limit claims:** NVIDIA describes this as 11B with FastConformer → Nano v2 9B → TTS/codec, OpenMDW 1.1, 16 kHz speech input, and a Linux/NVIDIA GPU reference stack; the repository download is about 44.4 GB and the card reports H100 test hardware. The [explainability note](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-VoiceChat-11B/blob/main/explainability.md) says the training speech is exclusively English and the model cannot handle non-English languages. This is suitable for an English branch-integrity assay, not a general multilingual replication. [Model card](https://huggingface.co/nvidia/NVIDIA-NemotronLabs-VoiceChat-11B).

**Assessment:** The memo's architectural and feasibility summary is substantially right, but the “head unproven” caveat is false for NVIDIA's published implementation/config. The more consequential experimental caveat is the official offline example's two-pass replay and post-processing: without pass-labelled raw traces, a polished output file can misattribute a difference to model internals.
