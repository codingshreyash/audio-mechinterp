# Whisper Tiny object-word causal replication — prospective v1

18 November 2026. **Design only; no model inference under this plan.** This is a separate follow-up to the completed `color_05` silver/teal FIT assay. That first assay's 12/12 word-window switches motivated this replication, and its reciprocal random arms reused four edit tensors across eight arms. This follow-up is prospective for a **new word pair**, not an independent preregistration of the earlier color result. Its purpose is to test whether the same encoder-window influence appears outside the color category and to repair the random-control independence issue. It is an ASR mechanism assay, not a security test.

## Fixed 52-decode matrix

For each voice and both directions (`plate` recipient ← `cup` donor, and the reverse), capture unedited log-mel features, the input to encoder block 0 after convolution/position/dropout, every post-block residual, and the final encoder `layer_norm` output. Save full state files or a lossless equivalent with SHA-256, plus per-time-position donor-minus-recipient L2 and maximum absolute differences. The first differing captured state is a numerical observation. Bidirectional attention may spread a word effect outside its acoustic interval.

Patch only donor rows in `W` at three fixed sites: the `encoder.layers[0]` forward **pre-hook**, the post-block-1 forward hook, and the post-`encoder.layer_norm` forward hook. Let the remaining stock computation and decoder run to a complete transcript. At each site and direction, run the equal-width donor `P` patch and a recipient self-patch in `W`. At the final normalized site also run a full-sequence donor patch and **two** random `W` edits with the same whole-window Frobenius norm as that direction's donor-minus-recipient edit. Counts are four unmodified baselines plus 36 site×(word, prefix, self) arms, four full-donor arms, and eight random arms = **52 decodes**. Every decoded output, including failed/censored controls, must be saved before a gate raises.

For independent reproducible random draws, fix base seeds `20261118` and `20261119`. For each of the eight random arms, form the UTF-8 string `whisper-object02-v1|{engine}|{recipient_word}|{donor_word}|{base_seed}`; derive `arm_seed = int.from_bytes(SHA256(string)[:8], "big") & ((1 << 63) - 1)`. Seed a **fresh** local CPU `torch.Generator` with `arm_seed`, draw a float32 standard-normal tensor of the selected `[1, |W|, 384]` shape, then normalize it to `||donor[:,W,:] - recipient[:,W,:]||_F`. Reject zero/nonfinite norms. Record base seed, arm seed, realized norm, target norm, and SHA-256 of the float32 edit bytes. Require all eight arm seeds **and** edit hashes to be distinct; the prior assay did not enforce this. These controls are still only eight matched-magnitude edits, not a distributional significance test.

## Outcome and gates

The primary outcome is an uncensored, EOS-terminated **complete-transcript target replacement**: recipient target absent, donor target exactly once, and every other normalized word identical to the recipient baseline. Report all four directions at each site. Separately report donor-word appearance with collateral changes, full normalized transcript match, WER, and token differences. Generation-processed first-token alias scores may be saved as a descriptive secondary, with the V3 clarification from the color assay: they are not raw logits or full-word probabilities and cannot rescue a failed primary outcome.

Self-patches must preserve the recipient's exact token IDs; full-donor final-state patches must preserve the donor's exact token IDs. Record hook counts and reject missing/multiple calls, shape/dtype/nonfinite errors, source drift, incomplete arm matrices, and more than 30 minutes or 4 GiB process RSS. Preserve all failed-attempt records. Before inference, freeze the runner, fake-model tests, independent source review, no-weight preflight, and an independent saved-result auditor. After inference, rerun the saved-data audit independently and bind all raw and sidecar hashes in a reviewable manifest. No data from corpus v2 or any locked test may be opened for this FIT follow-up.

## Source adaptation plan

Create a new runner module from the reviewed `whisper_fit_word_window_causal_v1.py`; do not mutate its frozen source or the completed color run. Replace its pair/word/slot/window pins with this plan's values and make the random generator consume the per-arm derived seed. Update fake tests so reciprocal directions produce distinct random edit hashes, and make the auditor recompute every derived seed and edit hash from the saved final states. Pin the new runner's own source commit and preflight receipt before the first model pass. The previous color result remains separately reported with its random-control deviation.

One new pair in the same two synthetic voices cannot establish broad generalization, natural-speech performance, multilingual behavior, or an agent security property. A positive result would support transfer of this **local ASR causal assay** across lexical categories; it would not identify a unique circuit or show an attacker-controlled end-to-end failure.
