These are source observations, not verified live host behavior.

Three gaps prevent an execution GO:

1. **Deadline success can be late.** `run_bounded` returns `timed_out=False` whenever `process.wait()` returns without `TimeoutExpired`, even if its final elapsed time exceeds 1,800 seconds. `execute` never rejects `worker_elapsed_seconds > 1800`. The committed read-only [fake reproduction](review_acoustic_fit_noise_parent_hold_repro_v1.py) forces a zero-exit return at 1,801 seconds and obtains `(returncode=0, timed_out=False, elapsed=1801.0)`. Require finite elapsed `0 < t <= 1800` in both process result and final audit, while retaining kill/reap failure evidence. A process-group descendant check would strengthen termination evidence; current fake timeout test exercises only a direct sleeper.
2. **The saved worker matrix is not audited as claimed.** `valid_worker_rows` admits 22 rows with valid case/arm/PCM identities but no complete output, internal metrics, clean-repeat parity, preflight/review binding or EOS/censor status. The same reproduction returns `True` for this forged 20-case matrix. Require model-specific complete-output fields and exact clean-repeat output plus state-hash parity, expected stage keys, finite metrics, start receipt/review hashes, strictly ordered rows, and a complete final row. Keep failures or missing arms as invalid.
3. **Result/evidence binding is absent.** `launch_result.json` records neither the SHA-256/byte count of `worker_output/records.jsonl` nor the pre/post host JSON and compressed raw-log sidecars. An edited or re-pinned saved worker/host file would not be detectable from the launch result. Pin these files and source/review/attempt identity in a read-only saved-data audit. The launcher GO check also fails to require its review commit to differ from and descend from the worker GO commit; as written, both GO files can be added in one commit. Preserve the two-stage independent review order.

The fake repro only shows acceptance under controlled mocks; it does not allege a live false result. The existing parent public path must remain unused for candidate weights. Correct these source gates, add adversarial regressions and obtain a new independent review and separately committed GO receipts before launching either ASR model. This FIT-only pilot remains descriptive even if it later runs cleanly.
