# VoiceChat public-sample H200 amendment V5

19 November 2026. This prospective source amendment adds one GPU policy, `h200-141gb`, to the public-sample-only environment smoke. It preserves the pinned public WAV and response JSON, official example command, checkpoint and package pins, native FFmpeg receipt, ready/preload checks, offline gate, review signature, evidence cap and wall-time cap. It does not admit a calendar fixture, alter the shared fixture preflight, or authorize model inference. Earlier A100 freeze and attempt records remain immutable.

The H200 policy requires Python 3.12, every shared preflight package pin, the exact checkpoint size and SHA-256, exactly one GPU whose reported name contains `H200` and whose total memory is at least 130,000 MiB, and at least **30 GiB (32,212,254,720 bytes) of actual free disk after checkpoint staging**. It performs the same runtime check in both ready and preload phases, so a pre-stage projection alone cannot pass. The reviewed executable freeze can choose a VRAM cap no greater than 130,000 MiB for this policy; H100 and A100 retain their 75,000 MiB maximum and the unchanged shared preflight's 60 GiB disk gate. The runtime inventory, selected policy and cap are freeze bound. The sample's process-tree memory telemetry enforces the reviewed cap with the existing sampling limitation.

The delivered H200 root disk reports 123,690,532,864 bytes total and 100,431,302,656 bytes free before staging; there is no second disk. The measured A100 component sizes used for a staging projection are: checkpoint 44,382,749,892 bytes, venv 12,439,787,625, NeMo 273,116,132, Nano cache 34,717,302, and FFmpeg prefix 747,788,803. These sum to 57,878,159,754 bytes, leaving a projected 42,553,142,902 bytes free on the delivered H200 root. The 30 GiB gate leaves a projected 10,340,888,182 bytes above the floor for transfer overhead, package cache and capped evidence. This projection assumes the checkpoint blob is staged **once** and the runner points to that copy; no second checkpoint blob is part of the plan. The actual post-stage free-byte check remains decisive and fails closed below the floor.

The shared `voicechat_h100_local_preflight.py` remains byte-for-byte unchanged. This H200 check lives in the public-sample runner so the existing fixture's H100/A100 policy is unaffected. An independent source review and new executable freeze review must cover this amendment before a live H200 attempt. An H200 run cannot reuse the earlier A100 freeze or its review.
