# Independent design review: VoiceChat H200 step-400 diagnostic V2

19 November 2026. **PASS for source-only design; HOLD executable and GPU inference.** I reviewed the V1 protocol at commit `4b20dc2` and its pre-inference V2 amendment at commit `670fe76`. Their current SHA-256s are `530aedfd72265f94e047546533be30a3414b927ec22a94f604e30ccab45ea107` and `b1a621ef8eea0a68ed277e095f6d5bbd07694648ae9b7d93f79a5f51640a0b91`. This review supersedes the two measurement objections in the [V1 HOLD](VOICECHAT_H200_STEP400_MEMORY_DIAGNOSTIC_INDEPENDENT_DESIGN_REVIEW_HOLD_V1.md); it does not sign a wrapper, environment freeze, or one-shot launch.

The pinned [model loop](https://github.com/NVIDIA-NeMo/Speech/blob/097dfe9e2f55baf653b83035868bdc89849f1b47/nemo/collections/speechlm2/models/nemotron_voicechat.py#L671-L729) confirms STT then TTS in `range(1,T)` and a post-TTS/pre-`gen_codes` observation point. The pinned [function-call helper](https://github.com/NVIDIA-NeMo/Speech/blob/097dfe9e2f55baf653b83035868bdc89849f1b47/nemo/collections/speechlm2/inference/utils/offline_voicechat.py#L171-L289) only parses and starts a second pass after first-pass inference returns; a reviewed dedicated stop at `t=400` can prevent that return. V1 fixes the same public WAV, response fixture, checkpoint, source and first-pass arguments as the prior H200 attempt, the six observation steps, the 130,000-MiB cap, bounded wall/disk/evidence use, and independent watchdog. A premature stop remains a failure, not a truncated behavior result.

V2 now captures a pre-`t=1` live-memory baseline **after** checkpoint and TTS warmup, resets CUDA peak counters before the first generation forward, and records reset/snapshot times. That makes the first peak a defined generation interval rather than an accidental preload-inclusive peak. V2 also requires unique-storage accounting over the union of STT inference state and returned TTS cache, with cross-family sharing counted once and unknown containers explicitly marked incomplete. It prohibits storage identifiers in output and requires a fake-cache alias test. The saved auditor must reconstruct interval order, storage arithmetic and actual parent NVML sampling gaps. These provisions address the V1 HOLD without changing the input or allowed model behavior.

**Implementation gates remain:** independently review a wrapper and no-model tests for original-call identity/count, exact first-pass preparation, `T=859`, no second pass, `t=400` exception handling, transient-reference release, cache traversal limits, NVML PID coverage and process-group termination. Freeze the exact runtime, staged files, output ID, caps and ignored-file inventory, then obtain a separate independent host review and one-shot GO. No executable or new host freeze was reviewed here, no H200 was started, and no model weights or outputs were opened. A completed trace would distinguish memory-accounting patterns only; it would not diagnose a leak by itself or establish a security finding.
