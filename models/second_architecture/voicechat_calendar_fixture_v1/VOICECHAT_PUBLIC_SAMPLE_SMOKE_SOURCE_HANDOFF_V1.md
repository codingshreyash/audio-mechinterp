# VoiceChat public-sample smoke source handoff

19 November 2026. `public_sample_smoke_v1.py` implements the separate public-sample-only path in amendment `91a6d83` and conceptual review `cf399b0`. It is a source candidate awaiting independent source review and an externally reviewed executable freeze. **No VoiceChat weights, GPU, Brev host, public sample, or calendar fixture were run while developing it.** The no-model tests inject fake preflight checks and an executor. They do not create a real freeze or authorize model use.

The production CLI has no dependency-injection switch. It requires an externally keyed freeze review binding the exact freeze bytes and independent source-review hash. The source reviewer must separately create a JSON record with schema `voicechat_public_sample_source_review_v1`, decision `GO`, the exact six-role `source_sha256` map, reviewer ID and UTC review time. The freeze binds that record, an explicit run ID equal to the output directory name, this runner, tests, handoff, shared preflight, amendment, conceptual review, absolute paths, exact four-argument official command, pinned NeMo/source/sample/checkpoint/Nano identities, an explicit allowlist of child environment variables and its hash, and finite caps. The HMAC review key and calendar controller key are removed from the parent environment before preflight and never enter the model child. The runner reserves a new exclusive output directory before its `ready` then `preload` checks, so a failed attempt consumes the run ID. Both phases reuse the shared pinned source, checkpoint, Nano, package, GPU and disk checks; they add the exact public WAV and response hashes and the exact Nano `refs/main` bytes, and omit only calendar QA, controller grants and anchor. The official script process starts only after those checks, the offline environment check, and another frozen-source/environment comparison. It receives no calendar tool, WAV, stub, adapter or dispatcher.

The launcher streams stdout/stderr into bounded evidence, samples process-tree GPU memory with `nvidia-smi`, checks wall time and aggregate output, and terminates its process group on a detected breach. The minimum reviewed total cap is 64 KiB. It reserves at least one quarter of a small cap, up to 1 MiB, for terminal receipts. Aggregate output growth and VRAM peaks are **sampled**, so a worker can temporarily exceed a cap between polls. After a failure it records the observed bytes, truncates raw artifacts to fit the retained evidence cap, and records each original size/hash (or an explicit unavailable hash above the 1 GiB read ceiling) and retained size/hash. This is **partial preservation**, not a hard live-write quota. A final manifest hashes every retained prior file including `result.json` or `failure.json`; `final_manifest.sha256` is an independently checkable digest of that manifest. The digest file cannot recursively hash itself. Successful output is labeled only `environment_smoke_only`; failures are `failed_or_incomplete_environment_smoke`. An abnormal telemetry error kills the process group and follows the same failure seal. Independent source review must assess these exact cap semantics before a live freeze. A future controller must protect the review HMAC key and attest the reviewer; a caller-supplied key alone is not proof of independence.

The existing fixture protocol is untouched. An early sample smoke cannot replace independently authenticated 12/12 human listening QA, adjudications, both C grants, external anchor, fixture-specific ready/preload, fixture worker review or fixture executable freeze. The sample output proves no calendar parity, model mechanism, or security finding.
