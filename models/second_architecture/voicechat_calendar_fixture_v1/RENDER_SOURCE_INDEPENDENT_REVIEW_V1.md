# Independent source review: VoiceChat synthetic renderer

**18 November 2026. No-go for the first render until the Apple voice path is bound.** I reviewed renderer `dc5f3e1` (source SHA-256 `27efe9d3498960475be04f6f4a8bdec942de74913d472dd8fd5e0e36768fda26`) against the frozen six-script fixture, audio recipe, Piper assets, and trailing-silence helper. I ran bytecode compilation and `checked_inputs()` only; both passed. I also exercised conversion and padding on a temporary synthetic sine wave. No TTS model, ASR, or VoiceChat inference was run.

The planned matrix is exactly **six case IDs × two voices = 12** recordings. Script/recipe/padding/Piper executable/model/config hashes match their pinned values. Piper receives one ASCII script through stdin and one explicit `--output_file`; its installed CLI reads stdin when no `--input-file` is given and derives the config path as `model.onnx.json`, matching the checked file. Apple `say` receives one script, explicit Samantha voice, and one AIFF output path. Samantha currently appears in the local voice list as `Samantha en_US`. The absolute Piper paths and `/usr/bin/say` make the renderer intentionally local to this Mac.

The conversion path rejects non-mono, too-short, silent, nonfinite, overlong, or excessive-peak audio. It uses rational `resample_poly` conversion to 16 kHz, targets −20 dBFS RMS with a 0.95 peak cap, writes PCM16, then calls the reviewed helper, which removes only exact terminal zero samples and appends **80,000** zero-valued frames. A synthetic 22.05-kHz input produced 16,000 converted frames and a 96,000-frame final WAV whose final 80,000 samples were exactly zero and whose preceding sample was nonzero. The fresh output directory is exclusive; a full render manifest is written only after all 12 rows finish. A caught mid-render failure writes `error.json` and leaves no complete manifest.

**Blocker:** `/usr/bin/say` is executed but its binary SHA-256 is not pinned or checked, and the actual Samantha voice identity/availability is not recorded in the run metadata. The local `say` binary currently hashes to `b9f92936d6bb411e891f4136ae714b85a8876585ba449ea3c8d5e557765ebe8f`. Before rendering, pin/check this executable and record the selected voice and a read-only installed-voice identifier in the start metadata. Apple voice assets may still change without the executable changing; preserve the raw AIFF and final WAV hashes and state that limitation. A successful render cannot establish human intelligibility.

Two smaller source improvements would make failures easier to audit: record or pin the exact NumPy/SciPy/SoundFile runtime versions before conversion, and include the current case/voice plus captured subprocess stderr in an error receipt if a child command fails. The current preflight and initial metadata write occur before the `try`, so failures there do not get an `error.json`; they remain fail closed because no complete render manifest exists. After the blocker is fixed and independently checked, the 12 WAVs still need the separate ASR and human listening receipt before fixture inference.
