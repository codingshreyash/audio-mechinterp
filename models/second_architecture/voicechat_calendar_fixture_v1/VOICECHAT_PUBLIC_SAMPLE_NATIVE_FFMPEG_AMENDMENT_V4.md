# VoiceChat public-sample native FFmpeg amendment V4

19 November 2026. This source amendment applies only to a new public-sample environment smoke. It does not change the calendar fixture, the model card package pins, earlier source GO decisions, earlier executable freezes, or prior attempt output. No model inference is authorized by this document.

The sample runner requires an isolated FFmpeg 7 Conda prefix on Linux x86_64. The first `LD_LIBRARY_PATH` component is the absolute, resolved `<task-prefix>/lib`; the prefix basename begins `voicechat-sample-`. Every other component is absolute and the full string is freeze bound. The runner reads `<task-prefix>/native-source-manifest.json` with exact schema `voicechat_native_source_manifest_v1`, `kind=conda_explicit`, `ffmpeg_major=7`, and an `explicit_spec` object containing only `path=conda-explicit.txt`, its SHA-256 and byte count. The explicit spec has exactly one `@EXPLICIT` header and every package line is an official `https://conda.anaconda.org/conda-forge/` URL under `linux-64` or `noarch` with a 32- or 64-hex package digest (a bare MD5, bare SHA-256, or `sha256=<digest>` fragment). The manifest also contains one `package_archives` object per explicit URL with exactly `path=package-archives/<URL-decoded archive filename>`, SHA-256 and byte count. URL decoding covers Conda filenames such as `x264-1%21164...conda`, installed as `x264-1!164...conda`. The runner hashes each preserved archive, compares the URL digest with that archive, and requires the corresponding installed `conda-meta/<decoded archive stem>.json` SHA-256, URL, `fn`, name, version, build and `conda-forge` channel to agree. The installed metadata directory must contain exactly one JSON per explicit package plus optional `history`. It also hashes the manifest, spec, and every regular file under `conda-meta`. Missing, linked, nonregular, or changed source evidence stops admission.

The runner recursively enumerates every directory entry under the isolated `lib` tree without following directory links. It hashes every regular file and records every link text and resolved target in a sorted tree digest; it rejects dangling, cyclic or escaping links and unexpected file types. It also enumerates each top-level shared library filename, records every alias and resolved target, and hashes each unique regular target. It requires FFmpeg 7 SONAMEs `libavutil.so.59`, `libavcodec.so.61`, `libavformat.so.61`, `libswresample.so.5`, and `libswscale.so.8`; known FFmpeg libraries with another major are rejected. It separately hashes the installed `torchcodec/libtorchcodec_core7.so`, requires that file to be a regular unlinked file inside the active Python prefix, and includes the pinned public WAV SHA-256. The runtime receipt includes the platform, distribution identity, prefix, full `LD_LIBRARY_PATH`, source package evidence, recursive lib-tree digest/counts, shared library targets and aliases, TorchCodec core, and public WAV.

`expected_freeze_fields` recomputes this receipt when the new executable freeze is built, before a run reserves an output directory, and after preflight immediately before starting the child. A changed byte or path rejects the freeze or records a failed consumed attempt. The scope evidence stores the receipt for audit. The existing Python package inventory and pinned preflight also apply. An independent reviewer must assess the source and create a new source GO and a new executable freeze review before a live attempt.

The receipt proves checked bytes and paths at those inspection points. It does not prove package provenance from the URL strings, lock files against concurrent writes, or guarantee that the dynamic linker loaded exactly the inspected files. A live source review should inspect the complete Conda export, preserved archives and startup link map independently.
