The runner's `expected_freeze_fields` now calls `sys.executable -m pip freeze --all` and stores a SHA-256 digest of its sorted, nonempty output lines, with one final LF, plus the line count. It checks exact installed versions of NumPy `1.26.4`, PyArrow `25.0.1`, and Datasets `5.0.1`. It records the installed versions or explicit absence of Mamba's declared `tilelang`, `apache-tvm-ffi`, and `quack-kernels` dependencies, and rejects an installed version outside `==0.1.8`, `<=0.1.9`, and `>=0.3.4`, respectively. The eleven previously pinned model-card packages are still checked by the shared preflight. The full installed-environment receipt is part of the signed freeze's exact `expected` object and is recomputed both at run entry and after ready/preload, before the official process starts.

This receipt binds distribution names, versions, and editable locators reported by pip. It does **not** prove the wheel bytes, native shared-library bytes, driver, or ABI are unchanged. Independent executable review still needs the raw `pip freeze --all`, the changed PyArrow wheel hash, `pip check`, the import-only smoke, and a decision about any missing Mamba dependencies. A `null` dependency version records absence; it does not authorize an exception. The [PyArrow repair plan](VOICECHAT_PYARROW_NUMPY_DEPENDENCY_REPAIR_PLAN_20261119.md) requires the host import smoke and dependency decision before model execution.
