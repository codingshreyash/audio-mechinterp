The sample GO does **not** admit the calendar cohort, stock/adapter parity, or a security claim.

**Execution notes:** The packet assumes Python 3.12 can be obtained on the selected host and that its pinned CUDA packages install successfully; neither is established by a CLI dry run. Set `PYTHONDONTWRITEBYTECODE=1` before installing or importing from the NeMo checkout where possible, since the preflight rejects ignored importable cache files. The runner's VRAM measurement is sampled, and its retained-evidence limit is not a guarantee that transient bytes never exceed the cap between polls. The actual host, source tree, package set, checkpoint hash, Nano cache, disk free space, freeze, HMAC review, and final saved result each need their own verified receipts before the packet can advance beyond source-only PASS.
