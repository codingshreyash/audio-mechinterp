The opaque ID incorporates case and voice but is logged *after* transcription, not passed to either processor or model. `load_v2()` verifies the inherited `asr_screen_v2.py` SHA before import. Its `check_model_pins()` checks Python/library versions, Transformers implementation hashes, exact cached model revisions and file hashes, and uses `local_files_only=True`. `transcribe()` uses greedy Whisper and CTC decoding on CPU and receives only the waveform.
- `--run` fails before creating an output directory unless `ASR_QA_FREEZE_V1.json` binds the actual runner SHA and all five pinned source hashes with the specified status. Each model run uses its own new directory; raw JSONL rows have only allowed audio IDs/hashes, transcript, token IDs, and decoder metadata, and are flushed and `fsync`ed one by one. `verify_raw()` requires all 12 rows in the original order. `--compare-only` requires both completed, provenance-matching runs and rejects an error receipt before joining frozen references. Its counts retain denominators 12 per ASR and 24 in total.
- Normalization is implemented as Unicode NFKC, `casefold`, replacement of every **nonalphanumeric** character by a space, then whitespace splitting. For these six English scripts this gives the declared punctuation/space treatment, including `twenty-six` becoming `twenty six`. Word errors are Levenshtein distance over the normalized word lists; `full_script_match` means zero word errors. The implementation is slightly broader than the prose phrase “punctuation to spaces” for non-English combining marks/symbols, irrelevant to these frozen English scripts.

## Narrow limits to preserve in the run record

The freeze receipt is a manually created review gate, not a cryptographic reviewer signature. The script checks its values, but cannot prove who wrote it. The prose asks for Whisper then Wav2Vec2 serially; each CLI invocation runs one CPU model, but the code does not prevent an operator from launching two processes concurrently. Follow the declared order and preserve both raw directories before comparison. Caught failures **after** `meta.json` creation get an `error.json` and any already flushed raw rows; a hard kill or failure creating the initial metadata can leave a partial directory without an error receipt. No such directory has `complete.json`, and `--compare-only` will reject it. Read an absent completion receipt as incomplete, regardless of whether an error receipt exists.

This screen is descriptive. Even two matching ASR transcripts do not independently prove the human heard the exact date, title, or C confirmation phrase, or that VoiceChat understood the audio. Perform the planned blinded listening QA before any VoiceChat inference.
