# Independent VoiceChat saved-capture codec rereview: GO

19 November 2026. **Decision: GO for the corrected source-only saved-capture codec; HOLD for live VoiceChat use.** I rereviewed fix commit `373cc4b` against the preserved [V1 HOLD](VOICECHAT_SAVED_CAPTURE_INDEPENDENT_SOURCE_REVIEW_HOLD_V1.md) and the [codec handoff](VOICECHAT_SAVED_CAPTURE_SOURCE_HANDOFF_V1.md). This review loaded no VoiceChat weights, ran no model inference, and created no human/controller records.

The HOLD reproduction is closed. `_validate_directory()` now rejects a symlink at the capture root even when `trusted_root` is omitted. With a supplied trusted evidence root it checks lexical containment and every path component from that root down to the capture directory, rejecting a linked parent before enumerating artifacts. I independently saved and loaded an ordinary nested directory under a trusted root, then confirmed that a direct root symlink and a linked parent both raise `ValueError`. The caller must supply its reviewed run root as `trusted_root`; ancestors above that boundary and concurrent hostile filesystem mutation are outside this codec's guarantee.

All **7/7 no-model tests** pass in the project virtualenv. `py_compile` and `git diff --check 373cc4b^ 373cc4b` pass. Beyond the suite, I changed one byte of a tensor file without changing its size and confirmed a tensor-hash rejection; after restoring it, I changed the declared tensor shape while binding a fresh manifest hash and confirmed a shape-metadata rejection. The codec still records exact tensor shape/dtype/SHA-256, checks aggregate and per-file byte caps before reads, rejects extra files and linked children, preserves tuple/list and dictionary order, and uses `np.save`/`np.load` with `allow_pickle=False`. Its bfloat16 path retains the exact 16-bit representation. The saved-data comparator test loads an on-disk capture after its original in-memory audio has changed, so it tests the saved-byte boundary rather than the mutable object.
