# VoiceChat step-400 external freeze/launcher source handoff

19 November 2026. **Source-only candidate; executable HOLD.** This is a fresh
one-attempt admission path for the diagnostic public sample. It was developed
and tested without model import, weight loading, a GPU, or Brev changes. The
previous H200 public-sample freeze/review is consumed and cannot sign this
experiment.

`voicechat_step400_freeze_launcher_v1.py` has two explicit modes. `build`
requires a new attempt ID and absent freeze/review files. It invokes the
existing V5 H200 source, checkpoint, package, native FFmpeg, Nano-cache,
offline-resolution, and actual disk/GPU checks. It freezes the five local
diagnostic source files and five matching tests, project commit, pinned NeMo source, public WAV,
response JSON, VoiceChat checkpoint, Nano metadata, command, environment,
resource caps, build-time ready/preload receipts, and an independently derived
expected worker identity. The worker identity's prompt hashes are calculated
from the pinned official example's literal defaults and rendered template
without importing the model. The unsigned freeze is written outside the
unused attempt directory and is bounded to 256 KiB. Build mode rejects an
inherited `VOICECHAT_STEP400_REVIEW_KEY_HEX` before the V5 pip and Nano
preflight subprocesses can start.

`launch` requires a separate, canonical external review record with an HMAC
over that exact freeze, source digest, reviewer ID, and timestamp. The review
key must be supplied in `VOICECHAT_STEP400_REVIEW_KEY_HEX` to the **parent
only**; the launcher removes it from its process environment before any
preflight subprocess and excludes it from the model child's environment.
Before the
child, the launcher recomputes the frozen source/host identity and checks the
generated Nano modules and offline preload identity. It then passes the
frozen argv and environment to `supervise_candidate`. The fixed Python
bootstrap removes the child CWD from `sys.path` and seeds exact project
package paths after the pinned NeMo-only `PYTHONPATH`; the worker runs with
`-B` to prevent generated bytecode. The project-source check rejects newly
added package initializers and local bytecode before this bootstrap runs.
After all checks, the launcher atomically writes and fsyncs a consumed-GO
claim next to the attempt directory before it starts the bounded parent.
The claim survives a missing or removed attempt directory. Same-UID actors
who can delete that external claim remain outside this source-only guarantee.

The twelve no-model tests check exact command shape and package origin,
untracked initializer rejection, freeze-specific signature, unsigned build,
build-mode key rejection in both API and CLI paths, missing-review denial before host/child, valid-review handoff and replay
denial, preflight key removal, and duplicate/noncanonical/changed JSON denial:

```sh
models/second_architecture/.venv/bin/python -B -W error::ResourceWarning \
  -m unittest models.second_architecture.voicechat_calendar_fixture_v1.test_voicechat_step400_freeze_launcher_v1 -q
```
