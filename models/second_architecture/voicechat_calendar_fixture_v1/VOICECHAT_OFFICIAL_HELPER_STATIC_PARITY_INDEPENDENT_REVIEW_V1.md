# Independent review: VoiceChat official-helper static parity

18 November 2026. **GO for the narrow, offline source-level check in commit `94fe430`; HOLD on live adapter/model parity.** No VoiceChat checkpoint, calendar tool, or generated waveform was used in this review.

I independently downloaded NVIDIA NeMo Speech's `offline_voicechat.py` at revision `097dfe9e2f55baf653b83035868bdc89849f1b47` and compared it byte for byte with `vendor/offline_voicechat_097dfe9.py`: both are 14,183 bytes, SHA-256 `ebde701baec12a014443eac36262a6af7a7a62b3e052f1c4a387db6aaad8da44`. The retained Apache-2.0 header is present. The test hashes those bytes before extracting the single undecorated `run_fc_offline_inference` AST function. Extraction removes imports and other helper functions but does not rewrite this function's body. Its fake `run_offline_inference`, tokenizer, position extractor, and tensor builder make the parser and replay arguments inspectable without NeMo or CUDA.

I ran `python3 -m unittest models.second_architecture.voicechat_calendar_fixture_v1.test_official_helper_static_parity_v1 -v`: **4/4 pass**. The synthetic cases cover a valid first call plus a later call, an array of two parsed items with one response, malformed first call with a later valid call, and no call. The official helper's first-call selection, response wrapper/step, and injection tensor shapes agree with the expected values derived from the adapter's `_clean_call_text` and `_stock_first_parse` and the fixture dispatcher. The official helper still records a canned response for malformed/no-call cases even though pass 2 gets no function injection; the adapter's empty `replay` field in those cases is a trace-schema difference.

**Scope limit:** The test does not call the adapter's `run_two_pass`; it feeds its parser's expected values into comparisons against a fake official run. Therefore it verifies these four source-level parser/replay examples, not full adapter equivalence. It does not test prompt rendering, WAV loading, exact model inputs, stochastic generation, raw function-head outputs, TTS codec IDs, unspliced or spliced waveform, model/checkpoint identity, or the v2 human-QA gate. An exact live stock-versus-stock and stock-versus-adapter comparison on the same QA-approved WAV remains required before a calendar output can be treated as native model evidence. A prewritten response in NVIDIA's example is not a live tool execution.

The pending live protocol in `VOICECHAT_OFFICIAL_HELPER_STATIC_PARITY_V1.md` is an appropriate next gate: first validate the published sample, then compare fixed prompt/input/model settings and pass-labelled raw results, injected tokens and unspliced audio, with stock-repeat variation measured. This review authorizes no model inference or security claim.
