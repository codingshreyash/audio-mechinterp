It has no production CLI, NeMo import, checkpoint load, calendar call or external network path. It has not produced VoiceChat output, human listening records, controller grants or an anchor. It deliberately rejects a real `source_plan_only_no_model_work` plan; the current source cannot authorize fixture inference.

The implemented slice checks the fixed case B/Piper selection, five-stage order, seed, bound input-hash map and fixed `1e-4` comparison contract before creating an exclusive run directory. It rechecks the supplied hash snapshot before each injected fake worker and before comparison. It creates each arm directory before work, consumes it after failure, requires distinct reported process IDs and matching seed/checkpoint/WAV/prompt provenance, checks per-arm wall time and reported VRAM/output caps, and hashes required raw artifact files. Adapter discovery alone selects the response bytes using `fixed_response_bytes`; the no-call branch writes its exact pinned placeholder. Every stock arm must use the same immutable response hash and the expected injection-field presence. The final call wires the three stock captures and adapter capture to `compare_stock_adapter` at the predeclared tolerance. All output is labelled `synthetic_test_only_no_model_work`.

The related plan-builder and old-HOLD regressions pass too: **26/26**. `py_compile` and `git diff --check` pass. Tests use only temporary synthetic dictionaries/bytes and create no human or anchor records.
