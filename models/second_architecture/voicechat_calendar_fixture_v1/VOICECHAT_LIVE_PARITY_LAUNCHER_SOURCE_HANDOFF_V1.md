# VoiceChat parity launcher source handoff: bounded synthetic slice

18 November 2026. `live_parity_launcher_v1.py` is a **synthetic-only arm supervisor** under the [prospective live parity protocol](VOICECHAT_LIVE_PARITY_ORCHESTRATOR_PROSPECTIVE_V1.md) and the [approved source plan](VOICECHAT_LIVE_PARITY_SOURCE_PLAN_INDEPENDENT_REREVIEW_V2.md). It has no production CLI, NeMo import, checkpoint load, calendar call or external network path. It has not produced VoiceChat output, human listening records, controller grants or an anchor. It deliberately rejects a real `source_plan_only_no_model_work` plan; the current source cannot authorize fixture inference.

The implemented slice checks the fixed case B/Piper selection, five-stage order, seed, bound input-hash map and fixed `1e-4` comparison contract before creating an exclusive run directory. It rechecks the supplied hash snapshot before each injected fake worker and before comparison. It snapshots all cap values before any worker can mutate the caller's dictionary, creates each arm directory before work, consumes it after failure, requires distinct reported process IDs and matching seed/checkpoint/WAV/prompt provenance, and checks per-arm wall time and reported VRAM/output caps. A separate **total evidence cap** includes the source plan, scope, response, arm artifacts/receipts and comparison. Plan, response and comparison bytes are checked before writing; artifact size is checked with `stat` before streaming its hash. Every later response digest is stat-checked against the total budget before a bounded streaming read, including the stock precheck and final comparison. If a worker exhausts the total cap, its partial arm directory remains consumed even when there is no room for a failure marker. Adapter discovery alone selects the response bytes using `fixed_response_bytes`; the no-call branch writes its exact pinned placeholder. Every stock arm must use the same immutable response hash and the expected injection-field presence. The final call wires the three stock captures and adapter capture to `compare_stock_adapter` at the predeclared tolerance. All output is labelled `synthetic_test_only_no_model_work`.

Twenty-one fake-worker tests pass, including input mutation (also through a shared in-memory plan object), missing raw/pass capture, partial replay, no-call injection, parsed-call response bytes, response tampering, process/seed/prompt mismatch, mutable output/time/VRAM caps, 100-KB response mutations at each of three later read sites, total and per-arm output caps, stock instability, consumed run ID, 20-KB response with an 8,192-byte total cap, oversized plan/comparison, cumulative small-file output, and an artifact rejected before content read. The related plan-builder and old-HOLD regressions pass too: **36/36**. `py_compile` and `git diff --check` pass. Tests use only temporary synthetic dictionaries/bytes and create no human or anchor records.

**Still required before live use:** a production launcher must independently revalidate the real 12/12 QA manifest, case-B receipt, C grants and external-anchor authenticity before any NeMo import; rerun pinned `ready` then `preload` and check exact source/checkpoint/Nano/sample hashes immediately before each fresh process; bind a separately reviewed external executable freeze with fixed caps and source/test/review hashes; run and archive the unchanged official sample; implement genuine fresh checkpoint-loading adapter and three stock workers with the pinned helper and inert calendar stub; monitor actual GPU memory and process resources; save lossless raw tensors/codes/PCM and command stdout/stderr so the comparator reads independently hashed artifacts rather than worker-supplied in-memory objects; and obtain independent source, freeze and saved-result reviews. Report no-call or unstable stock repeat without changing the selected WAV or response. The current synthetic supervisor's reported PID/VRAM and arbitrary `.bin` files are test contracts, not proof of real process isolation or model provenance.
