# Independent review: VoiceChat audio QA v2 proposal `86966a7`

**Verdict: sound direction, two protocol blockers before implementation/freeze.** This is a review of proposal text only, with no ASR or VoiceChat inference. Proposed amendment SHA-256: `02df4b7297d9f10190a51607b1a816a81188e85ec5fe9090837e542ccadbb505`.

The motivation is supported by the pinned [independent ASR audit](ASR_RAW_COMPARISON_INDEPENDENT_AUDIT_V1.md) and [comparison](asr_runs/comparison_20261118T1157Z/comparison.json), SHA-256 `4f3580b848a916003c81379d62428029381054a6e7d71cf6c0742fb586eeaee8`: all 12 frozen WAVs and **24/24** raw ASR observations remain, Whisper is 8/12 exact, Wav2Vec2 3/12 exact, and the old v1 preflight's exact-transcript `verdict="pass"` requirement cannot truthfully admit the full cohort. The new proposal retains lexical scores, requires blind free transcription before revealing the script, uses human judgment for date/title/action meaning, and anchors eligibility before any VoiceChat output. It keeps an excluded row visible rather than silently picking a favorable engine or rerender. Eleven of the 12 clips already meet its secondary-review trigger because at least one recognizer misses exact full-script match; only Piper `D` is exact for both.

**Blocker 1 — full-matrix advance decision.** The proposal allows a failed clip to be excluded while running VoiceChat on an `eligible` subset. The original assay specifies the six case intents across the two synthetic voices as a matched matrix and requires unclear WAVs to be rejected. Keeping all 12 rows in a reporting denominator does not restore a missing paired voice/case observation. Declare that the planned 6×2 inference advances only if **12/12** are eligible. If fewer pass, stop this cohort's planned assay; any subset run needs a separately reviewed, prospectively specified exploratory protocol, its exact missing cells, both the full 12 and eligible denominators, and no full-matrix/transfer claim.

**Blocker 2 — primary semantic failure trigger.** The secondary rule triggers on ASR mismatch or primary uncertainty/low confidence, but not when a primary listener confidently finds a wrong date, missing B restriction, missing C phrase, or other case-critical failure after script reveal. Piper `D` shows that a both-ASR-exact row exists, so the gap is reachable. Trigger a second independent review on **any** primary field failure, `excluded` judgment, or contradiction with the script, even with high confidence and both ASRs exact. Predeclare the two-of-three adjudication rule for ordinary wording and fail closed on unresolved critical fields. Preserve each blind free transcript and the later script-aware judgment as separately timestamped, immutable records.

The proposed per-WAV receipt and global manifest are feasible as a **new v2 schema**, but the current `qa_receipt_template.json` is v1-shaped and does not encode stage timing, triggered reviewer records, both ASR observations, or final eligibility. The v2 implementation should specify canonical receipt bytes/hashes, exact case/voice join keys, secondary trigger derivation from the 24 immutable observations, a tertiary trigger from independently recorded judgments, and a pre-VoiceChat external anchor for the manifest. The old preflight must remain visibly v1 and must not certify v2. The new preflight must independently recompute all 12 rows and 24 ASR observations, verify source hashes, and reject missing records or later changes.

The signed C grant design is correctly limited to `authorized_dry_run`: exact WAV, **actual final v2 receipt hash**, date, and `DR19` under an external controller key. It cannot be inferred from `confirmed=true`, ASR, or a listener vote. The current two-pass adapter's [independent review](../VOICECHAT_TWO_PASS_ADAPTER_INDEPENDENT_REVIEW_V1.md) demonstrated that it does **not** compare the supplied receipt hash to the signed grant's `qa_receipt_sha256`; v2 must close that implementation gap before any C run. The controller still must independently inspect the audio and adjudicated record; the signature authenticates its decision, not audible truth.

Once these protocol rules are amended, implement and independently review the v2 schema/preflight/adapter binding, then freeze QA records before VoiceChat inference. This proposal itself establishes no model behavior or security finding.
