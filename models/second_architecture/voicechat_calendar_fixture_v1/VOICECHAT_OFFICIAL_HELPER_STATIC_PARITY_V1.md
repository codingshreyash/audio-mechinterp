# VoiceChat official helper parity: offline source-level check

18 November 2026. This is a **source-level, fake-output** check. It is not a VoiceChat model run, audible-output check, calendar action, or security finding.

## Source and method

The test uses NVIDIA NeMo Speech revision `097dfe9e2f55baf653b83035868bdc89849f1b47`. The exact [official offline helper](https://github.com/NVIDIA-NeMo/Speech/blob/097dfe9e2f55baf653b83035868bdc89849f1b47/nemo/collections/speechlm2/inference/utils/offline_voicechat.py) is retained under `vendor/offline_voicechat_097dfe9.py` with its Apache-2.0 header. Its SHA-256 is `ebde701baec12a014443eac36262a6af7a7a62b3e052f1c4a387db6aaad8da44`. The test checks those bytes, extracts the original `run_fc_offline_inference` function by Python AST, and executes that function without importing NeMo. A fake model supplies fixed first-pass function positions; fake tensor construction records the official second-pass arguments. The local adapter's parser and inert calendar response are compared at that boundary. The source itself is unchanged.

Run from the repository root:

```sh
python3 -m unittest models.second_architecture.voicechat_calendar_fixture_v1.test_official_helper_static_parity_v1 -v
```

Result: **4/4 pass**. A valid first call matches the adapter's tag cleanup, parsed call, call and response positions, token IDs, and default JSON response wrapper. A JSON array preserves both parsed entries but injects a single response. A malformed first position does not promote a later valid position into replay. A no-call pass still performs pass-2 audio decoding without function injection. The stock helper records a prewritten response even when no call was used; the adapter's trace instead leaves its `replay` field empty. These are bookkeeping differences, not model decisions.

The test does not cover `load_wav_16k_mono`, Jinja prompt rendering, `encode_system_prompt`, real TTS codec codes, generated waveforms, the saved WAV's tool-gap splice, the checkpoint identity, or the adapter's new v2 human-QA receipt gate. The [official example](https://github.com/NVIDIA-NeMo/Speech/blob/097dfe9e2f55baf653b83035868bdc89849f1b47/examples/speechlm2/offline_voicechat_fc_infer.py) accepts a *prewritten* API response; it does not execute a live tool. The fixture selects an inert response from the parsed call, so same-input stock comparison must pass that selected object to the official helper. It must also keep pass 1 and pass 2 separate.

## Live parity gate still required

After 12/12 audio clips pass the independent human-QA v2 rule and the CUDA environment passes pinned-source and checkpoint checks:

1. Run the **unchanged** official example on NVIDIA's published sample and preserve its files and hashes. This checks environment compatibility only.
2. On one QA-approved fixture WAV, use the same audited WAV bytes, template, rendered prompt, tokenized prompt, model state, generation settings, and RNG state for stock and adapter arms. First run stock twice to measure repeat variation. Record stock pass-1 and pass-2 raw dictionaries with a passive wrapper around `run_offline_inference`; do not modify its arguments or returns.
3. Feed the adapter's selected inert response as the stock helper's `api_response` object. Compare exact pass-1 text and predicted function token IDs, call positions and parser object; exact pass-2 injected token IDs/steps, text/function/codec IDs and lengths; and the **unspliced** waveform before output writing. Require exact discrete equality. Report the maximum absolute float-PCM difference and stock-repeat difference; predeclared waveform tolerance is `1e-4` only if stock repeats satisfy it. Check passive TTS-code capture against a no-wrapper arm.
4. Stop at the first identity failure and attribute the differing stage before using calendar outputs as mechanistic evidence. The official writer removes a function-call interval from saved audio, so compare raw pass-2 audio first and treat the final WAV as a separate transport artifact.

These live steps are a procedure, **not completed results**. Source-level parity cannot establish that a proposed call was generated by the model, that audible speech disagreed with it, or that any action happened.
