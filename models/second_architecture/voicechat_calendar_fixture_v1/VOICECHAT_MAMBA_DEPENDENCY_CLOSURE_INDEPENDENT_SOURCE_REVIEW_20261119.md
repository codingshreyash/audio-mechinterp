## Independent checks

[CUTLASS DSL 4.4.2](https://pypi.org/pypi/nvidia-cutlass-dsl/4.4.2/json) requires its base library at `4.4.2`; [that base library](https://pypi.org/pypi/nvidia-cutlass-dsl-libs-base/4.4.2/json) requires `cuda-python>=12.8`; [cuda-python 12.9.4](https://pypi.org/pypi/cuda-python/12.9.4/json) requires `cuda-bindings~=12.9.4`. The existing freeze has `cuda-bindings==12.9.4`. [Apache TVM FFI 0.1.9](https://pypi.org/pypi/apache-tvm-ffi/0.1.9/json), [Torch C DLPack 0.1.5](https://pypi.org/pypi/torch-c-dlpack-ext/0.1.5/json), and [Z3 4.15.4.0](https://pypi.org/pypi/z3-solver/4.15.4.0/json) satisfy the stated limits.

This supports `--only-binary=:all:` for the recorded host; the actual resolver report remains authoritative.
