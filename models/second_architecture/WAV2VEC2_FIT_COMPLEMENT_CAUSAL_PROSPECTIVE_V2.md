# Wav2Vec2 FIT complement assay: fixed random-row order

19 November 2026. This prospective V2 amendment fixes an ambiguity in [V1](WAV2VEC2_FIT_COMPLEMENT_CAUSAL_PROSPECTIVE_V1.md) identified by independent review **before source freeze or any complement-model inference**. V1 and its HOLD review remain in the record. All 16 directed mode cells, two sites, six arms, windows, outcomes, controls and resource limits remain unchanged.

The arm label `C` in V1 means the **outside-word complement** and is distinct from preprocessing Mode `C` (shared outside-word waveform statistics). This amendment calls the complement `C_off` in explanatory text and fixes canonical JSON arm labels in V1's order: `W`, `C`, `self_C`, `full_donor`, `R1_C`, `R2_C`. These underscore labels correspond to V1's prose names. `C_off` is the row union `[0,W_start) ∪ [W_end,T)` in increasing time order.

For **each** `R1_C` or `R2_C` arm, first concatenate the recipient and donor hidden states from the left `[0,W_start)` and right `[W_end,T)` portions along the time axis, left **then** right. The resulting complement tensor has exact shape `[1,T−(W_end−W_start),768]`. Compute the donor-minus-recipient complement L2 norm in float64. Draw **one** `NumPy Generator(PCG64(seed)).standard_normal(complement_shape)` array for the complete concatenated complement, using V1's seed rule. Scale this one float64 array to the donor-minus-recipient complement L2 norm, cast it to float32, add it to the concatenated recipient complement, and scatter the resulting rows back into the full recipient state in the same left-then-right order. Keep the frozen W rows bitwise unchanged. Record both source and realized L2 norms, the seed, patch hash, and full state. Reject zero or nonfinite source/draw norms. The independent auditor must reconstruct this exact concatenation, one draw, scaling and scatter order without using the runner's patch function.

No other V1 gate is relaxed. A corrected independent plan GO, runner/auditor source reviews, byte-identical no-weight preflight and independently reviewed freeze receipt remain required before one CPU model run. This is a posthoc but prospectively specified FIT mechanism follow-up, not held-out validation or a security test.
