# FIT acoustic-noise pilot: Wav2Vec2 capture-topology amendment V2

19 November 2026. **Source amendment, no candidate inference.** V2 changes only the Wav2Vec2 capture-hook interpretation in the frozen [V1 worker](acoustic_fit_noise_pilot_v1.py) and [V1 protocol](ACOUSTIC_FIT_NOISE_PILOT_PROSPECTIVE_V1.md). All V1 `color_05` Piper/Kokoro clips, the single noise seed and nominal 20 dB level, five arms per clip, 20-case denominator, pinned Wav2Vec2 checkpoint and stock normalization, complete CTC transcript, stage list, internal metrics, and CPU/resource limits remain exactly as V1. This amendment authorizes only a **new Wav2Vec2 attempt** after independent source review, a fresh V2 preflight and V2 GO receipts. The completed Whisper V1 attempt is not repeated under V2.

## Why a new version is needed

The immutable V1 `wav2vec2_attempt_001` stopped on its **first forward** before any case row. Its parent result SHA-256 is `b69468b110a06a55ae8b4b96be367dbc27d608bd1ecfc2b5ecd334547a7d6ebd`, worker JSONL SHA-256 `f1752019284dec76d8cd14203b1d8bc63f5b2890a6f140dbb42d3901c732d5cc`, and worker stderr SHA-256 `a23cc760bf3fd9e1b43ca7d9da914d2111bfcf8a6df2ae5256a59973100dd9b5`. The recorded exception was `capture shape mismatch at post_block0: torch.Size([286, 768])`. This is a hook-shape failure, not a noisy-audio model result. Preserve the entire V1 attempt unchanged and count it as failed, never as a partial completed matrix.

The older [Wav2Vec2 capture helper](wav2vec2_fit_baseline_stage_capture_v1.py) registers `post_first` hooks for `post_block0`, `post_block5` and `post_block11`, because its original Transformers version returned a tuple at those sites. The pinned V2 environment is **Transformers 5.20.2, Torch 2.15.0**. In that implementation, `Wav2Vec2EncoderLayer` returns a Tensor with a batch axis, e.g. `[1, 286, 768]`. Applying `[0]` to it drops the batch axis. The V1 helper then correctly rejects the resulting `[286, 768]` as not `[1, 286, 768]`. The local V2 capture selects the full Tensor at those three block sites. `feature_projection` still returns a two-Tensor tuple and V2 selects only its first Tensor. Every other captured stage remains a Tensor. The V2 hook rejects any unexpected return type or multiplicity, preserves batch geometry, and passes the unchanged old stage-shape/finite checks. It does not change model weights, decoding or the acoustic transform.

## Source, admission and endpoint

The [V2 worker](acoustic_fit_noise_pilot_v2.py) requires the full frozen V1 PCM/noise hash matrix and validates installed model/processor/source bytes through the existing no-weight preflights. It adds a strict Transformers 5.20.2 and Torch 2.15.0 capture contract to its **new** preflight schema `acoustic_fit_noise_preflight_v2`. The new preflight receipt must be generated and committed after V2 source is frozen, independently recomputed, and separately reviewed. A V2 worker GO JSON must use schema `acoustic_fit_noise_review_go_v2` and bind its exact runner/protocol/preflight hashes; no V1 GO is transferable. A separate V2 parent launcher must bind the V2 worker and preserve the same 1,800-second hard deadline, AC/open-lid/power-log evidence, complete 20-row checks and read-only saved audit. It needs its own independent GO and a new exclusive `wav2vec2_attempt_002` directory. Until those gates pass, **no new candidate forward**.

The only prospective endpoint is the V1 complete Wav2Vec2 CTC transcript and the V1 processor/encoder/logit divergence metrics on the 20 fixed arms. `clean_repeat` exact output/state parity, source PCM/noise SHA-256, hook counts, expected stage geometry, and all failed/partial rows remain gates. A V2 successful run would be a small FIT-only descriptive robustness observation. It would not prove a causal audio circuit, cross-model transfer, human intelligibility, attacker reachability, a held-out effect, or a security violation.
