# V6 pilot bound audio batches: source-only handoff

**No candidate model load; live pilot HOLD.** The [batch adapter](voxtral_track_b_v6_bound_batch_adapter_source_v1.py) runs the actual `candidate_common` human-QA gate and fresh no-weight [pre-pilot admission checks](voxtral_track_b_v6_pre_pilot_launcher_source_v1.py) before creating a processor. It rechecks W/A/R, the pinned snapshot manifest and installed Transformers source map, loads only `AutoProcessor` from the pinned local checkpoint, and verifies the snapshot/source map again after batch construction. The returned tensors remain on CPU; a later reviewed child must move them to MPS without changing their bound hashes before model inference.

V3–V6 specify a fixed old-FIT `silver` replay but do **not** select Piper or Kokoro in their text. This source prospectively selects **Piper/color_05/fit_chosen/silver**, matching the earlier frozen nonbeaver ordering. It resolves the clip through the frozen FIT selection/mask receipt, verifies the exact WAV SHA-256 `fe554972f68b470fb0f4a1c844b874e70758279c281bba47e963792bef2634a9`, path containment, 16-kHz mono PCM16 format and frame count, and processes it under the frozen FIT prompt. It compares raw processor tensor bytes with the older FIT hashes for prompt IDs, attention mask and audio features, plus the new admission's dtype/shape-aware worker batch hash. This Piper choice and derived worker batch hash require independent prospective review before a live pilot.

For the synthetic input, the adapter reconstructs the exact all-zero PCM and 16-kHz mono WAV at the frozen first componentwise-satisfying frame count, checking the V6 128-sample step and 512-increment bound. It verifies PCM/WAV hashes, the Track B prompt, maximum geometry and EOS-inclusive longest alias against the no-weight preflight and A. It processes the WAV with the same pinned processor and checks raw input-ID, mask and feature hashes, dtype, shape, finite features, all-one mask, audio-placeholder count, and the admission's worker batch hash. No model output or gradient selects these inputs.

The existing [composition shell](voxtral_track_b_v6_pilot_composition_source_v1.py) remains public hard HOLD. It does not yet call this adapter in a production child; that splice, the pinned FP32 loader, MPS device transfer, parent watchdog, post-run host sidecar accounting, saved-data audit and external post-pilot GO all need separate review. The 32/32 human QA receipt and external A/R are absent, so the live path cannot pass admission. This source does not change the frozen V6 pilot call count or runtime budget.
