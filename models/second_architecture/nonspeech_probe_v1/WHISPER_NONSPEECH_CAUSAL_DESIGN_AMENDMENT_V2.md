# Pre-inference amendment: true no-hook silence donors and raw capture

19 November 2026. **Source-only; no causal candidate inference has run.** This supersedes the two-silence-call, 326-call count and schedule hash in the original [prospective design](WHISPER_NONSPEECH_CAUSAL_INTERVENTION_PROSPECTIVE_V1.md), its [first amendment](WHISPER_NONSPEECH_CAUSAL_DESIGN_AMENDMENT_V1.md), and the source-only independent design review `e75264a`. That review approved a design direction, not an executable or candidate-model load. The true no-hook silence outputs cannot also provide phase-specific raw encoder states through read-only hooks. This amendment adds a distinct read-only capture call for each silence donor.

The first four calls, in exact order, are: `d02_silence` **no_hook**, `d02_silence` **read_only**, `d08_silence` **no_hook**, `d08_silence` **read_only**. The no-hook calls have **no encoder or language-detection hooks** and retain full per-step raw float32 logits for donor numerical parity. The read-only calls have phase-tagged early/final encoder capture hooks that return `None` and save native detection/transcription tensors, with no edit. Their complete prefix and generated IDs through EOS must exactly equal the corresponding no-hook donor output. A failed donor read-only parity invalidates that duration's donor-state intervention; keep the failure and all later cases in the ledger. The two read-only calls save only their first-step full raw vector under the existing storage rule.

All 18 recipient Stage A and Stage B arm lists, random support/norm, patch sites, source WAVs, model/source pins, and complete-output endpoints are unchanged. The fixed denominator is now **328 `generate()` calls**: four silence calls, 180 Stage A calls, and 144 Stage B calls. The revised [no-weight planner](causal_plan_v1.py) has canonical sorted-key JSON SHA-256 `a4a77079c9381758720712f7b5420186e0b08a18c8f3fbbf1a99beb4926d087b`. This replaces the earlier `42a73ee56a5bd4382a649b5106bb1aac1e1a717fd5bb04da1a4af62715ba7e78`. There are still **38** calls that save full per-step raw vectors: two no-hook silence donors and 36 `donor_both` arms. The no-weight conservative raw float32 core evidence bound is now `1,261,452,320` bytes, including 328 first-step vectors and 80 reusable native `[1,1500,384]` states; the prior 256-MiB metadata allowance and 128-MiB reserve still fit under the **2-GiB** hard evidence cap.

If the target is zero, use a float32 zero edit. Save the realized float32 post-state hash and norm; the saved auditor must reconstruct this exact algorithm. This specifies the random-control implementation without changing any case, seed, arm, or support.
