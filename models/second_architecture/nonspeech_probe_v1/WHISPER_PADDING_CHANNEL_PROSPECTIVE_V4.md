# Amendment V4: processed scores and first decoder-state geometry

19 November 2026. **Source-only correction before executable implementation or candidate inference.** This amendment changes two evidence rules in [V2](WHISPER_PADDING_CHANNEL_PROSPECTIVE_V2.md) and [V3](WHISPER_PADDING_CHANNEL_PROSPECTIVE_V3.md). It does not change the 436-call order or schedule SHA-256 `d939618689e989a2dfe249cc6d4f0d3b32a532c184991680b77f11b4af6a0ace`.

The first-step processed-score vector is float32 with 51,865 entries. Whisper's generation processors can suppress tokens by assigning **negative infinity** to their scores. Therefore, save these vectors losslessly as binary float32 and allow `-inf` only in the processed-score vectors. Require every processed vector to have at least one finite entry and no `NaN` or `+inf`. For parity, require **exactly identical `-inf` masks** and maximum absolute difference at most `1e-5` over the finite entries. A mismatched suppression mask fails parity even if the selected token and text match. Raw pre-processor logits and saved encoder/decoder states must remain entirely finite. This corrects V2's blanket “nonfinite array fails” rule, which would reject the intended generation policy.

The first generation step's final decoder-layer hidden state has shape **`[1,4,384]`** because the frozen prefix has four tokens. Save and compare the full array, not a single width-384 row. Require exact shape/dtype and all-finite values. The [V4 evidence planner](padding_channel_plan_v4.py) retains the independently reviewed V3 call schedule byte-for-byte and budgets four decoder positions per call; its conservative core estimate increases from 1,375,203,488 to **1,377,212,576 bytes**. With the frozen 256-MiB auxiliary allowance and 128-MiB reserve, the total is **1,779,865,760 bytes**, below the unchanged 2-GiB hard evidence ceiling. Actual bytes and reserve must still be enforced before each forward and write.

The future fake-output tests must include matching `-inf` suppression masks, a mismatched mask rejected despite identical text, a `NaN`/`+inf` rejection, raw-logit nonfinite rejection, and acceptance only of a finite `[1,4,384]` decoder state. The independent executable reviewer must approve this correction and those tests before any checkpoint load.
