## Blocking findings

1. **The worker can run outside the bounded parent after a GO exists.** `natural_tail_runner_v2.run()` accepts an arbitrary absolute directory with user-created `launch_start.json` and `pre_host.json`. It checks matching JSON fields and a readable host archive, but not a live parent process or inherited one-use launch authorization. Its own 1,800-second timer starts *after* loading the model; it has no process-tree RSS or evidence-byte monitor. In a no-weight fault test, I created the two parent-looking files, mocked only the unavailable GO/model/host dependencies, and called `run()` directly. It wrote a complete call and completion record while no `parent_result.json` or RSS monitor log existed. This does not claim candidate inference occurred; it demonstrates that the direct CLI path reaches the inference loop without the required resource parent. The saved auditor would later reject such an attempt, but that is too late to prevent an unbounded model load. Require a one-use parent-to-worker handshake tied to a live parent identity **before** `_snapshot_load`; an ordinary `python -m ...natural_tail_runner_v2 run` invocation must fail without it. Test the direct invocation adversarially after the fix.
2. **The stated whole-attempt deadline excludes the pre-run host probe.** In `natural_tail_parent_v2.launch()`, `host_gate.probe()` runs before `started_mono = time.monotonic()`. The protocol says the 1,800-second whole-attempt wall deadline includes host probes. Move the monotonic start and deadline before the first host probe, include both probes in the elapsed receipt, and fail closed when the deadline is exhausted. A source-only test should delay the pre-probe and verify that the available worker budget shrinks by the same amount.

The 4-GiB process-tree RSS and 1-GiB whole-checkpoint evidence monitors, AC/open-lid checks, post-host archive verification, and immutable fresh attempt directory are present on the intended parent path. The two blockers above prevent certifying that all inference must use that path or that its total wall time matches the frozen protocol. Correct the committed sources, regenerate and commit source-only admission receipts from the new hashes, then request a new independent executable review. No result should be interpreted from a partial attempt.
