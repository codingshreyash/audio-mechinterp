# Prospective V3 saved-auditor repair for English Whisper

19 November 2026. **HOLD for interpreting the saved English V2 run.** The completed `descriptive_whisper_english_20261119_v2` attempt is kept byte-for-byte unchanged. This amendment adds a new saved-record auditor and a new independent audit review gate. It does not rerun a model, alter the V2 worker or parent, or treat a failed V2 audit as a model failure.

The V2 auditor hardcoded multilingual Whisper EOS ID `50257`. The pinned English-only checkpoint uses EOS and pad ID `50256` (decoder start `50257`, no-timestamps `50362`, vocabulary 51,864). The saved V2 worker used the checkpoint tokenizer's EOS correctly. A complete English sequence with a generated `50256` therefore fails the V2 auditor's EOS/censor check even though it is properly terminated. The new auditor reads the revision-pinned local `config.json`, `generation_config.json`, and tokenizer, verifies their EOS/pad IDs agree, and uses the selected checkpoint's IDs. It also derives decoder start, no-timestamps, vocabulary, mel bins, encoder rows, and hidden size from the selected pinned checkpoint. For multilingual Whisper, the corresponding pinned IDs are EOS/pad `50257`, decoder start `50258`, no-timestamps `50363`, vocabulary 51,865. The 20-case, two-repeat, 18-difference, time/shape/hash, language-choice, and full-record structural checks remain.

Only the English V2 attempt path is eligible for this V3 saved audit. The V3 source-only preflight binds the existing V2 source GO, exact V3 auditor/test/amendment bytes, pinned checkpoint assets, and SHA-256 of the existing English V2 `parent_result.json` and `records.jsonl`. It hashes the records without reading model outputs. A later separately committed V3 GO must bind that receipt and source before any saved output is interpreted. The V3 audit writes a result only to a separate, new audit directory; it never writes inside the completed attempt. It cannot reconstruct model forwards or raw activation tensors from saved curves.

No candidate weights are loaded or generated by this amendment or its no-weight fake tests. The current interpretation decision remains **HOLD**.
