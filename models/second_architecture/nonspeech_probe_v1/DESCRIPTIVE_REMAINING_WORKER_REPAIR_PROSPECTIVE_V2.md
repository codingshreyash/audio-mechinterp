# Prospective V2 worker repair for remaining descriptive models

19 November 2026. **HOLD for candidate inference.** This amendment applies only to new one-shot attempts for `whisper_english` and `wav2vec2`. It preserves the frozen 20 non-speech WAVs, all checkpoint/source pins, the invalid V1 English/Wav2Vec2 attempts, and every V1 worker/parent/GO file. No model outputs from those failed attempts were opened to design this repair; their saved record files are bound by SHA-256 only.

The V1 English-only worker passed `task='transcribe', language=None` to `WhisperGenerationMixin.generate`. In installed Transformers 5.20.2, `_set_language_and_task` raises if **either** argument is non-None while `generation_config.is_multilingual` is false. The V2 English-only path omits both keywords. It retains fixed greedy generation, a 128-token cap, 2/8-second inputs, output scores, raw logits, decoder states, attention masks, and all 20 cases plus two silence repeats. It does not change the multilingual Whisper path.

The V1 Wav2Vec2 worker reduced a captured `[1,T]` input trace to a one-dimensional `[T]` time curve, then called `np.linalg.norm` with `axis=()`. NumPy raises “Improper number of dimensions to norm.” V2 computes elementwise absolute value for this one-dimensional stage and Euclidean norms over trailing feature axes for higher-rank stages. Both baseline row norms and silence-difference row norms use this rule. A no-weight test must cover both, including the exact `[1,T]` input stage.

New paths are `runs/descriptive_whisper_english_20261119_v2` and `runs/descriptive_wav2vec2_20261119_v2`. Each model gets a separate new source-only receipt and independently committed new GO, bound to the V2 worker, parent, auditor, tests, this amendment, the unchanged V1 descriptive source/GO, and the shared corrected host timing helper. The GO for one model cannot authorize the other. The V2 parent saves the worker-exit timestamp before the post-host probe, requires ≤120 seconds probe lag, and keeps all earlier wall, RSS, evidence, AC/lid, and no-sleep controls. It performs no automatic retry.

The exact V1 failed-attempt byte hashes are fixed in V2 source for `parent_result.json` and `records.jsonl`. The parent will fail admission if they change; it never reclassifies them. A future V2 saved-data auditor must require 20 complete case rows, two exact-silence repeats, all 18 silence-difference rows, exact model-specific output/trace geometry, and the corrected host evidence. Source-only fake tests and independent review are required before either V2 candidate checkpoint is loaded. The current decision is **HOLD**.
