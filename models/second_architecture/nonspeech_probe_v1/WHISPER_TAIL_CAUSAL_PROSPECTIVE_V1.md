# Prospective Whisper Tiny encoder-state patch pilot

19 November 2026. **Source only; HOLD inference until a separate executable source review, model-specific GO, and fresh attempt.** This is a small post hoc mediation test of independently reviewed V4 engineered non-speech observations. It is not a held-out result, a security finding, or evidence of generalization. The V4 attempts and WAVs remain immutable.

## Frozen pair and endpoint

Select `d08_beep_train_low` with a 32,000-sample noise tail, seed 0, and its equal-duration zero tail in both pinned Whisper Tiny checkpoints. Both V4 outputs ended in EOS. The multilingual saved token path changes under noise while its detected-language prefix remains English; the English-only path does not change. The English-only arm is a same-WAV disruption control, not an answer-transfer target. Seed 1 and the English-sensitive case `d08_band_noise_low` remain observed V4 data reserved for a separately reviewed replication. No cases or layers are selected based on this pilot's outputs.

Run fresh no-hook zero and noise baselines first. Both must exactly reproduce the respective V4 `sequence_ids`, `prefix_ids`, termination, and first-step raw and processed FP32 vectors or the entire attempt is invalid. Each patch saves the full token path, decoded text, EOS/censor state, first-step vectors, detected-language logits and prefix, and hook counts. A changed output without EOS is incomplete. For the multilingual changed pair, **rescue** means noise-recipient patched output exactly matches the complete zero baseline; **induction** means zero-recipient patched output exactly matches the complete noise baseline. Prefix must stay equal to the unpatched recipient prefix for a transcription-only claim. English-only output changes are recorded as disruption. Capitalization or punctuation changes are reported separately from lexical changes.

## Fixed sites and rows

Whisper Tiny has four encoder blocks, 384 channels, 3,000 mel frames, and 1,500 encoder rows. Conv1 uses kernel 3/stride 1/padding 1; Conv2 uses kernel 3/stride 2/padding 1, so row `r` receives local convolution input around mel frames `2r-2..2r+2`. For this 8-second source and 2-second tail, source/tail boundaries are `b=400` and `e=500` encoder rows. Freeze **boundary** rows `{398..402, 498..502}` and **tail interior** rows `{403..497}`. The five-row boundary windows are intentionally broader than the minimum local convolution support. At later self-attention layers, the tail can affect source rows globally; a local-row rescue does not imply information remained local upstream.

Three sites are frozen: input to encoder block 0 (`post_conv_pos`), output of block 0 (`post_block0`), and output of final encoder layer norm (`post_final_norm`). At every site and region, test zero→noise and noise→zero. Four equal-count local arms are: donor transfer at target rows; recipient→itself identity sham; donor transfer at source rows sampled deterministically without replacement from `8..391`; and a norm-matched shifted-delta control that adds the donor-minus-recipient **target-row** delta to those source rows. Save exact row indices, FP32 donor/recipient state hashes, patch delta L2, and prove unselected rows unchanged. Add a full 1,500-row donor patch at each site and direction as a positive control; it must reproduce the donor complete sequence and first-step raw vector exactly for local-patch interpretation. A local null is uninterpretable if the corresponding full-donor control does not reproduce the donor output. A local donor match is interpretable only if identity and both source-row controls preserve the recipient output.

For multilingual Whisper, patch **transcription/generation encoder pass only**; leave its separate language-detection pass unmodified and require the language prefix and detection logits to match the recipient baseline. English-only has one generation encoder pass. Require one expected patch-hook call per generated encoder pass and no unexpected calls. Every arm starts a fresh `generate()` call without supplied or reused `past_key_values` or encoder outputs; verify no decoder cross-attention cache carries across calls. The input waveform, attention mask, model weights, generation arguments, and all unselected rows **at the patched hook tensor** remain fixed. Later layers may change through self-attention.

## Execution and limits

One pair per checkpoint gives two no-hook baselines plus `3 sites × 2 regions × 2 directions × 4 local arms + 3 sites × 2 directions` full-donor arms = **56 calls per checkpoint, 112 total**. Use independent, one-shot paths `runs/whisper_tail_causal_v1/whisper_multilingual_attempt_001` and `runs/whisper_tail_causal_v1/whisper_english_attempt_001`, with separate source-only admissions and model-specific GO receipts bound to the plan, exact V4 audit/record/inventory/review hashes, model snapshot, source and attempt path. The worker must authenticate a live bounded parent and nonce before weights. A separate saved auditor must rehash sidecars, check arm census, state replacement invariants, host and resource evidence, and score EOS-qualified endpoints. Run the two attempts sequentially.

The host gate explicitly permits the already authorized battery run: require **≥80%** battery at each attempt start, lid open, and no thermal warning; probe battery/lid/thermal state at intervals **≤15 seconds** throughout, and abort if battery falls to **≤70%**, sleep/thermal emergency occurs, or any state is unreadable. Record start, in-run, and post-run power-log coverage. The old AC-only host gate cannot authorize this run. Bound each attempt to **1,800 seconds whole elapsed time including probes**, process-tree RSS **<4 GiB**, and evidence **<1 GiB**, with a terminal reserve and fail-closed partial attempt. The V4 160-call runs took 17.0 seconds English-only and 25.2 seconds multilingual with peak RSS 0.85/1.01 GiB. Hooks and state writes may dominate: plan for **2–10 minutes per checkpoint**, 30 minutes maximum for both. These are estimates; no causal-pilot runtime has been measured.
