# Prospective V2: isolate the original tail/end boundary

19 November 2026. **Source-only design; no V2 model inference or GO is authorized by this document.** V1's saved, independently audited result has one strict combined-window crossover out of four union cells: `post_conv_pos` at an 8,000-sample prepend/append offset. V1 also found that the isolated original `498..502` tail/end window was control-qualified at `post_conv_pos`, whereas the isolated `398..402` source/tail window was not. These observations motivate V2; they are not V2 confirmation, and V2 must not be used to retroactively reinterpret V1 as having isolated an event.

## Question and fixed inputs

Does the isolated donor-minus-recipient effect around the **end of the original noise tail** follow that boundary when zero samples are prepended, and stay at its old position when zero samples are appended? This is a test of a position-specific causal effect in one engineered non-speech pair, not a search for a neuron or a security exploit.

Use only the original `d08_beep_train_low__z32000.wav` and seed-0 `d08_beep_train_low__n32000_s0.wav` zero/noise pair, and the eight 8,000- or 16,000-zero-sample prepend/append WAVs already pinned by V1 plan SHA-256 `b1aa22f0b0c9a357a641dcc7d3ee5e1a789d2337d9b0bbb81ae131e6e3162f61` and rendered-source manifest SHA-256 `eec732fb24a4b238ad0666d52d168f5ba41ec38c9d315a057a39e0d53be1435b`. Verify each complete WAV hash and geometry, and the translated PCM hashes in that manifest, before use. Do not select a different seed, duration, pair, offset, or successful V1 arm after seeing V2 outputs. Use multilingual Whisper Tiny FP32 CPU and the same pinned checkpoint, processor, package versions, deterministic generation settings, and `post_conv_pos` capture site as V1. Patch the transcription encoder pass only; leave language detection untouched. Zero is donor; noise is recipient.

The old tail/end boundary is near encoder row 500 in the 10-second original. Appending zeros leaves the **original noise-tail to added-silence interface** near row 500 and creates a later **new waveform end**. The zero-tail variant has no audible transition at that old interface. In the already saved V1 `post_conv_pos` states, the append new-end five-row donor-minus-recipient norm is exactly `0.0` at both offsets, while the old-interface norm is about `8.1954`. This is prior evidence used to design V2, not a V2 result. Do not call the old interface the new waveform end or use a zero native new-end patch as evidence that the model ignores that end.

## Frozen calls and controls

Use three **new**, separate one-shot attempts, in order: original replay, 8,000-sample translation, 16,000-sample translation. Each attempt runs all of its no-hook baselines before any arm. The original attempt runs two baselines and five `post_conv_pos`, `498..502` arms: direct donor transfer, identity sham, donor patch at five deterministic unrelated source rows from `20..300`, displaced equal-norm donor-minus-recipient delta, and full 1,500-row donor positive control. This is **7 calls**. The original pair must replay the V1 complete outputs, mel, masks, and first-step vectors. If its clean contrast or isolated tail/end control qualification fails, report the failure; no V2 boundary claim can follow. Still execute the two later stages on their fixed schedules and report their outcomes as descriptive. Do not promote a later arm to replace the failed original gate.

Each offset attempt runs four no-hook baselines (prepend/append × zero/noise). For **each layout**, run the following `post_conv_pos` arms, using five rows per local window:

1. At both fixed `498..502` and translated `498+δ..502+δ` windows, run direct donor transfer, identity sham, unrelated source-row donor, and displaced equal-norm donor-minus-recipient delta: eight arms.
2. Run one full 1,500-row donor positive control.
3. Take the exact donor-minus-recipient delta from the prespecified **old-tail-end-aligned window** (translated for prepend, fixed for append), and apply that same unscaled five-row delta to the competing window: one cross-window relocation. Save and compare its source and applied L2 norms; a mismatch above `1e-4` invalidates this control.

This is **4 baselines + 20 arms = at most 24 calls per offset**, or **55 calls maximum** across V2. The append translated window is both the competing window and the nominal new waveform end. Record the native donor-minus-recipient norm at both windows. A five-row delta L2 norm must exceed **`1e-3`** to count as nonzero for the primary decision; this threshold is fixed here using the archived V1 norm separation and FP32 precision, before any V2 inference. If the native new-end delta is below it, a failed *native direct donor patch* there cannot show that the model ignores the new end; the nonzero relocated aligned delta is the interpretable equal-norm comparison.

A translated zero/noise pair is eligible for arms only when both no-hook outputs end in EOS, have the same detected-language prefix and identical masks, and differ as **complete token paths**. If either layout lacks this contrast, including because a baseline is censored, save all four baselines, mark that layout ineligible, skip its arms, and report no crossover for that offset. Do not shorten output, change decoding, or substitute another pair. Every patched call must retain the recipient waveform, mel, mask, language-detection logits, and resolved prefix. A censored patched answer is recorded and fails the affected complete-answer control; it is not dropped or replaced. The saved auditor must verify all selected and unselected encoder rows, exact patch arithmetic, sidecar hashes, call order, EOS or explicit censor status, resource receipts, and skipped-arm census.

## Decision rule fixed before V2 outputs

At a given offset, a layout is control-qualified only if its **aligned isolated tail/end direct patch** produces the exact full donor token path including EOS; its identity, unrelated-row, and displaced equal-norm controls preserve the exact complete recipient path; its full-donor control reproduces the complete donor path and exact donor first-step raw vector; and the aligned donor-minus-recipient norm exceeds `1e-3`. The competing direct patch must **fail** to produce the exact donor path, and relocating the aligned delta to that competing window must preserve the exact complete recipient path. An opposite direct patch that changes the recipient to a third answer is a recorded nonspecific effect, even if it fails donor transfer. Report the stronger secondary condition, opposite direct patch also preserving the recipient, separately.

Call an offset a **strict isolated old-tail-end crossover** only if the original replay is qualified, **both** translated layouts are eligible and mel-shift-qualified, both layouts meet the rule above, and all full-donor and prefix checks pass. Report `x/2` offsets. A confirmatory within-pair boundary-timing result requires **2/2** strict offsets. If V2 gives 1/2 or 0/2, report the individual outcomes without an isolated tracking claim. If the append competing new-end native delta is below the frozen threshold, say that V2 compared a transported nonzero old-boundary delta at the new end; it did not test a native new-end contrast of equal strength. A result at this pre-attention site still cannot distinguish local acoustics from positional context, encoder-edge effects, or interactions outside the five edited rows.

## Execution boundary and later gate

Before any V2 weights load, freeze the exact implementation, schedule, source hashes, processor and checkpoint assets, threshold, and independent executable review. Require a new committed admission and GO for **each** V2 attempt. Keep V1 attempts and all prior source WAVs untouched. Reuse the reviewed local Mac controls: lid open, no thermal warning, at least 80% battery at start, abort at 70% or less, host samples no more than 15 seconds apart, 1,800-second whole-attempt limit, process-tree RSS below 4 GiB, and retained evidence below 1 GiB **per attempt**. A cap, missing receipt or scheduled call, or broken GO makes the attempt invalid; do not retry under the same GO. A fully recorded censored baseline makes its layout ineligible; a fully recorded censored arm fails its cell's complete-answer criterion. Neither alone invalidates the evidence census.

**Fresh sound-family replication is a separate later gate**, not a discretionary V2 fallback. If V2 qualifies, predeclare at least one independently constructed non-speech family and its matching controls before running it. Until that succeeds, describe the result as conditional on this one beep/noise pair; make no claim about human speech, multilingual requests, model safety, or attacker-reachable behavior.
