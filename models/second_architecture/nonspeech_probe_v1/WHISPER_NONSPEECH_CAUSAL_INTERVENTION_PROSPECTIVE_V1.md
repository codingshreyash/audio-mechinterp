## Interface map and the two distinct passes

In the installed source, `_retrieve_init_tokens` calls `detect_language` before transcription when `language=None`. `detect_language` calls the model once with the mel features and start-token decoder input, masks non-language logits, and chooses a language ID. `generate_with_fallback` then performs the transcription forward using the same mel features. The descriptive source observed **one encoder pass in each phase** for these short clips. Implement a phase wrapper around `model.detect_language`, as the reviewed descriptive `Capture` does, and fail if the phase-tagged hook count is not exactly one detection and one transcription call per generation. Preserve native language detection in every arm; `donor_detect` means patch its encoder state, **not** insert a forced language token.

At final encoder site A, hook `model.model.encoder.layer_norm` **after** it returns its `[1,1500,384]` tensor. Return a cloned patched tensor, leaving weights, saved donor, and native recipient state unchanged. The decoder consumes the patched final encoder tensor. Independently capture the same-duration silence donor final state from its no-hook generation for both phases; do not substitute one phase's tensor for the other without verifying exact equality. A phase-specific arm patches exactly the declared phase and leaves the other untouched. Record native, donor, and realized post-hook tensor hashes, shape/dtype, changed-row count, and L2 norm **for each phase**. Self replacement must use the same case's prior native state, not a current post-edit tensor.

At early encoder site B, a separate pre-hook on `encoder.layers[0]` replaces rows of the post-convolution, post-position input `[1,1500,384]`, again in both phases. The installed encoder passes no attention mask to its blocks; the pre-hook receives `hidden_states` and `None` and must preserve all other arguments. The processor's saved mask has 200 or 800 active mel frames for 2 or 8 seconds. The first convolution has stride 1 and the second stride 2, yielding a **nominal** active encoder interval `[0,100)` or `[0,400)`; use exactly those first rows for `active_both` and the equal-width interval `[100,200)` or `[400,800)` for `displaced_both`. Both lie within 1,500 rows. Record the actual donor-recipient norm in each interval. A displaced patch with zero/small realized edit is a weak control, and neither interval is a uniquely localized acoustic source because bidirectional encoder layers mix positions.

## Complete one-shot matrix

Run two silence no-hook donor baselines, then Stage A's **10 arms for all 18 recipients** (180), then Stage B's **8 arms for all 18** (144): **326 complete `generate()` calls** in the exact schedule order. Each generate call normally entails one detection and one transcription encoder pass. The schedule and independently seeded random-arm IDs are machine-readable in `causal_plan_v1.py`; no arm may be dropped or promoted after seeing output. Preserve failed/censored calls in the same denominator. Stage A arms are no-hook, read-only, self-detect, self-transcribe, self-both, donor-detect, donor-transcribe, donor-both, and two independent equal-norm random-both controls. Stage B arms are no-hook, read-only, self-both, full-donor-both, active-both, displaced-both, and two independent equal-norm random-both controls. **At both stages**, each random arm edits the full `[0,1500)` row support, not just the active or displaced interval. For each arm and phase, use its distinct frozen SHA-derived seed and a Gaussian vector normalized to the **full donor-minus-recipient tensor L2 norm at that arm's site and phase**; record seed, support, target and realized norm, cosine to donor displacement, and full output. These full-support random controls are not magnitude-matched controls for the narrower Stage B `active_both` or `displaced_both` arms. If a donor displacement norm is zero, use a zero edit and label that control uninformative; never resample to get a desired result.

Require exact complete **prefix plus generated token IDs through EOS** parity for no-hook/read-only/self arms against that case's no-hook baseline, and for `donor_both` at each site against its same-duration silence donor. Compare also actual generated step count, language token, first-step **raw** logits, processed scores, and first decoder-step state. Save one raw native state per case/site/phase (20 cases × two sites × two phases = 80 tensors), reuse its immutable bytes as source/donor evidence for every arm, and save each realized edited-state hash; do not duplicate a full 1,500-row state for every arm. Save complete first-step raw vectors for all arms and selected-token scores for subsequent steps. **Save full per-step raw float32 logit vectors for both silence donor baselines and every Stage A/B `donor_both` arm (38 calls total)**, so every claimed `donor_both` numerical parity comparison has an independently inspectable donor target. Use binary float32 sidecars with exact shape/dtype/byte hashes, not JSON float arrays. For full-donor both arms, require full per-step raw-logit max-absolute difference at most `1e-5` from the matched silence donor, or label numerical parity failed even if tokens match. This is a proposed strict check that must be validated in fake source tests before candidate inference. If either site fails full-donor parity, report every failure and do not interpret a local patch at that site as a clean donor-state sufficiency test. If no-hook/read-only/self parity fails, all causal interpretation of that case/site is invalid. A random edit changing the same output weakens donor specificity and stays in the ledger.

Primary outcome is the full token-sequence match to either recipient or same-duration silence donor, including generated EOS. Secondary outcomes are the detected language ID, first-step raw versus processed argmax, transcript text/script, and continuous score/activation changes. Detect-only versus transcription-only versus both arms implement a 2×2 final-state intervention: report whether an output change follows language selection, transcription state, both, or neither. When recipient and donor already have identical complete outputs, report score/state changes only and **do not** count a donor match as an output flip. Do not call an observed silence-output transfer a refusal, hallucination rescue, bypass, or exploit.

## Independent audit and resource gate

Before weights load, implement the worker, parent, read-only saved auditor, fake-model phase/hook tests, exact 326-call census and censor ledger, checkpoint/source admission, and an independent executable source review with a GO receipt committed **after** source freeze. No exploratory candidate forward is permitted to debug a failed source gate. Use a new exclusive attempt directory, no retry, a 1,800-second parent wall cap, regularly polled process-tree 4-GiB RSS ceiling, **2-GiB evidence cap** with 128-MiB pre-forward/pre-write reserve, AC/open lid, ten-minute pre-run power log, and a post-run log collected after worker exit. The no-weight worst-case binary float32 budget is `1,261,037,400` bytes for 38 calls × 128 full raw vectors, 326 additional first-step vectors, and 80 native `[1,1500,384]` states; adding a 256-MiB metadata allowance and 128-MiB reserve remains below 2 GiB. The worker and parent must enforce actual bytes and record any cap failure as censored; neither the arithmetic nor a compression estimate permits writing past the cap. The sampled RSS limit cannot rule out a transient peak between polls. Fence host coverage through a timestamp captured **immediately when the worker exits**, then check sleep/wake/thermal events through log collection and cap collection lag at 120 seconds; the invalid V1 host-timing attempt shows why. Save the pre/post host logs, sampled RSS, full model-asset hashes, per-call progress, case/phase hook counts and outputs, plus all failures. An independent reviewer must rehash saved raw tensors, reconstruct every edit from source/donor/seed, independently decode all 326 output sequences, verify complete parity and host evidence, and report every censored arm before a causal claim. Summary-only activation hashes cannot support that reconstruction.

## Separate decoder-policy question

The valid descriptive run found the raw first-token argmax configured in `suppress_tokens` for 16/20 inputs; silence itself generated ` you`. A **separate**, prospectively reviewed 20-case plus two-repeat decoding-policy study may keep the same checkpoint, waveforms, language detection, task, and deterministic settings while changing **only** `suppress_tokens` to `None` in a copied generation config, preserving `begin_suppress_tokens`, timestamp processors, and all other settings. Save and compare complete generated sequences and raw/processed logits against the stock output. Freeze its own source, full denominator, caps, admission and GO before model inference. It would test how decoding policy changes the visible output; it would **not** establish where acoustic evidence arose or replace the phase-specific encoder interventions above.

No result from this study alone establishes attacker reachability, held-out transfer, a spoken assistant action, or a security-property violation. A stronger next test needs new sound families/voices and an audio-language or speech-to-speech checkpoint with a complete answer/action endpoint.
