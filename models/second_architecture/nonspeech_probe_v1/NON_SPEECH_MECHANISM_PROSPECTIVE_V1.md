# Non-speech audio to transcript: prospective mechanism pilot V1

19 November 2026. **Source and design only; no candidate-model inference.** This pilot takes the observed beeps/noise-to-text behavior seriously while separating (1) a generated transcript, (2) a selected language, (3) a measured internal signal, and (4) a causal effect on the complete output. It is a small local mechanistic assay, not a security finding or a claim that non-speech Whisper hallucinations are newly discovered.

## Prior evidence and model choice

The [OpenAI Whisper model card](https://github.com/openai/whisper/blob/main/model-card.md) already warns that weakly supervised ASR can emit text not spoken in the input. [Barański et al.](https://arxiv.org/abs/2501.11378) tested non-speech-induced Whisper hallucinations, and [Wang et al.](https://www.isca-archive.org/interspeech_2025/wang25b_interspeech.html) studied decoder attention heads and a mitigation on Whisper-large-v3. These are primary sources and make a simple demonstration of text from noise prior art. This pilot asks **where a specified synthetic waveform affects a complete output** in small, open, architecturally different models; its results cannot establish a novel general mechanism without a later held-out and larger-checkpoint replication.

Use three separately labelled checkpoints: multilingual [`openai/whisper-tiny`](https://huggingface.co/openai/whisper-tiny/tree/169d4a4341b33bc18d8881c4b69c2e104e1cc0af) at commit `169d4a4341b33bc18d8881c4b69c2e104e1cc0af` for language selection and transcription; the already-pinned English-only `openai/whisper-tiny.en@87c7102498dcde7456f24cfd30239ca606ed9063` as a generation-family comparator; and CTC `facebook/wav2vec2-base-960h@22aad52d435eb6dbaf354bdad9b0da84ce7d6156` as an encoder/decoder-architecture comparator. The `.en` and Wav2Vec2 checkpoints **cannot** test a Russian/Hindi script outcome; score them only for nonempty English-like output and internal response. The multilingual checkpoint is not yet in the local cache. No weight download or load is part of this source handoff. The revision API returned that exact commit; its config, preprocessor, generation config, and tokenizer file bytes are recorded in [the metadata pin](whisper_tiny_metadata_pin.json). Its `generation_config.json` has `is_multilingual=true`, a null language slot, and 99 language tokens (including Russian and Hindi), whereas `config.json` contains an English forced prefix. **This metadata does not itself prove the installed generation path selects language automatically.** Pin every fetched model file and installed Transformers/Torch/NumPy source before candidate inference, verify the resolved config and tokenizer bytes against the metadata pin, and reject any changed revision or package source.

## Frozen engineered non-speech inputs

The exact [source spec](spec.json) and [no-model renderer](render.py) define **20** 16-kHz, mono, PCM16 WAVs: zero silence and ±1-LSB dither at 2 and 8 seconds, plus steady 700-Hz tone, 1-kHz intermittent beeps, alternating-polarity 8-ms click train, and 300–3400-Hz band-limited Gaussian noise at 0.005 and 0.05 target full-duration RMS at each duration. Gaussian seeds are frozen per duration; the same base waveform is scaled for the two levels. A peak above 0.8 fails rather than clipping. Render with NumPy 2.3.5 into a new exclusive directory. Preserve the exact source/spec hashes, all WAV/PCM hashes, sample counts, RMS/peak, source platform and a failed-run receipt. Do not choose a sound, seed, duration, or level after seeing a transcript. The dither and silence cases test the processor's near-zero behavior; they are controls, not speech.

An independent **technical signal audit** must reproduce all 20 PCM arrays and hashes, verify WAV format, exact duration, no clipping, silence zeros, dither support and in-band energy of the noise. These sounds contain no scripted or synthesized words by construction; that does not prove that a person could never hear a speech-like pattern in them. If an intelligible-speech claim is later needed, obtain blinded listening; this pilot instead makes the narrower engineered-non-speech claim. Existing audited FIT Piper/silver speech may be used only as a separately labelled operational positive control, not as a non-speech case or a tuning input.

## Frozen model observations

One run per model, one-sample batches, CPU FP32/eval, deterministic decoding, one clean model load, and the 20 cases in lexicographic case-ID order. Re-run the exact 2-s and 8-s silence inputs once at the end as deterministic repeat controls. Retain every case, including load failure, processor failure, all empty transcripts, timeout and censored generation, in the planned denominator. The parent watchdog is 1,800 seconds per model, peak worker RSS 4 GiB, total new evidence 128 MiB, with AC/open-lid and full interval power/sleep/thermal evidence on the Mac. A failed attempt is immutable and is never relabelled as a negative transcript. Use exclusive output paths and no automatic retry.

For multilingual Whisper, use `task=transcribe` with **automatic language selection**, no forced language token, no translation, `do_sample=false`, `num_beams=1`, at most 128 newly generated tokens and a complete EOS/censor check. The implementation and independent source review must verify the pinned Transformers 5.20.2 auto-language path and record exact resolved generation config/decoder-prefix token IDs **before** inference; any forced English or silent task change is HOLD. Save all generated token IDs including language/task/no-speech/EOS tokens, per-step selected-token scores, full text with and without special tokens, detected language token, and Unicode script of emitted letters. A language-token choice alone is **not** a multilingual transcript. Run the English-only Whisper under the same deterministic length/stopping settings but without claiming language detection. Wav2Vec2 uses its stock per-utterance normalization and complete CTC frame-ID path, logits hash, uncollapsed and collapsed IDs, and decoded text. Do not compare raw token counts or hidden-state norms across these models as if they shared a scale.

Primary descriptive outcomes per case are: (a) complete nonempty lexical text versus empty/no-speech, where punctuation-only and special-token-only outputs are empty; (b) model-selected language token for multilingual Whisper; (c) actual script of text; (d) EOS or censor; and (e) exact full output stability on repeated silence. Report 20/20 rows for each model and per-family/duration/level counts, not only examples. A text string in Cyrillic or Devanagari from an engineered non-speech WAV is a **non-speech transcription observation**, not evidence that the sound carried those words or an authorization bypass.

Capture time-resolved states at the processor output, Whisper post-convolution encoder input, post-encoder block 0, final encoder, first decoder step and subsequent text logits; Wav2Vec2 stock normalized input, first raw convolution, first GroupNorm, feature projection, post-block 0, final encoder and CTC logits. Use the installed-version-aware hook topology already established by the acoustic FIT pilot. Save raw tensor hashes, shape/dtype, hook counts, per-row norms and per-row differences from the same-duration silence baseline. Record input geometry and padding masks so a 30-second Whisper padded row is not mistaken for active sound. A large difference in an activation is observational until the intervention below changes a complete output.

## Predeclared interventions and causal limits

Run this stage **only after** the descriptive runner has an independent source review and a separate frozen intervention plan. The population is all **18 non-silence cases**, not a post hoc selection of cases that generated text. For each model and same-duration silence donor, test no-hook, read-only hook, exact self, full silence-donor state, and two independently seeded equal-norm random edits at one pinned final encoder interface. Require no-hook/read-only/self complete-output parity and full-donor exact donor-output parity (including Whisper language/task/EOS tokens or complete Wav2Vec2 CTC frame IDs). A failed full-donor parity invalidates causal interpretation at that site and remains in the ledger. Also test a separately frozen early-stage active-time-row donor patch and a same-width displaced-time-row patch on **all** cases; the nominal active/padding boundary is measured from processor geometry before outputs are opened. Bidirectional context means those rows are not isolated acoustic instants, and a negative displaced patch does not prove absence of information there. Record realized edit norms, source/donor/pre/post tensor hashes, full output, and every failure.

If a nonempty output becomes the silence donor's complete output under a full encoder-state transplant while self and random controls do not, that supports **sufficiency of the encoder state at this artificial interface for that case**. It does not identify a unique neuron, prove the decoder has no language prior, or show an attacker-suppliable exploit. If the silence donor itself emits text, use exact token transfer rather than calling it a rescue. Forced-English decoding may be used as a separate prospective prompt-control study; it must not be mixed into this auto-language primary result. A later audio-language/action study would need an unmodified waveform to change a consequential decision under an explicitly specified harness. This pilot alone cannot be called a security vulnerability.

## Admission and decision

The included generator and tests do **no candidate inference**. Before any candidate weight is loaded: independently review this exact spec/renderer/protocol; render and independently audit the 20 WAV bytes; pin multilingual Whisper checkpoint files and the resolved auto-language implementation; implement and independently review bounded no-hook runners; then freeze and review the intervention source separately. A null result is still useful: report whether a chosen architecture emits no text and where its internal representation changes under non-speech input. The current run decision is **HOLD**.
