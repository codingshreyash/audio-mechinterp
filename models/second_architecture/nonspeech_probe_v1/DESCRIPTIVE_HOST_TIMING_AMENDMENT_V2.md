# Prospective V2 host timing amendment

19 November 2026. **HOLD for a new candidate-model attempt.** This amendment changes only the parent host-log fence for a new one-shot multilingual Whisper attempt. The frozen 20 waveforms, model bytes, worker, saved-record scoring, and V1 attempt remain unchanged.

The first attempt `descriptive_whisper_multilingual_20261119_v1` exited with worker code 0, but the parent recorded `invalid_or_partial` because its after-host power-log check failed with `Host power-log coverage is stale or truncated`. Its parent result SHA-256 is `806bfd0c84899e88cec47b24b0966274561cdd155908c52369d0699496c2404a`; its records byte SHA-256 is `984625850ac33cd4c5d039304162a9b4396bd2a2ad3d31513a231eb452e708a3`. This amendment does **not** inspect, score, relabel, or repair that attempt's model outputs. It remains invalid and immutable.

The parent previously called the post-run host probe, then set `finished_utc` **after** that call and required the probe's second-resolution `pmset` terminal timestamp to cover that later time (with a one-second tolerance). A no-weight reproduction had terminal `08:11:11`, probe collection `08:11:11.611`, and after-call finish `08:11:12.087`; the terminal was earlier than `finish - 1 second` by 87 ms. The log could be current at collection yet fail because the parent compared it to a future time. This is a timing-check bug, not a successful model audit.

For V2, record `worker_exit_observed_utc` immediately after the bounded subprocess has exited and **before** starting the after-host probe. Freeze that as the end of the worker interval. Require the after-probe collection time to be at or after that timestamp and no more than 120 seconds later. Require the saved `pmset` log to cover from parent start through `worker_exit_observed_utc`, and to reach its own collection time under the existing terminal-snapshot rule. Reject any Sleep, DarkWake, Wake, or Thermal event from parent start through the probe collection, including the post-exit gap. Keep AC, open lid, external power, recent-transition, RSS, wall, disk, one-shot, and process-group controls. Save the post-host evidence **before** validating it so any failure remains auditable.

The V2 parent may use only the new absolute attempt path `runs/descriptive_whisper_multilingual_20261119_v2`. It requires the existing committed descriptive source GO, a new no-weight V2 preflight receipt binding the unchanged V1 attempt hashes and this amendment's source bytes, and a **later separately committed independent V2 GO**. V2 has no automatic retry. The current decision is **HOLD**.
