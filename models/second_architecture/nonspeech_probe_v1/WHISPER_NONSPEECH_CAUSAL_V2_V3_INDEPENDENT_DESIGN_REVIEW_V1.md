# Independent rereview: non-speech Whisper causal design amendments

19 November 2026. **GO for the amended prospective design; HOLD for executable source and candidate inference.** This rereview supersedes the two-donor-call count approved as a design in `e75264a`. I inspected the pre-inference [V2 donor amendment](WHISPER_NONSPEECH_CAUSAL_DESIGN_AMENDMENT_V2.md) at `79e1002`, the [V3 generation-arguments amendment](WHISPER_NONSPEECH_CAUSAL_DESIGN_AMENDMENT_V3.md) at `8e41109`, their revised planner, the valid descriptive worker source, and the source-only causal worker. No candidate model was loaded here.

The fixed schedule now has **328 complete generate calls**: for each of two same-duration silence donors, a true no-hook call followed by a separate read-only state-capture call; then 180 final-encoder and 144 pre-block-0 recipient calls over all 18 non-silence cases. The read-only donor's complete prefix/generated-token/EOS sequence must match its true no-hook counterpart before that donor state is interpretable. The donor calls and all Stage A/B calls have distinct names in the planner. The revised canonical schedule SHA-256 is `a4a77079c9381758720712f7b5420186e0b08a18c8f3fbbf1a99beb4926d087b`. The amended core float32 evidence calculation is `1,261,452,320` bytes; with the 256-MiB metadata allowance and 128-MiB reserve it fits the 2-GiB cap. Actual writes must still be bounded.

The V3 argument list matches the valid descriptive worker: `processor(..., return_attention_mask=True)` and generation with that mask, `task="transcribe"`, `language=None`, `return_timestamps=False`, `force_unique_generate_call=True`, `condition_on_prev_tokens=False`, `do_sample=False`, `num_beams=1`, `max_new_tokens=128`, `output_scores=True`, `output_logits=True`, `output_hidden_states=True`, and `return_dict_in_generate=True`. The installed generation path returns raw per-step logits, so a true no-hook donor can retain full raw-logit evidence without an encoder or detection hook. The prospective worker installs phase hooks only for non-`no_hook` arms. It also requires complete token parity with the valid descriptive V2 record for each case before interpreting an intervention.

I ran the no-weight planner and fake worker tests: **10/10 passed**. They cover the 328-call census, four donor calls, phase-specific hook selection, early active/displaced edits, seeded full-state random edits, and a mid-matrix failure ledger. These tests support source feasibility; they do not demonstrate actual candidate-model hook parity or causal effects. The V1 primary design remains explicitly post-descriptive; any result is a white-box case study on already inspected synthetic sounds, not a security finding.

The causal worker references a parent, saved auditor, tests, and executable handoff that are not part of this design review.
