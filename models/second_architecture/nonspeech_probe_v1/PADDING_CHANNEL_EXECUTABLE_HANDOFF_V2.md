## HOLD repairs

**Exact processor input:** The V2 worker saves one immutable float32 `[1,80,3000]` feature sidecar per each of the 20 trusted WAVs, before that case's first generate call. On each of 436 calls, it hashes the freshly processed features, requires exact equality with its case's saved tensor, records the same reference and pre/post-generate hashes, and validates the processor attention mask before writing or generating. The V2 auditor loads the pinned processor without model weights, recomputes features from all 20 pinned PCM arrays, compares every saved feature byte, and checks all per-call references, hashes, and masks. It also checks that the final sidecar inventory has no extras. The V5 core budget is **1,396,433,056 bytes**, including 19,200,000 feature bytes and 20,480 bytes of `.npy` header allowance. With the same 256-MiB auxiliary allowance and 128-MiB reserve, planned total is **1,799,086,240 bytes**, below the 2-GiB hard cap.

**Whole parent wall:** The V2 parent starts its monotonic 1,800-second deadline before its first write. The pre-host probe consumes that same deadline. The bounded worker receives only the remaining time **minus 480 seconds** reserved for post-host collection and final records, and is not launched if that window is nonpositive. The parent checks the deadline before/after host probes and before/after the final committed completion marker. A `launch_result.json` with status `candidate_complete` is not enough: `launch_completion.json` must be written after the result and within the same deadline to confer `completed_pending_saved_audit`. The V2 auditor checks that completion's result hash, elapsed time, UTC chronology, worker grant, and final whole-attempt cap all agree. A partial or overrun attempt has no valid completion marker.

**Whole parent evidence:** Before parent-managed launch, host archive, host JSON, result and completion writes, the parent counts **all** bytes under the attempt and adds proposed bytes. Nonterminal writes must retain the 128-MiB reserve; terminal writes cannot cross 2 GiB. The bounded worker monitor also checks whole-attempt bytes while the child runs, with its threshold reduced by the same 128-MiB parent reserve. Fake near-cap tests prove archive and JSON writes are rejected before creating target files. The saved auditor rejects a final attempt larger than 2 GiB.
