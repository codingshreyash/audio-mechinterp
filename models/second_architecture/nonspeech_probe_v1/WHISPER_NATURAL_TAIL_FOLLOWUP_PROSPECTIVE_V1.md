# Prospective ordinary-WAV test of the Whisper padding lead

19 November 2026. **Source-only design. HOLD for model inference until an independent executable review returns GO.** The [436-call result](PADDING_CHANNEL_ATTEMPT_003_INDEPENDENT_RESULT_REVIEW_20261119.md) showed that a white-box edit to nominal padding changed decoder scores, with one punctuation change and one 128-token censor among four output-informative beeps. It did **not** show that a person can obtain either effect by changing a WAV. This follow-up tests that missing step. It does not test a tool, authorization boundary, or deployed voice assistant.

## Frozen population and WAVs

Use all **20** already audited 16-kHz mono PCM16 WAVs in `runs/render_20261119_0740Z/manifest.json` (manifest SHA-256 `a37e6e6027611555cd65ceb1a8d9288b79c72460ae1155469eb1f094d7ddee90`). The 18 nonsilence files are the primary population; the two exact-silence files are negative controls and stay in the complete ledger. Four beeps are labeled *previously output-informative*, not held-out discoveries. The beep train runs throughout each original 2- or 8-second file, so **no original sample may be trimmed or replaced**.

The committed [source-only constructor](natural_tail_waveform_v1.py) fixes seven conditions per file: original `base`; append 8,000 or 32,000 zero PCM samples (`z8000`, `z32000`); or append the same count of independently seeded, two-valued background samples (`n8000_s0`, `n8000_s1`, `n32000_s0`, `n32000_s1`). The two noise seeds for each length are `(9405, 9406)` and `(9420, 9421)` respectively, using NumPy 2.3.5 `PCG64`; every noise sample is exactly `+32` or `-32` PCM16 units, or `0.0009765625` full-scale RMS. The same tail is used for every source at a given length/seed. It is appended *after* the last source byte. All original PCM prefixes must have identical SHA-256 to the source manifest. Every file remains below Whisper's 30-second window. The renderer must create the new fixed directory `runs/natural_tail_waveform_v1/source_v1` and a 140-row manifest before a run; its bytes and manifest are frozen and separately audited. No time stretching, gain, resampling, compression, or model-dependent selection is allowed.

This is **140 distinct WAVs per checkpoint**, for the pinned multilingual `openai/whisper-tiny` and English-only `openai/whisper-tiny.en` revisions and package/source hashes in `descriptive_pins_v1.json`. Include one exact `base` replay for each of 20 sources per checkpoint, giving **160 calls per checkpoint, 320 total**. A failed call remains in this denominator and is marked missing, never silently retried. Run the two checkpoints separately in frozen case/condition order; no output-adaptive probing.

## Frozen comparisons and interpretation

For each source and tail length, compare both seeded noise tails with the **equal-duration zero tail**. Compare zero tail with `base` separately. The 18 × 2 × 2 = **72 noise-versus-zero pairs per checkpoint** are the primary comparisons; the 18 × 2 = **36 zero-versus-base pairs per checkpoint** are duration/processor controls. Report all cases, not only the four beeps. A noise effect is *seed-replicated* only if both noise seeds at the same source/length change the EOS-complete prefix-plus-text sequence from that length's zero control in the same substantive way. Report token IDs and text, so punctuation, capitalization, lexical changes, language changes, and length censors remain distinct. A 128-token cap without EOS is **bounded repetition/censoring**, never an endless loop. An isolated score movement, one-seed flip, or capitalization change is reported at that narrower level. Exact `base` replays must have matching complete tokens and first-step vectors within numerical tolerance; otherwise hold behavioral interpretation for that checkpoint. The silence cases reveal whether any apparent effect occurs without the informative source audio.

Use the existing FP32 CPU Whisper generation path: processor `return_attention_mask=True`, automatic language detection for multilingual, `task="transcribe"`, `language=None`, no timestamps, deterministic greedy decoding, `condition_on_prev_tokens=False`, `force_unique_generate_call=True`, and `max_new_tokens=128`. English-only Whisper must use its native English prefix and have **no language-detection pass**. Save the full prefix IDs, generated IDs, decoded text, selected token scores, step count, EOS/censor status, and the **complete first-step raw decoder-logit and post-processor score vectors** for each call. For multilingual, save the detected language ID, candidate language logits, and resolved language-prefix ID. A language-prefix flip is not described as a lexical transcription flip. Save processor input-feature and attention-mask hashes for every WAV, and full input-feature tensors or lossless sidecars sufficient for an independent recomputation. Record exact generation arguments and pinned checkpoint/source hashes.

The **first analysis is byte/feature parity**, before reading generated answers. Recompute each source prefix, append length/values, WAV SHA-256, and independent PCM decode; check both noise seeds differ, zeros are exact, and fixed-length pairs have identical sample count and source prefix. Compare the processor's complete 80×3000 mel tensor, its nominal active and padded frame intervals, attention mask, global `log_spec.max()`, and its `max−8` floor. For each `base`/zero/noise pair, report maximum absolute delta, L2 delta, changed-frame count, and hashes **separately for original-source frames, appended-tail frames, boundary frames, and nominally padded frames**. Define boundary as the five mel frames before and after the original end and after the new end, and exclude those rows from interior summaries. If appending zero leaves all 30 seconds of padded PCM identical but changes a processor tensor or generation, investigate mask/preprocessing/runner behavior before attributing it to sound. A noise tail changes real active audio; even if padded frames change, correlation alone does not prove padding mediation. A global-floor claim requires the measured floor to change, padded-frame differences consistent with that floor, and a separately reviewed causal comparison that holds active information fixed. If the floor and padded frames stay identical, this run does not support that pathway for those cases. The previous white-box splice is a lead, not mediation proof for these WAVs.

## Independent review and resource gate

Before candidate inference, commit the render manifest, runner, fake-model tests, source-only admission, and independent executable GO in that order. A second reader should implement a separate WAV/PCM audit and recompute the complete 320-call schedule from the frozen source rows, not reuse the runner's own assertions. After the run, audit every call and sidecar SHA-256/shape; independently reconstruct first-step raw/processed vectors and full IDs/EOS outcomes; count missing, censored, and parity-failed calls explicitly. Preserve a failed attempt unchanged and amend the protocol before any new attempt. The saved 436-call attempt is immutable.

Run one local CPU FP32 worker at a time with no concurrent model load. Parent gates: AC power, lid open, no thermal emergency or sleep event, free disk for a **1-GiB evidence ceiling**, and available memory headroom before launch. Bound each checkpoint to **1,800 seconds**, process-tree RSS **4 GiB**, and evidence **1 GiB**; a ceiling hit fails the attempt without scoring partial output. Stop or defer if the host is hot, in clamshell, on battery, or under memory pressure. These caps are a proposed gate for the future executable and must be validated before GO. Do not start or alter any stopped cloud instance for this test.

The edited WAVs are attacker-suppliable in principle, but this engineered nonspeech set is neither a human-speech benchmark nor evidence of covert audio. Silence duration and ±32-LSB hiss may be perceptible, especially through headphones; do not call them imperceptible without blinded listening of the actual rendered stimuli. A useful positive result would justify held-out sounds and an action model with a defined trust boundary. A negative result narrows this natural-tail route only. Neither result alone is a security vulnerability.
