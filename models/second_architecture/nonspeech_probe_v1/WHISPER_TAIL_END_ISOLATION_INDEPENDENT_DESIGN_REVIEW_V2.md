# Independent design review: isolated Whisper tail/end translation, V2

19 November 2026. **PASS for source-only design at `f1c4aea` as clarified by `5a5cf7a`; HOLD V2 target inference until separate executable review, admission, and GO.** I reviewed the committed protocol against V1's frozen plan, independent raw-result audit, and saved original/translated `post_conv_pos` baseline states. I loaded no model weights and changed no V1 evidence.

The geometry and call census are internally consistent. An 8,000/16,000-sample zero offset at 16 kHz is 0.5/1 second, 50/100 mel hops, and 25/50 encoder rows after the stride-two convolution. The old tail/end five-row window is `498..502`; prepend places it at `523..527` or `548..552`, while append leaves the old noise-tail/silence interface at `498..502` and creates a nominal new waveform end at the later row. The schedule is **2 baselines + 5 arms = 7** original calls and **4 baselines + 2 × (8 local arms + 1 full-donor + 1 relocation) = 24** calls at each offset, **55 maximum**. Four translated baselines precede every arm in each offset attempt. An ineligible layout skips its prespecified ten arms, with no substitute input or arm.

I independently recomputed the motivating V1 `post_conv_pos` donor-minus-recipient L2 norms from saved baseline states. The original `498..502` norm is **8.1954066**. Append at both offsets has that same norm at the old interface and **0.0** at the nominal new-end window; prepend has about **8.1954066** at the shifted old boundary. The protocol correctly treats a zero native new-end edit as uninformative about whether the model uses the new end. Its nonzero, unscaled, equal-norm relocation of the aligned old-boundary delta to the competing window is the relevant location control. The `1e-3` nonzero threshold was set after V1 but before V2 inference and is explicitly tied to those archived norms and FP32 precision.

The primary rule requires original isolated tail/end viability, both clean translated contrasts, exact complete donor transfer at the aligned location in both layouts, preserved recipient paths under identity, unrelated-row, displaced equal-norm, and relocated equal-norm controls, full-donor positives with first-step vector equality, failed donor transfer at the competing location, stable language detection/prefix, and measured mel translation. It reports **x/2 offsets** and requires **2/2** for a within-pair timing result. A competing patch that produces a third answer is reported as a nonspecific effect; preservation of the recipient by that direct patch is a separate, stronger secondary result. The `5a5cf7a` amendment makes a fully recorded censored baseline an ineligible layout and a fully recorded censored arm a failed cell, while missing calls, resource failures, or broken GO invalidate the attempt. It also requires all three stages to run even if original viability fails, with no joint claim in that case.

This is a V1-informed follow-up on the **same already-open non-speech pair**, not an independent replication or a new security result. V1's union success and original isolated tail/end result informed this site and window choice; V1 did not establish an isolated translated tail/end effect. Even a 2/2 V2 result could reflect positional context, encoder-edge behavior, or interactions beyond the five edited rows. Append creates a later waveform end but no native zero/noise state contrast at that end, so the relocation specifically tests an imposed old-boundary delta there. A separately predeclared sound-family replication is necessary before a broader audio-mechanism claim; human speech and attacker-reachable behavior remain untested.

At executable review, freeze and inspect the exact unrelated-row selection/seed, all five-row mapping and relocation arithmetic, baseline and arm censor branches, complete-answer and prefix scoring, original V1 replay parity, and parent resource/evidence enforcement. This design PASS does **not** authorize a model run.
