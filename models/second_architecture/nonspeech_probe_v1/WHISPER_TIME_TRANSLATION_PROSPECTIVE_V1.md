# Whisper Tiny time-translation probe, V1

19 November 2026. **Prospective source-only design. No target-model inference is authorized by this file.** The question is whether the previously observed complete-answer rescue follows an acoustic boundary when the same waveform is moved later, or remains at an absolute encoder row. The prior qualified patch used the **union** of source/tail and tail/end windows; it did not isolate one boundary. This probe preserves that union for continuity and tests isolated windows separately. A positive result would concern an engineered non-speech input, not a security exploit or human-speech mechanism.

## Frozen inputs and acoustic alignment

Use only the already-open, 10-second `d08_beep_train_low` zero-tail and seed-0 quiet-noise-tail WAVs from the reviewed V4 source, in multilingual Whisper Tiny FP32 CPU. Their full-file SHA-256 values are `3e650da071ceb47c6a83b06bb00d13d8f4fde316dcc30d9cc2eb80fa16aa1220` and `28fa81a018d66cbb23ee2e471d56def5ace2113a73230bacf71de699d02a275b`. The [source renderer](whisper_time_translation_source_v1.py) has already committed eight derived WAVs and a byte-level [manifest](runs/whisper_time_translation_v1/source_v1/manifest.json), SHA-256 `eec732fb24a4b238ad0666d52d168f5ba41ec38c9d315a057a39e0d53be1435b`. It adds exactly 8,000 or 16,000 signed 16-bit zero samples either **before** or **after** each original PCM. For each offset, the prepend and append layouts have identical total duration and zero/noise pairs have identical attention masks. The added samples are silence in both variants. The unchanged source/tail boundary is nominally encoder row 400; the old tail/end boundary is nominally row 500. The 0.5-second and 1-second prepend move both boundaries by 25 and 50 rows. An append leaves the source/tail boundary at row 400 but adds a new waveform end at row 525 or 550. These are nominal local receptive-field indices, not isolated causal locations after self-attention.

Across the three separately bounded attempts, run **all 10** no-hook baselines: the original zero/noise pair and both layouts at both offsets, zero and noise each. Within each attempt, run its two or four baselines **before any arm in that attempt**; original-arm execution may precede the later translated attempts, but every translated contrast gate and arm is fixed here before any output. Save exact input hashes, PCM reconstruction, mel and mask tensors, full token paths, EOS/length-censor state, raw and processed first-step vectors, language-detection logits/prefix, and all three encoder states. The original pair must exactly replay its V4 output, mel, mask and first-step vectors. A translated pair is eligible for patches only if both outputs end in EOS, have the same detected prefix, differ as complete token paths, and have identical masks. Record a no-contrast or censored pair as such; do not select a new pair or substitute a shorter output. Verify exact zero/noise mask equality from the saved tensors. To operationalize the nominal 50/100-mel-frame shift, compare each translated baseline's saved mel to its original-variant mel in the predeclared interior frame windows `50..749` and `850..949`: prepend uses translated indices plus 50 or 100; append uses the same indices. Save the maximum absolute difference for each window and require it to be ≤1e-5 for a mel-shift-qualified claim. These windows exclude the original waveform front and source/tail edge; equality here cannot prove the boundary itself is local. A translation comparison requires both layouts at the same offset to be eligible; otherwise report its baseline results with no crossover claim.

## Predeclared intervention schedule

Use fresh `generate()` calls. Patch the transcription encoder pass only, leaving language detection unedited. At each site, save the original and edited full 1,500×384 FP32 state and prove all unselected rows unchanged. The sites are `post_conv_pos` and `post_block0`; after block 0, attention can mix rows, so its result is coordinate-specific. Use noise as recipient and zero as donor. The first stage uses the **original pair** and tests both sites at three windows: union `398..402 ∪ 498..502`, isolated source/tail `398..402`, and isolated tail/end `498..502`. Each window has direct donor transfer, identity sham, donor patch at a deterministic unrelated source-row set, and a displaced equal-norm donor-minus-recipient delta. Each site also has a full 1,500-row donor positive control. This is 2 no-hook baselines plus 26 arms, or 28 calls. Do not promote one isolated window after seeing its result. If the original clean pair loses its V4 contrast, stop all arms and report the replay failure.

For **each** offset, use a new one-shot attempt and both prepend/append layouts. At each layout, test the two sites at both a fixed and a translated **union** window, with the same four arm kinds, plus two full-donor controls. At `post_conv_pos` also test the isolated source/tail window at fixed and translated rows with the same four kinds. Add one **cross-window equal-norm relocation** for each of these three site/window combinations per layout: take the donor-minus-recipient delta from the prespecified acoustically aligned rows (translated for prepend; fixed for append), then apply that same 5- or 10-row delta to the competing rows, with no scaling. Its intervention L2 norm therefore equals the aligned-window direct delta's norm by construction. Thus each offset has four no-hook baselines plus at most 58 arms, or **62 calls**. A pair with no complete clean contrast gets no intervention arms; the other pair still retains its prespecified arms. Fixed windows are union `398..402 ∪ 498..502` and isolated source/tail `398..402`; translated windows add 25 or 50 to each row. In a prepend layout the translated windows track the moved waveform, while in an append layout the fixed windows track its unchanged source/tail boundary. Deterministic unrelated source rows are selected from `20..300`, with equal count to the target window and no overlap. The full-donor control is site and layout specific. Record donor-minus-recipient norm at every tested window; a zero-norm target is weak evidence and cannot qualify a location claim. No patch may change the input waveform, mel, mask, detected-language logits, or resolved prefix.

The direct transfer succeeds only if it produces the **exact full donor token path with EOS**. A window is control-qualified only if identity, unrelated source-row donor and displaced equal-norm controls preserve the complete recipient path, its direct transfer succeeds, and the full-donor control reproduces both the donor complete path and exact donor first-step raw vector. Record all failed and censored arms. For a union crossover at a given site and offset, require the original union window qualified at that site, both translated pairs eligible, mel-shift qualification, a qualified **translated** union on prepend, a qualified **fixed** union on append, the opposite direct windows failing donor-path transfer, and the cross-window equal-norm relocation preserving the recipient path in both layouts. Report `x/4` layout/site cells even when this strict criterion fails. This is a combined-boundary timing result; it does not identify which of the two boundaries matters.

Claim isolated **source/tail event tracking** only if the original isolated `398..402` post-convolution window is control-qualified, both translated pairs are eligible, mel-shift qualification passes, prepend shifted `398+δ..402+δ` and append fixed `398..402` are control-qualified, their opposite direct windows fail donor-path transfer, their cross-window equal-norm relocations preserve the recipient, all aligned target deltas are nonzero, and no other equal-norm control transfers. If the isolated original viability fails, report translated isolated outcomes descriptively with **no** event-tracking claim. The isolated tail/end original viability is a separate result, not a substitute for source/tail viability. Neither union nor isolated result proves a neuron, necessity, human intelligibility, attacker reachability, or a security violation.
