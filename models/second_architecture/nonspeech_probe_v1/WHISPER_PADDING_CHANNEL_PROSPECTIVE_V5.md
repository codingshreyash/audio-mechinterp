# Amendment V5: exact input features and whole-attempt limits

19 November 2026. **Source-only correction after the [independent executable HOLD](PADDING_CHANNEL_INDEPENDENT_EXECUTABLE_REVIEW_V1.md). No candidate inference.** V1–V4's 436-call V3 schedule, model pin, intervention matrix and claim limits remain unchanged. This amendment governs the new V2 worker, parent, auditor and attempt_002 paths; the admitted V1 source, receipt and unused attempt_001 remain untouched.

## Processor input evidence

The worker must save one immutable float32 `[1,80,3000]` `.npy` feature tensor for each of the **20** frozen WAVs on that case's first scheduled call. Later calls for the same case must hash the freshly processed tensor, require exact byte equality to the saved case tensor, and record the same sidecar reference and actual pre-generate and post-generate feature hash in every call. A duplicate sidecar is prohibited. The worker must compare each call's processor attention mask to its same-duration donor and save full mask geometry. The read-only auditor must independently run the pinned processor on each trusted PCM without model weights, compare exact feature bytes to the 20 saved sidecars, and verify every one of the 436 per-call feature references, hashes, masks and case bindings. A changed feature or mask invalidates the call; a source/processor drift blocks admission before inference.

The [V5 planner](padding_channel_plan_v5.py) retains the exact V3 schedule SHA-256 `d939618689e989a2dfe249cc6d4f0d3b32a532c184991680b77f11b4af6a0ace`. Twenty feature arrays add 19,200,000 bytes plus a conservative 20,480-byte `.npy` header allowance. The revised core bound is **1,396,433,056 bytes**; with the 256-MiB auxiliary allowance and 128-MiB reserve, the planned total is **1,799,086,240 bytes**, below the unchanged 2-GiB hard cap. Actual whole-attempt bytes must be checked before every parent-controlled write and every worker write. The arithmetic is a planning bound, not a runtime observation.

## Whole parent deadline and evidence cap

The 1,800-second wall limit starts before the first parent-managed attempt write and covers the pre-host probe, worker, post-host probe and final result. The parent passes the bounded worker only the **remaining time after the pre-probe minus a fixed post-probe/result reserve**; if no positive worker window remains, it fails closed. It checks the deadline before/after each host probe and before/after the final result write. A run cannot receive `completed_pending_saved_audit` if the final committed result is beyond the deadline. The saved auditor independently checks start/end timestamps and the reported parent elapsed time against 1,800 seconds. Fake clocks must prove that pre/post overhead cannot be hidden by starting a fresh 1,800-second worker window.

Before writing the launch start JSON, either compressed host log, either host JSON, and the terminal result JSON, the parent must calculate proposed bytes against **the entire attempt directory**, preserve a terminal-record reserve for all nonterminal writes, and reject a near-cap write before it occurs. The bounded worker monitor continues to check all attempt bytes, while the worker's own reserve applies to its output directory. The final result cannot itself cross 2 GiB. Fake near-cap writes must demonstrate rejection without creating or expanding the target artifact. The auditor rejects final over-cap attempts. All failures and censored calls remain in the ledger.

The new executable must also directly test the full fake call path: RR has no hook; donor and recipient read-only outputs match no-hook, and duplicate captures agree; DD matches the donor's complete tokens and all raw decoder steps; a changed processor mask or feature hash fails before generation; source hash drift fails admission. The exact V4 processed `-inf` mask and `[1,4,384]` decoder-state rules remain mandatory.

This amendment requires a new committed source-only admission and an independent executable GO committed afterward. It does **not** authorize a model load or a live run.
