# Amendment V2: donor capture, no-hook controls, and execution gates

19 November 2026. **Prospective source-only correction. No candidate model was loaded or run.** This amendment supersedes the 434-call count, donor-state source, and nonspecific evidence requirements in [V1](WHISPER_PADDING_CHANNEL_PROSPECTIVE_V1.md). It resolves the [independent design HOLD](WHISPER_PADDING_CHANNEL_INDEPENDENT_DESIGN_REVIEW_V1.md) for a **design rereview**. It does not authorize candidate inference: the worker, fake-model hook tests, admission and independent executable GO remain required.

## Self-contained donor and recipient state provenance

The [amended no-weight planner](padding_channel_plan_v1.py) freezes **436 calls**, schedule SHA-256 `1dbbbc07183bd6b93b94feffeaaf90c9c28ebadb2699f8e5ff361b2399097951`. Its first four calls are, in order, `d02_silence/no_hook`, `d02_silence/read_only_donor_capture`, `d08_silence/no_hook`, `d08_silence/read_only_donor_capture`. A no-hook call installs **zero hooks** and supplies the donor's complete output and full per-step raw logits. Its separate read-only call installs capture hooks at the first-convolution input (`log_mel`) and immediately before encoder block 0 (`pre_block0`) in **both** automatic language detection and transcription passes. The read-only hook returns its input unchanged. Save all four phase/site donor tensors as immutable binary sidecars, plus processor input features and attention mask. The donor capture call must exactly match its paired no-hook call in complete prefix/generated IDs, EOS, step count, selected language, first raw-logit vector, first processed-score vector, and first final-layer decoder hidden state; numerical vector max-absolute difference must be at most `1e-5`. A failure invalidates that duration donor for both sites.

For each of 18 non-silence cases at **each** site, `RR` is a true no-hook recipient call; the separate `read_only` call captures both sites and both phases without editing; `self` replaces by immutable recipient-native bytes. Save native tensors once per case/site/phase and compare the duplicate read-only capture from the other site's 12-arm block by exact shape/dtype/content hash. Require exact complete-output and first-vector parity among `RR`, `read_only`, and `self`, and between the two `RR` calls for a case. This makes every donor and recipient tensor used by `RD`, `DR`, `DD`, phase-split, and random arms traceable to **this run**, with no dependency on an earlier attempt's sidecars. The earlier saved study remains context, not an input.

Within each duration, independently verify the processor feature shape `[1,80,3000]`, mask shape and 200/800 active-frame count, early-state shape `[1,1500,384]`, and exact recipient/donor mask equality. Save native and realized edited-state hashes, tensor dtype, shape, changed interval, L2 norm, random seed and cosine to donor displacement for each phase. Reject a missing or repeated detection/transcription encoder forward, changed preprocessing, fallback, chunking, or any out-of-support mutation. A failed control or missing/censored call stays in the all-18 ledger and invalidates only the local causal comparison; it is never reclassified as a negative result.

## Exact evidence and numerical acceptance

Every one of 436 calls must save full prefix and generated IDs, selected language, decoded text, EOS or length-censor status, and full first-step **raw logits** and **processed scores** as float32 binary vectors of length 51,865. Save the first decoder step's final-layer hidden state as a float32 vector of width 384, plus the selected-token processed score as a float32 scalar at every generated step. Save full per-step raw-logit vectors for the **two no-hook silence donors and all 36 `DD` arms**; do not omit the donor targets. A 128-token length cap is a censored endpoint, not an EOS match. The source and binary sidecars must carry shape, dtype, byte count and SHA-256; the independent auditor rehashes and decodes them.

`DD` must match its same-duration no-hook donor's complete token path and all saved per-step raw logits at max absolute difference `≤1e-5`. For donor read-only/no-hook and recipient `RR`/read-only/self comparisons, require complete token path equality and max absolute difference `≤1e-5` for first raw logits, first processed scores, and first decoder hidden state. Require selected-language equality too. These are deterministic acceptance rules; they replace V1's “where the prior audit format supports them.” Raw-versus-processed first-step differences stay visible for the decoder-policy interpretation. If an array is absent or nonfinite, parity fails; no equality of decoded strings can rescue it.

Freeze worker, parent, auditor, fake tests, schedule, protocol, source hashes and generation arguments in the admission receipt. Reject version/source/weight drift before deserializing candidate weights.

The hard ceilings are **1,800 seconds parent wall time, 4 GiB sampled process-tree RSS, and 2 GiB actual evidence bytes**. Reserve 128 MiB before each forward or write and budget 256 MiB for metadata and auxiliary artifacts. The conservative core float32 estimate in the planner is **1,375,203,488 bytes**: 436 first raw vectors, 436 first processed-score vectors, 38 calls × 128 full raw vectors (two donors plus 36 `DD`), 80 native-state tensors counted at the larger `[1,1500,384]` size, 436 first decoder-state vectors, and up to 128 selected-score scalars for all 436 calls. This deliberately double-counts first raw vectors in the full-logit calls; combined with allowance and reserve it is 1,777,856,672 bytes, below 2 GiB. It is **not** permission to exceed the cap: the worker must check actual output bytes and remaining reserve before each forward and write, record censored failures, and stop cleanly. A sampled RSS cap cannot exclude a transient peak between samples.

Require AC power, open lid, no thermal emergency, and a ten-minute pre-run host log before a candidate run. Fence the post-run sleep/wake/thermal log through the exact worker-exit timestamp, and collect it within 120 seconds. No retry or output-guided arm omission. The current unstable Mac battery/thermal state is a run HOLD until the host gate passes. CPU FP32, `eval()`, one-sample batches, deterministic generation, automatic language detection and the valid V2 call arguments in V1 remain fixed.

## Required fake-model tests before executable GO

The next worker source review must be against **executable** no-weight tests, not only the planner tests. A fake processor/model with sentinel tensors must prove: (1) both donor capture calls perform one detect and one transcription capture at **both** sites, with zero edited elements and no change in output; (2) `RR` installs no hook at either site; (3) recipient read-only calls capture both sites/phases and self returns exactly the saved native bytes; (4) `RD`, `DR`, and `DD` take the declared active/pad rows and channel axis for 2-s and 8-s shapes, without changing anything outside their intended support; (5) detection-only and transcription-only edits affect only the named phase; (6) random controls use the declared support, per-phase seed and realized L2 norm, including a zero-norm donor case; (7) donor/recipient captures are immutable and duplicate captures hash identically; and (8) changed mask, shape, source hash, duplicate/missing phase call, nonfinite array, evidence cap or reserve breach fail closed. Bind the test files and worker by SHA-256 in a new independent executable GO. None of these tests has run yet, and this amendment cannot substitute for them.

The primary question and claim boundary remain V1's: a white-box padding effect would be a within-checkpoint causal result, not proof of an attacker-suppliable waveform effect or a security finding. The waveform-level tail/duration test must be frozen separately after this assay and its independent audit.
