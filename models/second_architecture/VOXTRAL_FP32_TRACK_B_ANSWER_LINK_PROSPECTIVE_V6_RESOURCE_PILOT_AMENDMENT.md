## Frozen no-weight geometry

The no-weight preflight must process every selected Track B clip with the frozen prompt and pin the maximum input-feature tensor shape, audio-placeholder count, projector row count implied by that count, attention-mask length, and waveform sample count. Construct one deterministic 16-kHz all-zero PCM pilot waveform. Starting at the maximum selected sample count, increase its sample count in multiples of 128 only until its processor output has **each** shape/count at least the corresponding selected maximum; freeze the first such length and its PCM, processor-input, and prompt-ID hashes. If the processor cannot create that componentwise maximum within the 2-GiB output and 12-GiB free-disk gates, stop. The synthetic waveform is a timing input only and is never a Track B study case. Freeze one maximum-length V5 alias token-ID sequence including EOS, using V5's longest-length and lexicographic tie rule, for every pilot score call. No measured answer, likelihood, or gradient may select geometry or aliases.

## Fixed measured pilot after QA

Run exactly two **natural** old-FIT silver clean/zero generations under the previously frozen FIT prompt for plumbing parity, then exactly two synthetic-zero-audio generations under the Track B prompt with greedy decoding and `min_new_tokens=max_new_tokens=32`. The latter must emit exactly 32 suffix tokens, invoke the same one-prefill projector hook and FP32 MPS model path as Track B, and differ from Track B generation only in the EOS-suppression setting that forces the full permitted length. They are timing calls; do not inspect or retain their token IDs or decoded text. Capture only a hash of each complete suffix, the length, timing, hook count, input shapes/hashes, source-state hash, peak MPS driver allocation, and control parity. The source state for the synthetic score calls must be captured during a forced generation. Run exactly 72 singleton no-grad and 12 singleton differentiable score forwards on that same synthetic audio/prompt/maximum-length alias, with `logits_to_keep=Li`, one hook each, and no alias batching. Record timing and peak MPS allocation for every call; seal score values and gradients from study analysis, retaining only finite/parity indicators and hashes. No extra source-capture forward is reserved.

The first forced generation is an unpatched clean arm with a read-only one-call projector capture; it supplies the synthetic source state. The second is an exact-zero hook arm using that captured state. Require equal 32-token suffix hashes, equal prepatch source hashes, and bitwise pre/post projector equality in the zero arm. Both forced-generation elapsed times enter `t_g`; neither output may be inspected or used to select a study parameter. A missing capture or failed parity makes the pilot HOLD.

This entire pilot, including model load/setup, two old-FIT plumbing generations, two forced generations, 72 score forwards, and 12 backwards, has a 240-second model-work cap, 30-GiB MPS driver cap, 2-GiB new-output cap, and V3+V4+V5 host/clock/no-retry rules. A failed or interrupted pilot stops V6. No substitute input, faster second attempt, or after-the-fact shorter output bound is allowed. The shape-matched forced generations and 20% margin are an engineering feasibility screen, not a proof of every future runtime; the live per-context and cumulative caps still apply.

## Immutable post-pilot admission

Before the first Track B answer or score, a separate frozen auditor must issue a content-addressed pilot receipt, then an independent reviewer must give a GO bound to that exact receipt. Bind the 32/32 QA receipt, selected WAV and processor hashes, synthetic PCM/processor geometry, longest alias IDs, pilot and Track B runner/auditor source hashes, model checkpoint and installed source hashes, host logs, every planned/attempted/missing pilot call, call-class times, MPS peaks, and clock checks. A pre-pilot no-weight receipt cannot substitute for this measured receipt. Any absent call or failed parity/host/cap check is HOLD.

Let `t_g`, `t_s`, and `t_b` be the **maximum observed elapsed time per call** among the two forced 32-token generations, 72 no-grad score forwards, and 12 backward forwards respectively. Let `P` include all measured pilot model work, including setup and old-FIT controls. With no separate Track B source-capture call, admit only if both `1.2*(7*t_g + 72*t_s + 12*t_b) <= 240 seconds` and `1.2*(P + 16*(7*t_g + 72*t_s + 12*t_b)) <= 3,840 seconds`. Reject missing/nonfinite/zero timings. A later runner that needs separate capture is outside V6 and requires a new prospective amendment. Retain the measured receipt even if infeasible. Do not loosen either cap after observing model outputs.

Passing this screen authorizes only the frozen 16-context Track B experiment, subject to its per-attempt host, memory, disk, clock, and time gates. It does not establish an answer link, a time-localized mechanism, a reusable lens, or a security finding.
