# Voxtral FP32: fresh-word answer-link check (prospective)

**Question.** Does the numerically validated audio-state Jacobian method predict a change in a *complete generated answer* when applied to new words and an independent synthetic voice? This is a small model-level corroboration, not a reusable lens, an attacker-reachable input attack, or a security finding. The separate corpus-v2 480-WAV study and corpus-v1 locked test remain sealed.

## Population and admission

Use exactly the **first four pairs in the fixed Track B order** in [the reviewed V2 word-disjoint plan](WORD_DISJOINT_TIME_STATE_VALIDATION_PLAN_V2.md): `banana`/`tomato`, `carrot`/`cookie`, `train`/`plane`, and `ferry`/`taxi`. Use both Piper Amy and macOS Samantha and both directed word orders: 4 pairs × 2 voices × 2 directions = **16 recipient contexts / 16 WAVs**. No output-based selection or replacement. The other 16 Track B WAVs are not candidate-model inputs for this small Voxtral experiment, but the **entire 32/32 independently audited, blinded human-listening GO** and a source/manifests review must pass before any Voxtral inference. Recompute the Track B cross-corpus word exclusion, paired-PCM equality outside the frozen word slot, 16 WAV hashes and format, and complete processor input hashes. If any gate fails, stop; do not substitute a pair or voice. Samantha is a different synthetic engine, not a human speaker.

The fixed audio script is `I said {word} and then stopped.` The fixed Voxtral text prompt is **`What word did the speaker say between "said" and "and"? Answer with exactly one word. No explanation or punctuation.`** Freeze and hash its token IDs and the processor batch for all 16 clips before weights load. This prompt differs from the old FIT question because these new clips contain a statement; the change is declared prospectively and limits direct comparison. Keep every baseline in the planned population, including wrong, extra-word, and missing-EOS answers.

Use the pinned `mistralai/Voxtral-Mini-3B-2507@3060fe34b35ba5d44202ce9ff3c097642914f8f3` checkpoint as a whole FP32 model on MPS, frozen/eval, no autocast, greedy generation with EOS ID 2 and `max_new_tokens=32`. Pin the exact installed Transformers source and attention implementation to the reviewed FP32 gate. Before Track B, allow **one** old-FIT `silver` recipient replay only to test that the FP32 generation hook is neutral at alpha zero and returns the same complete answer as no hook; its output is plumbing evidence and never a study case. Do not use old-FIT results to alter this protocol.

## One model boundary and predicted effect

Intervene only at the output of `model.model.multi_modal_projector`. Derive the Track B projector word rows from the frozen half-open PCM word slot using the same prospective center rule as FIT, `160*(8*r+3)` samples for row `r`, clipped to actual projector rows. This is a nominal clock, not proof of a causal receptive field. Require equal source shapes and prompt/audio-token geometry within each matched pair. Do not assume the old 375-row geometry if Track B lengths differ; record and validate the actual shape before an edit. For recipient source state `H`, matched donor state `H_d`, and fixed word rows `R`, define `d = mean_R(H_d) - mean_R(H)`; add `alpha*d` to each row in `R`. Natural source states must be captured under the same prompt and FP32 path, hashed, and inspected for finite/nonzero `d` before any edit. Do not learn a direction from answer outcomes.

For each context, freeze tokenizer IDs for the canonical initial-capital recipient and donor words **plus terminal EOS**. Define the complete-reply teacher-forced margin `S(alpha) = log P(donor word + EOS | audio, prompt, edit) - log P(recipient word + EOS | audio, prompt, edit)`. Sum token log probabilities across the entire reply, including EOS. On two differentiable clean scoring forwards, compute both source gradients, subtract them, and form `J = sum_{r in R} grad_S[r] dot d`. Predict `S(+0.1)-S(0) ≈ +0.1 J` and `S(-0.1)-S(0) ≈ -0.1 J`. The prior four-coordinate random LM29 Jacobian establishes numerical feasibility only; it does **not** predict this answer margin. A two-candidate margin also does not characterize all possible free generations, as the earlier `deer`/`dear` case shows.

Run the following fixed complete-generation arms per context: unhooked clean, exact-zero hook, `+0.1 d`, `-0.1 d`, `+0.1 u`, `+1.0 d`, and whole-projector donor-state replacement. The seed-derived `u` is one random width-matched vector per context, drawn before inference, orthogonalized against `d`, scaled to `||d||₂`, and applied to the **same word rows**. It is an equal-norm specificity control, not a null guaranteed to preserve output. Whole-state donor replacement must reproduce the natural donor's entire generated suffix exactly; each donor's natural output is already captured as the opposite direction's clean arm. `+1.0` is a nonlinear stress arm and cannot be credited to the local derivative. Run no adaptive alpha or reroll after outputs. Measure `S` for clean, zero, ±0.1, random +0.1 and +1.0 with the same hooks under no-grad deployment; use each context's own baseline. The clean differentiable score and no-grad zero score must agree within `1e-4` margin units or that context is invalid for Jacobian comparison.

## Endpoints, controls and decision

The **primary endpoint** is the complete, freely generated suffix: exact token IDs, decoded text, and terminal EOS. Classify it with the frozen strict FIT classifier as `recipient`, `opposite`, `other`, `missing_eos`, `malformed_special`, or `malformed_surface`. A donor switch requires clean and zero both `recipient`, the edited suffix `opposite`, and terminal EOS; all other outcomes remain in the denominator. Record full donor baseline and whole-state replacement exact-ID parity, zero-hook bitwise source/answer parity, hook count, source shape and hashes, realized edit norm, all token log probabilities, runtime, and MPS peak. Any zero or full-donor parity failure holds that context for causal interpretation and is reported, not dropped. One prompt hook is expected per generation; extra or missing calls are invalid.

Report **all 16 contexts**, grouped by word pair and voice. For every context report `S(0)`, `J`, predicted and measured signed ±0.1 margin changes, random-control change, complete-answer class in every arm, and the +1 stress outcome. A local score prediction passes that context only if `|0.1 J| ≥ 0.02`, both signed measured deltas have predicted signs, and each error is at most `max(0.05, 0.25*|0.1 J|)` log-probability units; a smaller prediction is **unresolved**. In contexts with a measured ±0.1 margin crossing zero, separately ask whether the *same* edit changed the whole answer. A crossed two-candidate margin without a switch falsifies sufficiency of that margin for free generation in that context; a switch without predicted score movement falsifies this Jacobian explanation. If no local margin crosses zero, this study cannot establish a categorical answer link even if score transport is accurate. A +1-only switch is nonlinear evidence. Compare donor-direction and random-direction answer effects over the complete planned 16; a comparable random effect defeats direction-specific interpretation.

**Advance only to a separately specified wider study** if at least 12/16 valid contexts (including at least one pair in each lexical category and both voices) pass the local score criterion, at least four valid contexts across at least two pairs show a correctly predicted complete-answer switch at `|alpha|≤0.1`, and donor switches outnumber random-control switches by at least four contexts. These are engineering gates, not significance tests; the two directions of a pair are correlated. If the score gate fails, inspect the score graph and hook parity; if it passes without answer switches, report a score-level result and design a separate boundary test. No result here licenses a held-out or security claim.
