# Wav2Vec2 FIT baseline and stage-capture gate — prospective v1

18 November 2026. **Design only: no Wav2Vec2 weights have been loaded for this gate.** This is the first live step in [the source-level feasibility note](WAV2VEC2_CROSS_ARCH_CAUSAL_FEASIBILITY_V1.md). It measures clean CTC transcription eligibility and where an exact-PCM spoken-word contrast first becomes nonlocal. It performs **no causal patch**, no locked-test inference, and no security test.

## Frozen inputs and modes

Use exactly eight already-open FIT `fit_chosen` WAVs: `color_05` (`silver`/`teal`) and `object_02` (`plate`/`cup`), each in Piper and Kokoro. Rehash `eval/audio_jlens/corpus_v1/rendered/manifest.json` as `adf8cd02d24a43ef576bcb993dc54bd2527440a62798e12fc788def3c063971f`, every WAV and raw int16 PCM against its entry, require 16 kHz mono and equal length outside the declared word slot. Preserve exact script/word identities and all eight clean outputs even if CTC misses a word. Do not open corpus v2 or a locked test.

Model: cached `facebook/wav2vec2-base-960h` revision `22aad52d435eb6dbaf354bdad9b0da84ce7d6156`, `model.safetensors` SHA-256 `8aa76ab2243c81747a1f832954586bc566090c83a0ac167df6f31f0fa917d74a`. Use the stock `Wav2Vec2ForCTC` and `Wav2Vec2Processor`, CPU float32, `eval()`, `torch.inference_mode()`, four CPU threads, no downloads, batch size one, no attention mask (as the pinned stock feature extractor specifies for this checkpoint). Freeze all cached snapshot asset hashes, installed source hashes, versions, eight inputs, and source Git commit in a no-weight preflight before loading model weights.

Run both complete-waveform modes for each of the eight cases, in the fixed order pair `color_05` then `object_02`, engine Piper then Kokoro, word in manifest order, mode `S` then `C`. **S** is stock per-utterance `Wav2Vec2Processor` normalization on an unpadded waveform. **C** is a deliberate counterfactual: compute one float32 mean/variance from the PCM samples outside the word slot, which are bitwise common to the pair, and use those same statistics in `(waveform - mean) / sqrt(variance + 1e-7)` for both complete waveforms before the same model forward. Require Mode C input arrays to be bitwise identical outside the raw word slot. Record common statistics. Mode C is not a stock request or an accuracy benchmark.

## Captures, traces and complete CTC output

For every one of the 16 model forwards, save lossless CPU float32 `.npy` tensors for `input_values`; first convolution output before GroupNorm (`first_conv_raw`); first convolution GroupNorm output before activation (`first_conv_norm`); final feature-convolution output (`final_feature_conv`); projected feature hidden state (`feature_projection`); the input to transformer block 0 after positional convolution/norm/dropout (`encoder_pre_block0`); post-blocks 0, 5, 11; and all 32-label `logits`. Capture exactly one call per stage with hooks and verify shape, dtype, finiteness and CPU placement. Preserve full argmax frame IDs, CTC-collapsed decoded text, normalized words, frame count, output hashes and elapsed/RSS measurements. For a clean direction to be eligible, the complete transcript must contain its intended word exactly once and exclude the paired word; record every ineligible case without altering this matrix. No EOS concept applies to CTC.

For each pair/engine/mode, form donor-minus-recipient per-time-position L2 and maximum-absolute differences for every saved stage, with deterministic word order from the manifest. Save lossless float32 one-dimensional trace sidecars, file hashes, first exact nonzero index (`maxabs > 0`), and maximum difference outside a frozen nominal raw receptive-field window. For raw `input_values`, that window is the declared PCM slot `[s,e)`; for first-conv stages it is `[ceil((s-9)/5), floor((e-1)/5)+1)`; for all later stages it is `[ceil((s-399)/320), floor((e-1)/320)+1)`, clipped only to the actual stage length. These are **possible direct convolutional influence** windows, not proven word boundaries. Verify state shape consistency and store stage names and window in each trace row. A nonzero outside difference under S can originate in per-utterance normalization; under C, a first-conv pre-GroupNorm outside difference would violate the local-input expectation, while GroupNorm may create it before attention.

Save an append-only `records.jsonl` with one preflight row, 16 baseline rows, eight pair/engine/mode trace rows, then one completion row: **26 total on success**. The baseline row binds its mode, pair/engine/word, source WAV/PCM hashes, input and capture hashes/shapes, hook counts, complete CTC argmax/transcript and eligibility. A failure row preserves the error and every already-computed output; a saved-data auditor must reject incomplete attempts as scientific results. Save all stage files before writing the row that refers to them.

Bound this local gate to 30 minutes, 4 GiB peak process RSS and 2 GiB output directory bytes, checking between every forward and at completion. The first-conv tensors alone may approach 1.2 GiB across the 16 cases, so keep large raw sidecars local and bind them by SHA-256 in a small tracked manifest rather than adding them to Git automatically. Do not change precision or discard a stage after observing results. Commit and independently review runner, no-model tests, auditor, and no-weight preflight before inference; independently review the saved outputs afterward.

This is an architectural measurement, not a new security finding. Even a valid stage-locality pattern is specific to these synthetic FIT recordings and this older English CTC checkpoint. Causal intervention needs its own later frozen matrix and full-transcript controls.
