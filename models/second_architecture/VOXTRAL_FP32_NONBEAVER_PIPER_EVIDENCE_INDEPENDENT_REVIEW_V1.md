## Limit

The saved-data audit validates retained tensors and numerical consistency. It cannot independently prove the earlier live model execution or that a perturbation worked. I did not inspect efficacy metrics, run model inference, or change model code. This record supports two completed and saved Piper contexts, a reproducible pre-start rejection for the next context, and a plausible system interruption during the second run. Completing the four-context design requires an explicitly new campaign protocol or a documented gate change; the existing frozen gate rejects continuation.
