## Question and provenance

Can replacing the internal state over the *acoustic word window* make the full CTC transcript follow the paired recording, and how does this compare with equal-width nonword patches? This is a within-checkpoint causal assay, not a security test. Reuse the eight already-open FIT WAVs (Piper and Kokoro `silver`/`teal`, `plate`/`cup`), both directed swaps per pair, under each of the baseline's two modes: **S**, the stock per-utterance Wav2Vec2 normalization, and **C**, the shared outside-word normalization counterfactual. Bind the run to the baseline `records.jsonl` SHA-256 `c9865f4ec306e57baf7dbfc7bd05037ec769034d95db70440972904fcab2507c`, its reviewed capture hashes, the pinned corpus manifest, model snapshot, installed source, tokenizer, and the exact preprocessing in a no-weight preflight. The new runner must rehash the donor and recipient source WAV/PCM and the needed baseline captures before loading weights.

The baseline auditor currently reports five clean-recipient directions per mode: `silver` in both voices, `plate` in both voices, and Piper `cup`. Three directions per mode have transcription errors: `teal` in both voices and Kokoro `cup`. **Primary target-word inference requires both the recipient and donor clean transcripts to contain their own intended word exactly once, exclude the paired alternative, and differ only at that one word.** On the saved baseline, only Piper `plate`↔`cup` meets this stronger condition: two directed swaps in S and two in C. Retain all sixteen directed swaps and report all outputs; the other twelve are descriptive, with no intended-word transfer denominator. Eligibility is locked by the independent baseline review and never recomputed from patch outcomes.

## Intervention matrix

For each of 16 directed swaps (four pair/voice cells × two directions × S/C), test two sites, each with seven arms: **W** donor rows in the frozen nominal word window; **P** donor rows in the immediately preceding equal-width window; **Q** donor rows in the immediately following equal-width window; **self-W** recipient rows in W; **full-donor** all donor rows; **R1/R2** independent Gaussian perturbations *in W* whose total L2 norm equals that direction/site's donor-minus-recipient W tensor. This is 224 patched forwards, plus any explicitly recorded calibration forwards. Freeze canonical direction/site order and assign `seed = 971103 + 4*d + 2*s + r` for direction index `d∈[0,15]`, site index `s∈[0,1]`, and random index `r∈[0,1]`. Use the pinned NumPy `Generator(PCG64(seed)).standard_normal(W.shape)`, scale in float64 to the donor-minus-recipient W L2 norm, cast to float32, then add to a cloned recipient W state. Reject zero or nonfinite W deltas rather than silently substitute a seed. Record every arm, including invalid/censored ones. P/Q receive the native donor values, not rescaled values, and all patch magnitudes are reported; equal width alone does not make their amplitudes comparable to W. Do not interpret a W/P/Q contrast as pure spatial localization if their delta norms materially differ.

The sites are (1) the first tensor of `model.wav2vec2.feature_projection`'s output tuple, shape `[1,T,768]`, **before** positional convolution and transformer blocks, and (2) the first tensor of encoder layer 11's output tuple, shape `[1,T,768]`, **before** the encoder's final layer norm and CTC head. Preserve each tuple's other elements unmodified. A hook must fire exactly once, modify a cloned float32 CPU tensor, keep shape and finiteness, and restore itself after each forward. The recipient's entire input waveform and preprocessing mode remain unchanged in every arm; donor state comes from the same mode and site. Verify that each arm differs from the recipient hidden state *exactly* on its declared rows (or is an exact self copy). Run CPU float32, `eval()`, no attention mask or masking, no gradients, same pinned `facebook/wav2vec2-base-960h` revision and load-report gate as the baseline. A post-block11 full-donor patch should reproduce the donor's baseline logits and frame IDs exactly; require this as a positive-control gate. The feature-projection full-donor arm should likewise reproduce the donor's logits and IDs, because the CTC path uses that first tuple member; if it does not, treat downstream patch semantics as failed rather than explaining away the difference.

Use the baseline's fixed raw PCM slot `[s,e)` and the seven-convolution receptive field and stride to define W at both sites: `[ceil((s−399)/320), floor((e−1)/320)+1)`. The frozen pair/voice windows are `color_05` Piper `[95,156)`, Kokoro `[105,179)`; `object_02` Piper `[95,134)`, Kokoro `[105,170)`. Let width `k = end−start`, P=`[start−k,start)`, Q=`[end,end+k)`; reject a case if either control exceeds `[0,T)` instead of moving the window after seeing outputs. W is a **nominal direct acoustic influence window**, not a learned CTC alignment or exact linguistic boundary. The complete-waveform model and CTC head can depend on frames elsewhere.

## Outcome and audit gates

For every arm, save the complete float32 frame-logit matrix (32 labels per frame), its SHA-256 and shape, complete argmax frame IDs, CTC-collapsed transcript, normalized words, changed-frame counts and logit distances against the recipient and donor baseline, patch tensor hashes, delta norm, hook count, and per-arm resource measurements. Decode with the pinned processor; CTC has no EOS. A **target-only complete-transcript transfer** means that the normalized clean recipient transcript becomes exactly its own baseline transcript with its sole intended word replaced by the clean donor's intended word, with all other normalized words unchanged. A changed CTC path, logit score, or partial word is a separate observation. Require self-W logits and IDs to equal the recipient baseline exactly and both full-donor arms to equal donor baseline exactly before interpreting W/P/Q/R results for that direction/site; preserve and report failed controls rather than dropping the direction.

The saved-data auditor must independently rehash every recorded sidecar, recompute argmax IDs and decoded transcripts from logits, reconstruct each window and intervention norm from frozen captures, verify all expected matrix rows and control equalities, and reject missing, duplicate, partial or failure runs as completed science. No-weight tests must cover tuple-preserving hook behavior, exact W/P/Q boundaries, random replay, and auditor rejection of a changed transcript with no intended-word transfer. Check resource bounds between forwards; use the baseline's 30-minute/4-GiB process-RSS ceilings and a **512-MiB new-output cap**. Persist an append-only failure row with all completed arms on error. Keep large tensors local; commit only small source, plan, preflight, records, audit, and digest manifests.

## Interpretation boundary

The baseline shows that stock Mode S changes outside-word input samples **before the network**, because each full recording gets different mean/variance normalization. Mode C fixes that input difference, yet the first convolution's time-wide GroupNorm spreads a word-local difference before transformer attention. Thus a W patch at feature projection or block 11 probes sufficiency of a state under a selected preprocessing history. It cannot establish where an effect *originated*, that attention alone spread it, or that the same result holds for a raw deployed request. A W transfer with passing controls is an internal ASR causal result on FIT synthetic speech; a W failure is informative too. Neither is evidence of a security vulnerability, an attacker-controlled audio exploit, or speech-to-speech generalization. A separate, preregistered fixed-GroupNorm counterfactual would be needed to isolate the GroupNorm contribution.
