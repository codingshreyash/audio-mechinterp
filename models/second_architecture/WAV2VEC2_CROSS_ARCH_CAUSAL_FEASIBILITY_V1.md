# Wav2Vec2 cross-architecture audio causal assay — source-level feasibility

18 November 2026. **No Wav2Vec2 weights were loaded and no Wav2Vec2 inference was run for this note.** This is a conditional design on the already-open corpus-v1 FIT `color_05` (`silver`/`teal`) and `object_02` (`plate`/`cup`) pairs, in Piper and Kokoro. It would compare an encoder-plus-CTC ASR model with the completed Whisper encoder-decoder assays. It does not use corpus v2 or a locked test, and no security claim follows from it.

The preprocessor says `do_normalize=true`, `return_attention_mask=false`, 16 kHz. The local experimental environment has Torch 2.15.0, Transformers 5.12.1 and SoundFile 0.14.0; pin all source and tokenizer bytes in a later run preflight.

This differs materially from Whisper's audio front end and autoregressive decoder.

## No-model locality check on exact FIT PCM

The paired raw PCM is sample-identical outside its frozen word slot. The no-weight [preflight script](wav2vec2_input_locality_preflight_v1.py) rehashes all eight WAV/PCM files, recomputes each waveform's mean/variance with the installed processor's no-padding formula, and compares the two normalized arrays outside the slot. Its saved [JSON result](WAV2VEC2_INPUT_LOCALITY_PREFLIGHT_V1.json) binds the four measurements below. Run `reproductions/audio_prior/.venv/bin/python models/second_architecture/wav2vec2_input_locality_preflight_v1.py --output <new-json-path>` from the repository root to reproduce it. These are preprocessor calculations, **not model outputs**:

| Pair | Voice | Raw outside-slot max abs difference | Separately normalized outside-slot max abs difference |
|---|---|---:|---:|
| `color_05` | Piper | 0 | 0.26646137 |
| `color_05` | Kokoro | 0 | 0.22046661 |
| `object_02` | Piper | 0 | 0.18251419 |
| `object_02` | Kokoro | 0 | 0.26614094 |

Thus an apparent outside-word activation difference under the **stock** path can begin before the model, because the single changed word alters each clip's normalization statistics. Even if both clips are normalized with common statistics, the first model convolution's time-wide GroupNorm can spread a local difference before any transformer attention. An experiment that labels all early spread as “attention transporting word information” would misattribute the stage.

As a direct no-weight cross-check, I instantiated the pinned cached `Wav2Vec2FeatureExtractor` and passed each WAV through its stock preprocessing. Its four outside-slot maxima matched the independently computed JSON values **exactly** in float32. Neither check loaded `model.safetensors` or made a neural forward pass.

## Conditional, reviewable experiment

1. Freeze the four pair/voice cells, all WAV/PCM hashes, checkpoint and installed source hashes, and the two input modes **before** model inference. Mode S is stock `Wav2Vec2Processor` normalization on each full unpadded waveform. Mode C uses one common mean and standard deviation computed from the shared outside-slot PCM of each pair/voice cell, then applies those same statistics to both complete waveforms before calling `Wav2Vec2ForCTC.forward(input_values=...)`. Mode C deliberately changes preprocessing; it is a mechanistic control, not a stock-model result. Verify Mode C input arrays are bitwise identical outside the frozen word slot. Use equal-length paired WAVs, CPU float32, `eval()`, no SpecAugment or dropout.
2. Run and save **all eight** clean full CTC transcripts in each mode, without selecting a favorable pair after seeing them. Decode the full argmax frame sequence with the pinned processor's CTC collapse; there is no EOS token or autoregressive stopping condition. For a lexical direction to be eligible, the full clean transcript must contain the recipient word exactly once and exclude its paired alternative. Save ineligible rows and the complete denominator. If a mode has no eligible directions, report that failure rather than changing the pair or preprocessing posthoc.
3. Capture the normalized waveform; first-conv raw output **before GroupNorm**; first-conv output after GroupNorm; final feature-conv output; feature-projection hidden tensor; encoder block-0 input after positional convolution; post-blocks 0, 5, and 11; and frame logits. Report per-frame L2/max-abs contrasts and the first differing frame at each stage for Modes S and C. The seven convolutions have total stride 320 samples and raw receptive field 400 samples. A changed raw slot `[s,e)` can directly touch final-conv frames `[ceil((s−399)/320), floor((e−1)/320)+1)`: `color_05` Piper `[95,156)`, Kokoro `[105,179)`; `object_02` Piper `[95,134)`, Kokoro `[105,170)`. These are **nominal acoustic windows**; global normalization can make outside frames differ earlier.
4. Only after clean eligibility and an independently reviewed intervention runner, patch donor rows in the fixed nominal word window versus an equal-width pre-word window at feature projection and post-block 11, re-run the entire unchanged downstream model, and compare the **complete CTC transcript**. Include self patches, a full-state donor positive control at post-block 11, both directions, and whole-window norm-matched random controls. Save complete 32-label frame logits/argmax paths, CTC blank/repeat behavior, all decoded transcripts, and every invalid/censored arm. A target-word-only transcript change is an ASR causal observation; a shifted logit or CTC path without the complete word change is a separate observation.

An optional **separately frozen** Mode C-GN control can isolate GroupNorm: capture the recipient's first-conv per-channel time mean/variance **under Mode C**; apply those fixed statistics and the checkpoint's learned GroupNorm affine parameters to both recipient and donor first-conv tensors. Verify the recipient's complete logits/transcript reproduce the ordinary Mode C GroupNorm pass within a predeclared tolerance before interpreting Mode C-GN. Because this substitutes normalization statistics for the donor, it is an internal counterfactual, not a stock audio request. It can test whether outside-word differences appear at the first convolution only because GroupNorm recomputes statistics from the changed word. Do not silently mix this with Mode S or C.

## Interpretation limits

The checkpoint is an English ASR encoder with a CTC head, not a speech-to-speech assistant, audio-language action model, or direct analogue of Whisper's autoregressive decoder. Baseline CTC accuracy on these **exact** FIT clips has not been measured yet. This note establishes feasibility and a concrete preprocessing confound; it does not establish that Wav2Vec2 recognizes either pair, that a patch changes a transcript, or that any attacker-controlled waveform violates a security property. The first live gate should be independently reviewed clean-baseline eligibility and exact stage captures. Later causal claims require the separately frozen intervention matrix and saved-result audit.
