The parity and donor captures also discard these events. The protocol explicitly requires saved hook counts, shapes, and dtypes. Archive them with each trace, or provide equivalent independently auditable records. Runtime assertions alone do not meet the archive requirement.
2. **Report each signed-pair response.** `analyze_native_pairs` retains individual measured vectors but its `odd_even` result takes a median over all three cycles for each magnitude (`voxtral_old_fit_handoff_native_stage_a_v1.py`, lines 449–457). The protocol requires odd and even components for **every** positive/negative alpha pair. Emit cycle-keyed components for all three repeats, with any median only as an additional summary.
3. **Correct the full-state descriptors.** `stage_vector` selects only projector rows 24–26 or the corresponding three LM-input rows (lines 371–379), and `full_delta_l2` and `changed_full_coordinates` are computed from that selection (lines 429–440). The protocol calls for full-state L2 and changed-coordinate counts at each boundary. Compute those descriptive values from the already archived full projector output and full LM input; label the fixed word-row probe metrics separately.
4. **Make the preflight payload estimate complete.** `estimate_native_archive_bytes` (lines 97–133) omits at least the saved `source_effective_edit` tensor on each of 72 patched forwards: 3,538,944 additional FP32 payload bytes across both sites. It also omits smaller saved tensors such as directions and donor states. The hard writer cap still prevents an oversized successful artifact, but the present estimate is not the complete planned tensor-byte count required before model load. Update the estimate and its schema figures, then rerun both validation arms.
