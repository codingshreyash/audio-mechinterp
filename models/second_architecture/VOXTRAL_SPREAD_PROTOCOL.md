# Voxtral passive representation-spread assay (fit-only v1)

Run `voxtral_representation_spread.py` without flags for a CPU-only preflight. A later explicit `--run` performs four bounded MPS generations on the exact manifest-pinned Piper red/blue WAVs: unhooked and passive-projector-hooked for each. The hook only copies the projector output to CPU; it does not edit the model. Require identical generated suffix token IDs within each clip before interpreting the captured vectors. Output goes to a new `runs/voxtral_representation_spread_fit_v1/` JSON file.

The frozen [pair manifest](../../eval/tts/outputs/controlled_pair_v1/controlled_pair_manifest.json) places the changed PCM word in samples `[18082, 26627)` of a 16 kHz recording. The two waveforms are sample-identical outside that slot. In the pinned [Transformers Voxtral implementation](https://github.com/huggingface/transformers/blob/18329f1065382e54db698e242cf98bd3f3e5a766/src/transformers/models/voxtral/modeling_voxtral.py), the encoder takes 3,000 mel frames, stride-2 convolution emits 1,500 rows, and the projector groups four encoder rows into each of 375 decoder audio-token vectors. Its bidirectional encoder can spread word information beyond nominal time rows.

Record the full 3,000-frame mel L2 difference profile and the full 375-row post-projector L2 difference profile (`blue − red`). The conservative **direct pre-attention** receptive-field calculation places the word in mel frames 112–167 and projector rows 13–21 inclusive. Compare three disjoint groups: nominal word window, other rows within the recorded clip, and nominal padded rows. With the Piper clip, the nominal padding begins at mel frame 311 and projector row 39. Record count, mean, max, nonzero count, and share of total squared L2 per group. These boundaries are an indexing aid, not evidence that later activations stay local.

The processor-only preflight already shows an important input-side confound: the Whisper feature extractor's clip-wide max normalization makes red/blue mel features differ outside the changed PCM word, including the padded 30-second tail. The long padding tail dominates aggregate squared L2 simply because it contains many frames. The assay therefore reports per-row magnitudes and group counts; it must not infer a model-internal spread from off-word differences without controlling for this preprocessing effect. No causal patch or security claim is part of this assay.
