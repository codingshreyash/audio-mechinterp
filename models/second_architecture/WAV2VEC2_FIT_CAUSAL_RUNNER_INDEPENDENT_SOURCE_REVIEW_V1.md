The source fixes both issues found before this review: it hashes the `input_values`, feature-projection, post-block-11 and logits baseline captures **before** loading weights, and it records all planned arms even when an exact self or full-donor control fails. The runner's live hook requires one CPU float32 tensor matching the saved recipient state and replaces only the first tuple member. The pinned model source sends that member into the encoder or CTC head at the two sites. Complete greedy CTC output, all argmax IDs, full logits, patch tensors, hashes, distances, norms and per-arm resource measures are saved. The source gates the pinned load report, topology, 30-minute runtime, 4-GiB process RSS and 512-MiB new-output ceiling. This is a source and preflight GO, not an observed patch effect. Full-donor exact-logit equality and self equality are empirical gates for the later run. The source cannot establish a security finding, held-out transfer, or the behavior of a speech assistant.
