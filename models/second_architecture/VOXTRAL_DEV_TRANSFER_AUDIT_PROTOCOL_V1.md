# Voxtral development result audit, frozen before inference

This independent auditor is for the complete 48-record development transfer specified in [the prospective protocol](PROSPECTIVE_VOXTRAL_DEV_TRANSFER_V1.md). It must not inspect a partial run or load model weights. The executable is [audit_voxtral_dev_transfer_v1.py](audit_voxtral_dev_transfer_v1.py). Its exact source hash is recorded in the pre-run freeze note. Run its `--validate-only` mode and synthetic tests before inference. Its `--audit RUN_DIR` mode is used only after all 48 records finish and `result.json` exists.

The auditor pins the protocol, mask builder and manifest, corpus index, revised development runner, FIT runner and result, and two behavior-critical helper modules by SHA-256. It independently reopens all 96 selected development WAVs, checks PCM and all 48 pair boundaries, recomputes the direct-overlap mel frame and model row masks, and confirms the 48-record/96-direction selection without opening locked-test audio. After a completed run, it rebuilds the CPU processor features and verifies all saved native, blank, and feature-control hashes.

For each record it requires the exact 108 planned slots: eight source captures and 100 generated-or-explicitly-invalid conditions. It rehashes the checkpoint and attempt log, checks all 5,184 rows across 48 records, recomputes visible and special-token suffixes from token IDs, checks EOS and nonterminal special IDs, classifies the complete answer independently, and verifies two-candidate score arithmetic. It rejects invalid self conditions and checks passive and self complete-suffix token parity against the corresponding native or blank baseline. It checks hook counts/shapes/dtypes, source hash fields, patch row supports, equal-effective-BF16-norm control fields, random seed namespace, opposite-word donor hash, and the complete invocation/attempt/time/memory receipt chain. It independently recomputes all effect and strict time-preference gates over all 96 directions, preserving malformed generations and failed gates.

This is an artifact audit, not a second model execution. It cannot prove that recorded hidden-state tensor hashes or scalar log probabilities correspond to the pinned model without another forward pass; exact code, source hashes, hooks, and runner provenance bind them. It cannot turn a constructed state edit into an attacker-reachable waveform or a security finding.
