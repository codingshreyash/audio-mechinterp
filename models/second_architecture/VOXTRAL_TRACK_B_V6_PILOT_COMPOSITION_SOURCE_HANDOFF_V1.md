# Voxtral Track B V6 pilot composition: source-only handoff

**HOLD for model weight load and pilot inference.** The [composition source](voxtral_track_b_v6_pilot_composition_source_v1.py) wires the reviewed source interfaces in the acyclic order worker **W** → external admission **A** → independent review **R** → later launcher **L** pinning exact W/A/R hashes. There is no real A/R or frozen L pin. Its public `launch_v6_pilot()` always raises. The top-level `PilotOperation` is pickleable for a spawned child and imports torch in that child. It calls the actual [pre-pilot verifier](voxtral_track_b_v6_pre_pilot_launcher_source_v1.py), which rechecks 32/32 human QA, fresh no-weight model/processor/source fingerprints and host evidence before any loader. The operation then stops at `LIVE_BATCH_ADAPTER_REVIEWED=False`, before model weights. This is a deliberately incomplete live path.

The private fake-testable composition checks W/A/R and exact old-FIT/synthetic batch hashes before a supplied fake loader, then delegates to the [worker](voxtral_track_b_v6_pilot_worker_source_v1.py). The worker owns the exact **2 natural old-FIT + 2 forced synthetic generations + 72 no-grad + 12 grad score calls**, pre/post host probes, append-only attempt ledger, caps and retained receipt. After worker completion, the composition asks for a fresh post-run host probe, checks its raw/compressed log hashes and requires its collection timestamp to be **strictly later** than the pre-run collection time. Replaying the pre-run host receipt is rejected. It then writes a separate source-only sidecar bound to the worker measurement hash. That sidecar explicitly says **not pilot GO**. The real `_post_host_evidence` helper uses the pinned no-weight preflight's host parser; the fake path accepts an injected callback. A post-run probe failure or incomplete worker schedule cannot become GO.

The private parent helper delegates to the [MPS runtime adapter](voxtral_track_b_v6_mps_runtime_adapter_source_v1.py), whose exclusive watchdog claim precedes child spawn and whose 240-second parent deadline includes child setup and any future model load. Timeout/kill/OOM leaves claims and partial evidence, with no retry under the same campaign. The adapter configures the 30-GiB PyTorch MPS allocator cap before a child operation and samples driver allocation as a **lower bound** on transient usage. The separate [pinned loader](voxtral_track_b_v6_pinned_loader_source_v1.py) provides a child-only FP32/eval/MPS factory after W/A/R/QA/host and double snapshot/source-byte checks. `_pinned_model_factory` names that connection, but the live operation cannot call it until the missing batch adapter and full source composition are reviewed.

## Live blockers

- Obtain actual audited 32/32 QA, independent A/R, and a later launcher with exact W/A/R hashes. This source does not issue or self-approve any of them.
- Implement and independently review deterministic construction of the bound old-FIT and maximum-geometry synthetic tensors from the exact pinned processor, with hashes matching A, **before** calling the model loader. Connect those tensors, pinned loader, post-run host evidence and worker inside a top-level spawn-pickleable production child operation. The current fake composition uses dependency injection; it does not certify a live input path.
- Preserve V6's 240-second inclusive model-work and 30-GiB allocator cap, full parent no-retry claim semantics, and independent saved-data audit. The post-host sidecar currently sits **outside** the worker output directory, so its bytes are not counted by the worker's 2-GiB output cap or its saved-data auditor; live composition must close this accounting/audit gap before pilot GO. The worker's `schedule_complete_resource_unverified` cannot be relabeled as a measured pilot GO by this shell.
- Obtain a distinct independent post-pilot GO bound to the exact measured receipt and call ledger before Track B inference.

Verification: [five fake tests](test_voxtral_track_b_v6_pilot_composition_source_v1.py) cover full 88-call fake worker composition and post-host sidecar, exact timestamp replay rejection, QA/batch failure before loader, top-level operation pickling and pre-load HOLD, and parent timeout/no retry. No real model, candidate WAV or GPU was used.
