# Independent source review: Wav2Vec2 acoustic worker V2

19 November 2026. Reviewed committed V2 worker/protocol `b5c35ae` and no-weight preflight `4db1698` against the preserved failed V1 attempt and installed Transformers 5.20.2 source. **GO for the narrow capture-topology diagnosis; HOLD for a V2 worker GO or model inference.** No candidate model was loaded for this review.

The committed worker source SHA-256 is `3bcda1389b43b1680e19f2f1e2718c11a0ad86c5a794e3721cc33c3a5ad94715`. Its local selector correctly distinguishes the installed module returns: `Wav2Vec2EncoderLayer.forward` returns a full Tensor, while `Wav2Vec2FeatureProjection.forward` returns a two-Tensor tuple. V2 keeps the full Tensor at `post_block0`, `post_block5` and `post_block11`, and selects only the first tuple item at `feature_projection`. It retains the old stage shape, finite-value, hook-count and logits parity checks. This addresses the specific `[286,768]` V1 failure without editing the older frozen FIT helper. The V2 preflight records Transformers 5.20.2, Torch 2.15.0, and the capture contract; it recomputed exactly at the time of review. Its frozen PCM/noise case matrix, model revisions and resource limits match V1.

**HOLD reason:** the V2 protocol authorizes only a new Wav2Vec2 attempt and expressly excludes rerunning completed Whisper V1. Yet the committed V2 worker's `run_model()` still branches on `model_name == "whisper"`, and its CLI permits `--model whisper`. A future V2 GO receipt would therefore admit a Whisper V2 run that is outside this amendment. The parent launcher can add a second guard, but the worker admission must match its own protocol.

Require `run_model()` to reject every model name except `wav2vec2` before a model load and restrict the V2 CLI to that value. Add a no-weight regression for direct-function and CLI rejection. Freeze the corrected worker hash and regenerate the V2 no-weight preflight receipt; then obtain independent source re-review and separate V2 GO receipts. Preserve `wav2vec2_attempt_001` and all V1 review artifacts unchanged. No V2 inference is authorized by this memo.
