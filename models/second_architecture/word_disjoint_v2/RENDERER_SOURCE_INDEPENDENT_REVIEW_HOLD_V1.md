## Required corrections

1. **The renderer's freeze gate is self-asserted.** `render.freeze_receipt()` accepts a JSON file with `status: independently_reviewed_renderer_frozen` and matching current file hashes. It does not require a hashed independent GO review, source commit identity, or clean committed source. I reproduced this without rendering: a temporary file with only the six expected SHA-256 fields and that status returned successfully from `freeze_receipt()` when used as `FREEZE`. Therefore an arbitrary local receipt can unlock `--render` before review. Require a committed, clean renderer/auditor/queue/test source set; pin the V2 plan and its independent GO review; bind a separately committed independent source GO rereview by path and SHA-256 (with its reviewed source hashes and commit); and verify these references and statuses before creating output. Keep the freeze receipt externally written and hash-bound to the exact executable sources.
2. **The listening queue trusts a forgeable technical binding.** `queue.main()` checks a few fields and the `audit.py` hash in `TECHNICAL_BINDING.json`, but it does not independently recompute `audit.verify()` from the saved fragments and clips or compare the full resulting technical report. A hand-written binding with the correct manifest hash and status can therefore enter `--write` without the technical audit. Recompute the technical audit before copying anonymous WAVs, require the binding's full report to equal it (plus its manifest/auditor hashes), and reject extra or changed source files. The private/public split can remain as designed. This is an admission issue for the listening bundle, not evidence that any candidate inference occurred.

After correction, rerun the no-model tests and both source commands, add negative tests for a forged freeze and forged technical binding, and request independent rereview. Track B candidate inference remains separately gated on audited 32/32 blinded human listening and reviewed/frozen candidate runners. None of this source work establishes a security finding.
