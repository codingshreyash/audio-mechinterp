# Independent source review: Track B Whisper Tiny candidate assay

19 November 2026. **Decision: HOLD for Whisper candidate inference.** I reviewed the Whisper runner and saved-data auditor introduced in `b604ebd` and bound to the human-QA gate in `9b79ae9` against the frozen V2 plan, earlier reviewed Whisper FIT implementation, and the 32-WAV fixture. I loaded no model weights, ran no model inference, and opened no locked-test WAVs. This is a source review, not an assessment of model behavior or a security finding.

## Blocking input-identity gap

The V2 plan requires every patched decode to hold the recipient waveform/input fixed and use the pinned stock Whisper processor **with its audio attention mask**. The clean loop saves the mask shape and hash (`run_whisper.py`, lines 279–300). The patch loop reconstructs a processor batch from the same WAV but compares only `input_features` to the saved clean mel before generation (lines 317–337). It never compares the reconstructed `attention_mask` with the clean mask shape/hash. The saved-data auditor independently verifies the clean mask, but no patch-row mask identity is recorded or checked. Therefore a changed mask can pass the patch input guard even with identical mel features. A no-weight reproduction used identical `(1,80,3000)` float32 mel arrays and masks differing in one entry: the existing `np.array_equal` mel guard returned `True`, while mask equality returned `False`. This is a logical coverage gap; I did not observe a real processor mask drift.

Require the patch loop to compare the live mask shape and digest against the saved recipient clean mask **before every patched decode**, and add a negative no-weight test that changes only the mask while leaving mel identical. The auditor should verify any additional patch-row mask evidence if the runner records it. Then request independent source rereview before freezing or loading candidate weights.

## Checks that passed

- `prepare` enumerates 32 clean WAVs and 32 directed cells × two sites × six arms = **384 patched complete decodes**. It reports `admitted_for_candidate_inference=false` while human listening QA is absent. `preflight` fails closed on that missing 32/32 QA receipt.
- The two hooks target the output of encoder block 0 and the final encoder LayerNorm consumed by cross-attention. The live patch hook checks the full observed recipient state against the saved clean state and removes the hook in `finally`. The word interval uses the frozen five-frame guard and `ceil(WAV_frames/320)` active rows. W and O are complementary within active rows; all six arms leave padded rows recipient-identical. Separately seeded PCG64 random arms are matched to the natural W/O edit norm. The auditor reconstructs these edits independently from the clean state sidecars.
- Clean and patched records contain complete generated token IDs, decoded strings, normalized tokens, censoring/EOS status, and strict full-template eligibility. Self and full controls compare complete ID lists to the respective clean baselines; failed controls remain visible and close the mechanism interpretation gate. The auditor checks the complete 418-row order, rehashes clean arrays, reconstructs each patch, re-decodes IDs with the pinned processor, and rejects extra/missing output files. Saved-data auditing cannot itself prove how IDs were generated; source hooks and execution provenance address that separate question.
- The no-weight byte ledger is **278,863,872 bytes** including clean arrays, NPY headers, 32 MiB metadata and 64 MiB contingency, below 512 MiB. Source enforces CPU float32 eval, four Torch threads, 30-minute wall time, 4-GiB peak process RSS and 512-MiB output caps before/after forwards. A partial run cannot satisfy the auditor's full matrix.

All seven no-weight candidate-source tests passed; `py_compile` passed for both Whisper files. No candidate output was inspected. Even after source GO, model inference remains separately gated on audited 32/32 blinded listening and a committed hash-bound preflight/freeze. Any internal-state transfer would establish a local causal property of this ASR checkpoint and these recordings. It would not by itself establish an attacker-reachable speech-assistant exploit.
