## Blocking findings

1. `reviewed_source` accepts a required GO sentence **anywhere** in a review document. A committed HOLD review that quotes the exact GO sentence for discussion would pass this check if its chronology and source bytes match. The gate needs an unambiguous decision field or exact decision line and must reject contradictory HOLD language. The first independent negative test demonstrates the current false admission.
2. `_audit_campaign` checks counts and permitted labels, but not the two expected case IDs in order, distinct case indices, the four expected `case × site` identities, or the saved forward count. A fake auditor return with two copies of beaver and four copies of its encoder31 cell is accepted. The gate must bind the final campaign receipt to both fixed cases and four fixed cells; the second independent negative test demonstrates the current false admission. Re-review the corrected auditor interface before binding it here; the independent auditor source is itself on HOLD.
3. The environment preparation stages a narrow source/input archive without requiring a **verified Git checkout at the reviewed HEAD with its required history** on the remote host. The gate calls `git show`, `git log --diff-filter=A`, and `git merge-base` for exact source/review chronology. A plain copied source archive cannot satisfy this admission. Specify a pinned Git bundle or equivalent verified remote checkout, its HEAD/tree and required history, stage it in the narrow source package, and verify it before the gate runs. Do not weaken chronology checks to accommodate a source-only copy.
