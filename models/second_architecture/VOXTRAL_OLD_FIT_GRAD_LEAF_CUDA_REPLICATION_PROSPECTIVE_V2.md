# CUDA gradient-leaf replication: direct-replay decision amendment

18 November 2026. **Prospective source-only amendment; no CUDA result or model load.** The [V1 design](VOXTRAL_OLD_FIT_GRAD_LEAF_CUDA_REPLICATION_PROSPECTIVE_V1.md), SHA-256 `188925bc4022aa9841502d310899b5f9b28bf8ec0ba32ab7f7acb3fc45579050`, remains unchanged. Its [independent conceptual HOLD](VOXTRAL_OLD_FIT_GRAD_LEAF_CUDA_REPLICATION_CONCEPTUAL_REVIEW_HOLD_V1.md), SHA-256 `c957310d936b548497fc96a17bb63be56d09edcb277cea83b801603c8cc6f4a3`, found that “direct replay reproduces the full-model contrast” lacked an exact equality rule. This amendment replaces only that decision phrase. All V1 inputs, two-case/four-cell denominator, CUDA settings, capture schedule, other thresholds, caps, and security-claim limits remain fixed.

For each `case × site × condition × repeat`, join one full-model call and one fixed-input direct-language replay by the recorded case ID, site, mode (`N0`, `N1`, `G0`, or `G1`), and within-mode repeat index (`0` or `1`). The direct replay input is the first full-model N0 LM input for that site, as V1 requires. Require matching tensor shape and dtype and **bitwise equality of contiguous raw CPU tensor bytes**, including signed zeros, for all three paired boundaries: (1) full-model LM0 pre-block input versus direct-replay LM0 pre-block input; (2) full-model post-LM0 state versus direct-replay post-LM0 state; and (3) full first-answer logit vector versus direct-replay full first-answer logit vector. This is 16 matched call pairs and 48 required tensor comparisons per case, 32 pairs and 96 comparisons across the two planned cases. Compare LM7/14/22/29 states and other captured boundaries descriptively without using them to waive a failure of these three required comparisons. Do not substitute equality of only the `G1−N0` difference or a numeric tolerance for individual tensor equality.

The independent saved-data auditor must report every paired boundary's equality flag and, for a mismatch, changed-coordinate count, float64 L2 and maximum absolute difference. If any matched call is missing, duplicated, has the wrong mode/repeat, has invalid shape/dtype/nonfinite values, or has inconsistent input/source/claim provenance, mark that case/site cell `invalid` under the V1 provenance rule. If all captures are valid but **any** of the three required direct/full tensor comparisons differs bitwise, label that case/site cell `different_pattern`, even if the `G1−N0` contrast or first answer token agrees. A `same_pattern` label requires all **24** direct/full comparisons for that case/site cell to pass **and** every other V1 same-pattern condition for that cell. The observed repeat floor `max(1e-6, 3 × maximum within-condition repeat L2)` remains solely the rule for whether a *within-CUDA cross-condition* difference is above floor; it does not relax direct/full equality. No post-result selection of a more permissive rule is allowed.

An independent reviewer must accept this exact amendment before runner/auditor implementation. The later executable freeze must bind V1, this V2 amendment, both independent reviews, and source/test hashes. The original MPS factorial result, the ongoing Mac color-pair campaign, and any sealed development/test data remain outside the new CUDA attempt.
