# Decision: test the two global statistics before another activation swap

19 November 2026. **Independent research decision; no model run or executable GO.** This memo uses the already inspected synthetic FIT audio. It selects a bounded model-internal experiment that can run locally while fresh-corpus human review and audio-assistant compute are pending. It does not change the frozen prior attempts.

## What the saved evidence actually says

The [independently audited acoustic-noise run](ACOUSTIC_FIT_NOISE_WAV2VEC2_V2_RESULT_INDEPENDENT_REVIEW_V1.md) found exact raw-PCM equality outside the word slot in every **word-slot-noise** arm, but Wav2Vec2's stock processor had an outside-word input difference before the network. Of 12 noisy variants, ten kept their own clean complete CTC transcript. Kokoro/teal word noise changed the model's wrong `TIL` to intended `TEAL`; Kokoro/silver outside-slot noise changed preceding `IS` to `ISE`. Full-noise transcripts were unchanged. The [Whisper comparison](ACOUSTIC_FIT_NOISE_CROSS_MODEL_SYNTHESIS_V1.md) first measured word-noise outside-row spread after encoder block 0, with no lexical word change. These are stage observations on four correlated FIT recordings, not general robustness rates.

The separate [Wav2Vec2 FIT baseline](WAV2VEC2_FIT_BASELINE_V2_RESULT_INDEPENDENT_REVIEW_V1.md) used a shared outside-word input normalization for silver/teal and plate/cup pairs. In that controlled path, the first raw convolution was **exactly equal outside the edited slot**, whereas its first GroupNorm output differed outside it. The [independent formula reconstruction](WAV2VEC2_FIT_GROUPNORM_RECONSTRUCTION_INDEPENDENT_REVIEW_V1.md) matched the pinned GroupNorm outputs from raw saved tensors; its shared-stat algebraic counterfactual made outside rows equal. This proves the *numerical origin of that measured spread*, not a downstream transcript effect. Finally, a [selected FIT state transplant](ACOUSTIC_FIT_NOISE_CAUSAL_RESULT_INDEPENDENT_REVIEW_V1.md) showed that actual feature-projection word rows suffice to transfer the Kokoro/teal complete transcript both ways; it did not identify whether processor normalization or GroupNorm created the consequential state.

## Most informative next local test

Freeze **all eight** already saved clean/noisy pairs: four source recordings (Piper and Kokoro × silver and teal) crossed with `word_noise` and `outside_noise`, with their exact WAV/PCM/noise hashes and nominal word-slot sample windows. Keep both noise strata, all unchanged transcript cases, and the two preobserved changes in the ledger. Do not select only Kokoro/teal. The outside-noise stratum is a specificity/control stratum: its raw PCM changes outside the word and may directly change the preceding `IS`, so its `IS`→`ISE` case is **not** evidence of remote propagation.

First, make an input-statistic 2×2 for each pair: raw PCM source `clean` or `noisy` × utterance-normalization statistics from `clean` or `noisy`. This creates clean/clean, clean/noisy-stats, noisy/clean-stats, and noisy/noisy. Reproduce the pinned stock feature extractor's float32 normalization exactly; require clean/clean and noisy/noisy to match stock input values, complete logits, CTC frame-ID paths and transcript before interpreting cross-statistic arms. Save the actual mean/variance, input hashes, exact per-time differences, complete logits and decoding. A clean waveform given noisy statistics that adopts the noisy endpoint would demonstrate conditional sufficiency of that statistic change in this fixed case. A noisy waveform given clean statistics that retains the noisy endpoint would show that the direct acoustic edit can suffice without the stock global input coupling. If neither crossed arm changes a transcript, report the hidden-state effect and null output.

Second, for the four **word-noise** pairs only, use one common outside-slot input mean/variance, as in the reviewed baseline, so clean and noisy normalized inputs and first raw-convolution outputs are bitwise identical outside the convolution receptive-field overlap. At the first convolution GroupNorm, cross raw-convolution source (`clean`/`noisy`) with GroupNorm channel/time statistics (`clean`/`noisy`): four combinations. The first layer has kernel 10, stride 5, no padding and channel-wise GroupNorm across the full time axis; the [formula audit](WAV2VEC2_FIT_GROUPNORM_RECONSTRUCTION_INDEPENDENT_REVIEW_V1.md) pins epsilon, affine weights and the overlap rule. Replace **only that normalization output**, leaving later layers and weights unmodified. Require the two natural-statistic diagonal arms to reproduce no-hook GroupNorm tensors and complete logits exactly; require the clean-statistic intervention to restore exact outside-word GroupNorm equality where raw-convolution inputs are equal. Then compare full CTC frame paths and transcripts for the crossed arms. This tests whether time-wide GroupNorm statistics are conditionally sufficient for any decoded change in the common-input path; it also shows whether later layers re-spread a local difference after that early global coupling is removed.

Use exact self/no-hook/read-only hook controls, one call per hook, stock checkpoint and source hashes, complete 286-ish frame-ID paths (do not assume a fixed length across voices), realized tensor edit norms, and all failed/censored attempts. Freeze the window mapping, arm order, seeds if any, paired denominators, CPU/RSS/output/time caps, and a read-only saved-data auditor before new weights load. Verify the 2×2 stock-diagonal and GroupNorm-diagonal replay **at logits**, not just transcript. If a diagonal fails, the corresponding intervention cannot support a mechanistic claim. Do not compare raw L2 values across Whisper and Wav2Vec2 coordinate systems.

## Interpretation boundary

The first 2×2 asks if stock *whole-recording input statistics* contribute to a complete decoded change. The second asks whether the *first time-wide GroupNorm statistics* contribute after deliberately holding input normalization common. The latter is an artificial preprocessing path, not a deployed model behavior. A result can be described as sufficiency or conditional dependence at a specified site and case only after the parity controls pass. It cannot establish unique mediation, necessity in every context, human intelligibility, transfer to new voices/words, an attacker-controlled exploit, a VoiceChat tool decision, or a security vulnerability. A null transcript result still advances the mechanism: it would show that observed global representation spread alone did not alter these complete CTC decisions.

**Decision:** GO as the next bounded local mechanistic question; HOLD on candidate inference until a separate prospective executable protocol and independent source/launch review bind the exact inputs, statistic formulas, hooks, controls and budgets.
