# Thinker layer 30→31 boundary: code audit and interpretation

Scope: fit-only Qwen2.5-Omni-3B red/blue controlled pair, 2026-11-18. This is a read-only analysis of [the frozen sweep plan](thinker_layer_sweep_plan_v1.json), [the 144 saved cases](thinker_layer_sweep_results_v1.json), [the sweep](sweep_thinker_layers_v1.py), [the patch hook](patch_thinker_residual_v1.py), the [pinned model configuration](../../models/qwen_omni/README.md), and the pinned Transformers source. It does not examine or change a held-out set.

## Observations from the saved results

- The 36-layer sweep uses **one** red/blue lexical pair, two synthetic engines and two directions: four cases per layer, not four independent prompts. The plan was fixed after earlier layers 0/17/35 pilot observations and before this full sweep, so this boundary remains exploratory.
- The donor patch at word-aligned **audio-placeholder positions** changes the complete generated answer in 4/4 cases at every post-block layer **0–30** and 0/4 at **31–35**. All 144 clean answers match the input color; all patched generations end normally; each patched run reports one prefill hook call. The hook leaves decode calls unmodified.
- The behavior cliff is **not** a zero-to-nonzero causal cliff. Donor-oriented first-reply logit-margin change remains about +2.9 to +3.4 at post-block layer 31 and +2.0 to +2.2 at 32; it is near zero by 33. At layer 31 the edited answer still favors the recipient, so its sizable score movement is insufficient to cross the answer decision boundary. At layer 30, donor-oriented post-edit margins remain positive in all four cases. Thus the precise observation is **loss of answer-flipping sufficiency after layer 30**, followed by decay of score influence through layer 33.
- The donor-minus-recipient edit norm *increases* through the late layers (median across four cases ≈436 at layer 30, ≈538 at 31, ≈1,137 at 35). A small late patch is not the explanation. The norms do not establish an equal effective edit after normalization or attention.

## Facts from the pinned implementation

The checkpoint is `Qwen/Qwen2.5-Omni-3B` revision `f75b40e3da2003cdd6e1829b1f420ca70797c34e`; local adapter pins Transformers commit `e7e568dc7673ac99a87660c7c50e84830268285c`. The nested text config declares 36 hidden layers, `use_sliding_window=false`, `max_window_layers=70`, and no explicit `layer_types`. Instantiating the pinned config locally yields `full_attention` for **all** layers 0–35, including 30 and 31. There is no configured attention or masking switch at 31. The `max_window_layers=70` field is inert here because sliding attention is disabled; the vision encoder's separate full-attention indices are unrelated to this text stack. [Pinned checkpoint config](https://huggingface.co/Qwen/Qwen2.5-Omni-3B/blob/f75b40e3da2003cdd6e1829b1f420ca70797c34e/config.json); [pinned Transformers config implementation](https://github.com/huggingface/transformers/blob/e7e568dc7673ac99a87660c7c50e84830268285c/src/transformers/models/qwen2_5_omni/configuration_qwen2_5_omni.py).

Each text block computes Q/K/V from its **input** hidden states, applies causal self-attention, then an MLP with residual additions, and returns the post-block tensor. The audio encoder's projected features are inserted into audio-placeholder embeddings before the text stack. The stack iterates over the same type of block for layers 0–35, applies a final RMSNorm, then `lm_head` projects the last/answer position to logits. The local hook replaces only selected audio-placeholder rows in a **block's output** on the prefill call. It does not directly alter that block's already-computed Q/K/V cache, the terminal answer position, or subsequent decode-step tensors. [Pinned Transformers model implementation](https://github.com/huggingface/transformers/blob/e7e568dc7673ac99a87660c7c50e84830268285c/src/transformers/models/qwen2_5_omni/modeling_qwen2_5_omni.py); [local patch hook](patch_thinker_residual_v1.py).

This timing gives a mechanical reason for the **layer-35 null**: changing an audio position *after* the final self-attention block cannot reach the unchanged terminal position before final normalization and the text head. More generally, a post-block audio patch at layer `l` can change the first answer only if **some later block** transfers information from those patched positions to the terminal position. The patched audio positions precede the terminal position, so the causal mask permits that transfer; the code does not guarantee the model actually uses it. A post-30 patch can be read by block 31; a post-31 patch cannot affect block 31's attention output and has only blocks 32–35 left. That establishes an important hook-placement asymmetry, but does **not** by itself explain why the full-answer flip disappears specifically between 30 and 31.

The donor states were captured with a forward pass using `use_cache=False`, whereas the patched recipient runs through `generate(use_cache=True)`. The prefill outputs should be comparable for causal inference, but the sweep did not independently verify equality of cached and uncached prefill activations at every layer. This is a checkable technical caveat, not evidence of a layer-31 bug. The hook's shape gate and one prefill call per run make a silent failure to execute at layers 31–35 less plausible; a returned tensor checksum or direct downstream capture would verify actual replacement.

## Interpretation against primary literature

The best working explanation is **late transfer of color information from audio-placeholder rows into the terminal answer state**. Specifically, block 31 may be a decisive readout point in this task: patching its input via post-block layer 30 changes the answer; patching its output audio rows leaves the terminal state that block 31 already computed untouched. Later blocks still show some causal score sensitivity (layers 31–32), then almost none (33–35). This is an inference from hook timing and outcomes, **not** a demonstrated unique layer-31 circuit or proof that the natural model forms its decision there. Layer-31 changes could also reflect a threshold effect, normalization, context-dependent attention, or a route through other prompt positions. The increasing donor-state norms do not distinguish these.

An especially close, independent 2026 study used **Qwen2.5-Omni-3B** for audio-visual question answering. It reported that masking attention to audio and video tokens in layers **31–35** left accuracy unchanged or slightly improved, despite a layer-31 visual attention sink. This is compatible with a task in which useful multimodal information has already moved into text/answer states by that depth. Its inputs include video, its endpoint is multiple choice, and its mask operation differs from our donor-state replacement; it therefore corroborates a *possible routing pattern*, not this exact color boundary. [From Senses to Decisions](https://arxiv.org/html/2606.10147).

Other causal audio work finds strong answer-position bottlenecks or late integration, but not this same checkpoint/task/hook result. [Causal Tracing of Audio-Text Fusion](https://arxiv.org/html/2603.13768) finds late fusion in Qwen and Qwen2 **audio** models and a last-token bottleneck; it does not evaluate Qwen2.5-Omni in the cited experiment. [Represented but Ignored](https://arxiv.org/html/2608.19211) patches the answer-position residual for prosody in Qwen2.5-Omni and emphasizes that a shifted answer score need not mean a robustly changed response. These precedents make a generic “first discovery of late audio fusion” claim untenable. Our specific fit-only layer curve is a targeted replication/extension candidate, pending stronger causal controls and held-out words/voices.

## Most discriminating follow-up checks

1. **Verify hook delivery at 30–35 without changing the v1 files.** Save recipient and donor post-block tensors, injected tensor hashes, and the next block's Q/K/V or pre-attention inputs for the same cases. Confirm cached versus uncached prefill equivalence within stated numeric tolerance. Run a self-patch and a deliberately large, bounded edit at each late layer; if the latter has no downstream effect even at layer 31, inspect hook and attention implementation before drawing a routing conclusion.
2. **Bracket the proposed transfer.** For the fixed fit-only pair, compare post-block-30 audio-row patch with a pre-block-31 audio-row patch, post-block-31 audio-row patch, and post-block-31 terminal-position patch. If the first two flip, the third does not, and a terminal patch does, the result supports transfer **during** block 31. Record full answers and logit margins. At block 31, selectively patch audio K/V or the terminal attention output and measure whether the donor effect follows; use paired same-size nonword and self controls. Hooking only attention weights is insufficient to infer content flow.
3. **Test necessity as well as sufficiency.** On clean inputs, block or replace the terminal query's access to the word audio positions in layer 31 and neighboring layers, while preserving other positions. Compare full-answer changes to matched random/time-window controls. If layer-31 attention loss changes behavior, it supports natural use of that path; if it does not, a donor swap may be exploiting a path that clean inference does not rely on. This is a proposed new experiment, not a result.
4. **Freeze a replication gate** before new words or speakers: same sites, layer-boundary statistic, clean-performance denominator, full-answer/EOS endpoint, and a prespecified band such as 28–34. Ask whether the transition recurs with independent voices, lexical pairs, and phrasings. Report the boundary distribution rather than selecting the sharpest case. A different boundary does not invalidate the fit-only trace; it limits generalization.

**Current conclusion:** the code audit rules out an explicit layer-31 sliding-window/mask transition. The observed 30→31 *answer* cliff is consistent with late audio-to-terminal transfer and with published Qwen2.5-Omni-3B attention-knockout evidence, while the nonzero margins at 31–32 show that late audio rows are not completely disconnected. A targeted block-31 transfer experiment is needed to identify the mechanism.
