# Whisper Tiny on authentic speech: prospective mechanism protocol V1

19 November 2026. **Source only. HOLD target Whisper inference.** This protocol fixes the denominator and analysis before any target output on this corpus is opened. It tests whether a quiet two-second tail changes a complete transcription of real speech and, conditionally, whether a small encoder-boundary state carries that change. An ASR result is not a security finding or an audio-language action result.

## Acoustic location fixed from source geometry

The source WAVs are 16 kHz PCM. Whisper's pinned feature path gives 3,000 log-mel frames with a 160-sample hop and 1,500 encoder rows after kernel-3, stride-1 and kernel-3, stride-2 padded convolutions. Before self-attention, encoder row `r` has a local convolutional receptive field around mel frames `2r-2..2r+2`; centered STFT windows can further blur the exact source/tail edge. For each recording with `N` active samples, predeclare the source/tail center `b = floor((N+160)/320)` and the tail/padding center `e = floor((N+32,000+160)/320)`. The **boundary region** is `b-3..b+3` union `e-3..e+3` (14 rows), fixed from PCM length, not from an output heatmap. Validate the assumed mel-frame/time mapping against the pinned feature extractor and report actual mel differences across the whole 3,000-frame input. If mapping is wrong, stop the causal run and revise prospectively; do not shift the patch to a result-favorable row. At later transformer blocks, attention can distribute tail information outside this window, so a positive local patch does not imply the information is confined there.

## Conditional causal test

Test **every** pair in its split meeting all of these predeclared criteria: both clips pass the human-perception screen; both unpatched answers end in EOS; both have identical prefix IDs and detected language; their normalized complete answers differ; two fresh unpatched replays reproduce both complete token paths and first-step vectors. Record the eligibility decision for all eight pairs. If no pair qualifies, report zero eligible pairs and no patch conclusion. Do not select the most dramatic divergent pair.

For each eligible pair, patch only the generation encoder pass, leaving language detection and the recipient waveform, mel, mask, decoder prefix and all unselected state rows unchanged. Run both directions, zero→noise and noise→zero, at two predeclared sites: `post_conv_pos` and `post_block0`. At each site/direction run the 14 boundary rows with (a) donor-row replacement, (b) identity/self replacement, (c) same-count donor replacement at deterministically selected **source-speech** rows, and (d) a displaced delta at those source rows scaled to the boundary edit's L2 norm. Run (e) an all-1,500-row full-donor positive control at each site/direction. Select the 14 source rows by SHA-256 seeded sampling from encoder rows `8..b-8`, independently of target outputs, without boundary overlap. Record actual edit norms, hook counts, full native/edited states, first-step vectors, full token paths and EOS. No cache or supplied encoder output may bypass the instrumented pass.

A **control-qualified complete-answer transfer** requires the boundary edit to produce the donor's exact complete token path with EOS; self, source-row donor and displaced equal-norm controls must preserve the recipient's complete path with EOS; and the full donor must reproduce the donor's complete path **and** raw first-step vector. Failed positive controls make the cell uninterpretable. A control that also changes the answer disqualifies a location-specific claim, even if the target edit works. Count qualified cells over all eligible pairs, both directions and both sites; report failures, censored calls and all controls. Exact donor logits are not required for a local answer transfer, but their distance must be shown. This patch tests causal sufficiency in this instrumented model, not a unique neuron, necessity, real-world exploitability, or a tool authorization decision.
