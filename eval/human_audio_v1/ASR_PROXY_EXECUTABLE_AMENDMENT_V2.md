# ASR proxy V2 executable gate

19 November 2026. **HOLD candidate inference until a new V2 admission, independent executable review, and committed GO exist.** The V1 Wav2Vec2 source-only admission and 16-WAV plan remain unchanged. V1 parent/auditor source lacks an executable GO requirement; it must not launch the study. Preserve those files as a failed source gate, not as candidate results.

V2 adds a one-shot parent, live-channel worker wrapper and saved-only auditor around the V1 model routine and fixed attempt path `runs/asr_proxy_v1/attempt_001`. It does not change the 16 WAVs, pinned `facebook/wav2vec2-base-960h` revision, FP32 CPU processor/CTC decoding, full logits/input-value sidecars, 600-second wall, 4-GiB process-tree RSS or 256-MiB evidence ceiling. The V2 parent must validate the exact committed V1 admission and V2 admission, a later independent review memo, and an even later GO receipt before the attempt directory or model weights are touched. The GO binds model revision, fixed attempt, V1/V2 admission hashes, V2 source hashes and independent review hash. The parent records the GO hash in launch and result evidence. The V2 saved auditor requires the same GO and performs the entire V1 saved-logit audit before issuing a distinct V2 receipt.

The V2 parent alone creates a one-use inherited pipe. It writes a random nonce, then sends a heartbeat while it monitors the worker process tree. Before checkpoint deserialization, the V2 wrapper verifies the committed GO, exact admission and launch hashes, parent PID, nonce and a live heartbeat. A daemon watcher exits the worker if the pipe closes or heartbeats stop for over two seconds. The nonce SHA, GO SHA, V2 admission SHA and V2 source identity are in the launch record; none is accepted from a standalone worker command line. The parent closes its pipe on any bound violation. A forged launch file without a live pipe cannot execute the V2 worker's model routine.

The V1 worker CLI remains callable and therefore outside V2's authorization claim. A valid V2 receipt requires the V2 parent/worker module identity and a worker-ready record emitted only after nonce and first heartbeat, checked by the parent and saved auditor. This is process evidence, not an anti-forgery guarantee against someone with write access to all attempt files.

Chronology is checked against the original GO commit tree, and current clean source bytes must equal that tree. This prevents a later byte-for-byte restoration of a reviewed file from creating a false chronological failure, while any changed bytes still fail. A missing or malformed GO, wrong model, wrong attempt, wrong admission/source/review hash, altered current file, or invalid source→admission→review→GO ancestry must fail before weight load. No automatic retry under the same attempt path. The independent reviewer must run no-weight fault tests and issue GO only after the final source/admission are committed.
