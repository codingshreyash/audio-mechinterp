# Blinded human review intake, version 2

The [A/B bundle](blind_bundle_v1/TECHNICAL_MAPPING.json) contains 16 opaque, hashed WAVs for each independent listener. Reviewer exports are records supplied by people; no source transcript, ASR output or model result may fill a review field. Two distinct reviewer IDs are required. If either normalized verbatim transcript, clarity, or after-speech sound judgment differs, the existing V1 builder produces a blind C queue with only those clips. A third distinct reviewer completes that queue.

The V2 intake verifies the source bundle, exact queue hashes, every WAV hash, A/B export hashes in the C receipt, C queue and C export hashes, complete record counts, opaque IDs and distinct reviewer IDs. Each agreed A/B value is final. For every disputed field, C must create a two-of-three majority. A transcript with no majority, an unclear majority, an unresolved or `unsure` after-speech judgment, or a transcript that differs from the source reference makes that clip fail its listening screen. The receipt keeps all three raw judgments and disagreement flags; it reports no pass without actual reviewer exports. A pass here means the recorded listeners heard the reference words clearly under this protocol, not a universal claim about human intelligibility. The independent Wav2Vec2 proxy is a separate screen.
