# Audio-aware Jacobian experiment: predict a causal spoken-word patch

Status: **design frozen before this candidate is run**, 2026-11-18. This plan uses the existing controlled `red`/`blue` spoken-word result only as a positive control. It does not claim that a Jacobian lens has decoded or explained that result. The exact fit/development/new-test item allocation is in [SPLIT_V1.json](SPLIT_V1.json). No candidate model or new-test audio was run to write this plan.

## Question and distinction from the text J-lens

Can a derivative of the **complete-answer preference** with respect to a specified span of audio-encoder or connector states predict the size and sign of the answer change caused by replacing those states with an opposite-word donor? The local prediction must be compared with the measured patch on the **same** hook, source positions, precision, prompt, and answer score. If it works at small edits, then a more reusable audio-to-answer readout may be worth fitting. If it fails, a vocabulary top-token display would be premature.

Anthropic's [Jacobian Lens](https://www.transformer-circuits.pub/2026/workspace/index.html) and [released fitter](https://github.com/anthropics/jacobian-lens/blob/581d398613e5602a5af361e1c34d3a92ea82ba8e/jlens/fitting.py) average full residual-to-residual derivatives over many text contexts and positions, then use a vocabulary readout. The first stage here is deliberately **not** that corpus-fitted lens: it is a context-specific, scalar-output Jacobian/VJP assay over audio rows. It tests whether such a derivative is causally predictive before paying for a full transport matrix or interpreting it as a general concept direction.

## Existing implementation that can be reused, and what must change

- [fit_terminal_jacobian.py](../../models/qwen_omni/fit_terminal_jacobian.py) is a checkpointed full-rank fitter for `J[j,i] = ∂h_35(last)_j / ∂h_l(last)_i` at text layers 0 and 17. It repeats one input eight times and needs `ceil(2048/8)=256` coordinate-batch backpropagations **per prompt**. Its graph-start hook and atomic checkpoint pattern are reusable. Its **same-last-position source slice** is not an audio-time lens and cannot be relabeled as one. A fresh implementation must retain a selected encoder/connector row tensor and take gradients at **all selected rows**, not `[-1]`. One scalar answer contrast needs one backward per candidate completion, avoiding 2,048-coordinate full fitting at this gate.
- [time_map/index.py](../../models/qwen_omni/time_map/index.py) maps the pinned processor's mel-frame count to 200-frame attention chunks, encoder rows, pooled connector rows, and actual audio-placeholder token positions; [the extractor](../../models/qwen_omni/time_map/extract.py) has source-pinned layer/connector hook examples. The frozen WAV manifest supplies a **known splice interval**. Select rows whose nominal centers fall inside that interval, record the full row map and hashes, and require equal donor/recipient sequence shapes. These are tensor indices, not forced phoneme boundaries: mel-window overlap and encoder self-attention spread information beyond the slot.
- [The full-model finite-difference audit](../semantic_bridge/FINITE_DIFFERENCE_AUDIT.md) found poor quantitative agreement for a previous terminal text-residual Jacobian under BF16, especially at layer 0. The new assay therefore measures the **effective BF16-rounded edit**, uses small-step checks, and treats any disagreement as a numerical or nonlinear finding. Do not infer that the earlier terminal matrix is already validated for audio rows.

## Causal quantity and measurement

Use pinned `Qwen/Qwen2.5-Omni-3B` Thinker revision `f75b40e3da2003cdd6e1829b1f420ca70797c34e` and Transformers source `e7e568dc7673ac99a87660c7c50e84830268285c`. For each recipient spoken clip `x_r` and opposite-word donor `x_d`, define two **canonical** complete continuations: title-cased answer word followed by the tokenizer's end-of-turn token. Freeze the exact tokenizer ID sequences and their byte strings before a model forward. For a continuation `y`, use teacher forcing to sum its log probabilities, including end of turn:

`L_y(x;H) = Σ_t log P(y_t | audio x, prompt, y_<t; H)`.

The donor-oriented complete-answer contrast is `S(H)=L_{y_d}(H)−L_{y_r}(H)`. This is a *sequence* log-likelihood contrast, not a single first-token logit and not a generated answer. At the recipient anchor `H_r` for a source site and row set `R`, save its gradient `G_R=∂S/∂H_R` and the matched donor-minus-recipient edit `D_R=H_d[R]−H_r[R]`. For each patch fraction `α`, form the actual BF16-rounded injected tensor `H_α` and predict

`ΔS_pred(α)=⟨G_R, H_α[R]−H_r[R]⟩`.

Then **measure** `ΔS_actual(α)=S(H_α)−S(H_r)` with the same teacher-forced candidate sequences, and separately generate the full greedy answer to end of turn. The local Taylor intercept `S(H_r)` is retained; do not use an uncentered `J·H` score. Score both red→blue and blue→red and reverse each new pair. When two candidate continuations require different forward graphs, compute their gradients separately and subtract. Do not sum gradients from nested encoder and connector hooks: each source site is a distinct intervention and causal question. A single source-gradient VJP is sufficient; no `[time × 2048 × 2048]` bank is required in this stage.

## Sites, windows, and edit sizes

Primary sites: post-block audio encoder layers **15 and 31** (`thinker.model.audio_tower.layers`), and the connector output (`thinker.model.audio_tower.proj` after adjacent-row pooling). Encoder layer 0 is a secondary diagnostic if memory permits. Map the same declared waveform slot to each site's own row indices with the pinned time map. For each site report the selected rows, attention-chunk IDs, tensor shape, donor-minus-recipient norm, and outside-slot feature differences. Do not treat a projected connector row as the same tensor position as an encoder row.

Start with `α={0,0.05,0.10,0.25,1.0}` on the fit positive control. Freeze the same grid for development and test; no per-item tuning. `α≤0.10` tests local derivative behavior; `α=1` tests the actual donor replacement and complete answer, where nonlinearity is expected. Record effective post-rounding edit norms and zero-edit equality. Use batch size one; retain at most the graphs needed for one candidate continuation at a time. Cut the gradient graph immediately **after** the earliest source hook being tested, preserving its tensor values but avoiding an unnecessary upstream graph. Capture a clean donor at the same site with `use_cache=False`, and verify cached/uncached prefill state agreement before comparing to `generate(use_cache=True)` patch outcomes.

Controls at each source site: self-patch; same-size wrong-time window in another chunk (report its natural edit norm); equal-norm random direction at the **correct** rows with fixed seeds 0/1/2; row-shuffled donor edit; and a wrong-time edit scaled to the word edit norm, explicitly marked as a synthetic out-of-distribution control. The zero-prediction baseline is `ΔS=0`. Compare the local Jacobian's sign and absolute error against zero and a fit-only scalar norm predictor; never choose the stronger baseline after seeing test outcomes. Full-answer donor flips are reported for these controls, along with malformed and no-EOS outcomes. For the time-resolved claim, report a per-row contribution `⟨G_r,D_r⟩` and its summed prediction, not merely a heatmap; row contribution after self-attention is a *sensitivity at that tensor site*, not an attribution to an isolated acoustic frame.

**Fit-only scalar norm baseline, fixed before candidate model evaluation (2026-11-18 amendment):** for each site independently, use fit positive-control routes from both original voices and both patch directions, and only `α∈{0.05,0.10}`. For case `i`, let `n_i=||H_α[R]−H_r[R]||_F` after BF16 rounding and `z_i=ΔS_actual,i` in the donor-oriented answer contrast. Set `β_site=max(0, Σ_i n_i z_i / Σ_i n_i²)` if the denominator is positive, and `β_site=0` otherwise. The norm-only prediction for every later case at that site is `β_site n`; use the same coefficient for all development/test items and patch fractions, with no intercept or per-voice fit. Record the fit rows and coefficient in a hashed artifact before opening the new test. This comparator deliberately ignores edit orientation. It is not part of the first one-route VJP plumbing gate and cannot be calibrated from a single route alone.

## Frozen split and run order

1. **Fit positive control:** existing red/blue controlled pair, both original Piper Lessac and Kokoro Sarah routes. Verify the published patch and clean complete answers from the saved artifacts without modifying them. Test the derivative at one connector site and one encoder site first. If local numerical checks fail, diagnose VJP orientation, hook placement, BF16 precision, and cached/uncached prefill behavior before enlarging the run.
2. **Development:** the separate [heldout_flow manifest](../heldout_flow/stimuli_v1/manifest.json) contains `cat/dog` and `Monday/Friday`, two new phrasings and two new voices. Only after that set's own prespecified boundary assay is scored may it be used for this Jacobian implementation/debugging. Once thresholds, parser and code are fixed, stop tuning. These items are not this experiment's test set.
3. **New locked test:** [SPLIT_V1.json](SPLIT_V1.json) fixes `north/south` and `seven/eight`, two further phrasings, and the pinned Piper Amy/Kokoro Bella render configuration. Render and hash all 16 test WAVs with identical PCM outside each swapped word slot **before** any Jacobian or model answer on them. Add the immutable WAV manifest SHA as a versioned companion artifact; do not edit the split definition to accommodate a failed clean response. Test has eight matched pairs and 16 directional patches per site. Voices are new relative to the fit pair, but reused in development, so only lexical/phrasing transfer is independently held out.

## Gates and interpretation

**Plumbing gate:** CPU toy tests prove gradient orientation and row selection, zero/self edit reproduces exact answer scores, hook fires once, and a fresh VJP agrees with the saved gradient for one fixed fit input. Validate all hashes and exact candidate tokens. Abort the candidate claim if a source row is disconnected or the test/frozen split does not match.

**Locality gate:** on the fit pair and then development, at `α=0.05` and `0.10`, record per-case sign agreement, median absolute error, median relative error, and prediction-versus-measurement scatter for `ΔS`. A useful pre-test threshold is sign agreement ≥75% on nonzero measured effects and at least 25% lower absolute error than the zero predictor, separately at the connector and at least one encoder layer. Cases whose measured change is below a frozen BF16/numerical-noise floor are *indeterminate*, reported with counts, never counted as correct signs. If this gate fails, report failure and stop before full-rank fitting; investigate precision or derivative definition on fit/development only.

**Locked-test gate:** apply the fixed code, thresholds and patch grid once to all 16 directional test cases per site. Report both the all-planned denominator and a clean-eligible denominator; no silent exclusions. For a transfer claim, require the same sign/error threshold at `α≤0.10` for connector and one encoder site, and demonstrate better error than both frozen baselines. Show category, phrasing and TTS-family rows separately; with only two lexical contrasts, avoid strong inferential or security claims. At `α=1`, report full greedy donor-answer flip rate and measured-versus-predicted `ΔS` but **do not** require the local Jacobian to stay quantitatively correct. A small-step pass with large-step failure supports local linearity plus nonlinear transition, not a reusable global lens. A changed score without a complete generated answer change is score-level evidence only.

**Next step only if gates pass:** fit a reusable audio-to-terminal transport on a larger **fit-only** corpus, with row-region policy and source/target centering frozen. The existing 2,048-wide coordinate fitter implies 256 backward batches per prompt at batch 8 even for one output-position map; a per-audio-row full matrix would be much larger. Benchmark one connector-region fit first, compare an affine transport with an anchor-constant baseline, and introduce a separately frozen larger test set. Neither a single local VJP nor a favorable 16-direction result should be presented as an Anthropic-style corpus-averaged J-lens, a circuit explanation, or a security vulnerability.
