## Development Stage A

The current runner SHA-256 is `6f314b7a2322ff33ab0fdccb190a805702f26e59197f30460fcd36b8faac8745`; metrics SHA-256 is `448f619332a9f96ea58358dcb07cab37f332b818817033b6ce449621d599b67c`. The runner binds the frozen spec, render manifest, protocol, V2 policy, FIT lens, calibration raw/report, and ridge baselines/report before model work. Its loader selects only `split == development`, requires 48 matched pair records and 96 unique directions over 12 word pairs, verifies each chosen WAV hash and exact int16 PCM equality outside the word slot, and never selects a case using candidate answers. It leaves the locked-test media unopened.

The clean stage captures all 96 source and terminal states and full greedy answer+EOS outputs; prefix checkpoints are metadata- and hash-bound. For each direction, donor source means come from the opposite word in the same pair/voice/template. Both sites use the same six bins and α grid `(0, .005, .01, .025, .05, 1)` as the protocol. The map, global ridge, six-bin ridge, and zero comparator all predict a donor-oriented V2 score change from the clean recipient anchor. The measured score has the same orientation. The runner saves V1 movement, full generated suffix, rank-16 capture, effective edit norm, category-anchored absolute readout, α=0 score/state/answer checks, hook counts, and memory. Failures produce a numbered record with the 96-planned denominator rather than a partial pass.

The primary metrics keep **96 directions × three small α values = 288** conditions per site in the gate. They require 72 clean semantic complete answers, 72 classified first tokens with 75% purity, at least 48 above-floor effects with 75% sign agreement, valid 288/288 measurements, map MAE ≤75% of each of zero/global/six-bin MAE, and at least 68 absolute-anchor improvements. Invalid measurements or absolute scores fail the gate; they are not silently dropped. Pair bootstrap resamples 12 pairs with all eight related observations retained. Five CPU toy tests pass, including score orientation, comparator shape, all-planned gate, toy generation hook, and rejection of early EOS/hidden special IDs.

**Claim limit:** Stage A is only the frozen primary screen. Even a pass requires Stage B time controls and canonical complete-sequence scoring before a positive development claim. This code and the FIT smoke have no security endpoint.
