# Prospective evaluation protocol for the corpus-fitted Qwen transport

**Status: pre-development draft for independent review, 2026-11-18.** The rank-16 FIT map was already specified and launched before this evaluation document. The V2 prefix policy was made after FIT-only answer inspection; its promotion here is explicitly fit-informed. No Qwen development or locked-test answers have been opened for this corpus. Freeze this document, evaluator code, fit calibration artifacts, and hashes before development inference. A later edit requires a new version and cannot silently reclassify a result.

## Fixed population and target

Use `SPEC_V1.json`, `rendered/manifest.json`, `SCORING_V2.json`, and the committed rank-16 fitter. The map-fit sample is exactly 48 contexts: 12 pairs × Piper/Kokoro × two directions × `fit_chosen`. The prospective development and locked-test samples each contain **96 planned directional contexts**: 12 disjoint pairs × two voices × two directions × two split-exclusive templates. Keep every planned context in every denominator. No answer-based example replacement. The model is pinned Qwen2.5-Omni-3B Thinker in FP32 on MPS, with a 30 GiB driver-allocation stop. The terminal state is prompt-last post-block-35 residual before language-model final norm. Sites are post-encoder31 and post-connector; they are evaluated separately.

At each site, use the six disjoint nominal-row-center bins from the frozen swapped-word sample slot: one preword quarter, four word quarters, one postword quarter. At a boundary, assign to the earlier bin, except the first lower endpoint belongs to the first bin. If any bin has zero rows, record an invalid planned context; do not move boundaries. The donor is the opposite word in the same pair, voice, and template. If donor and recipient source tensor shapes or row maps differ, record invalid; do not align after observing answers. Set `δ_b = mean(H_donor[b]) − mean(H_recipient[b])` and apply the **uniform bin edit** `H_recipient[t in b] += αδ_b` for each of six bins. This is the primary causal intervention. It differs from a rowwise donor swap and from naturally changing the waveform.

Use `α={0, .005, .01, .025, .05, 1}`. The three nonzero small steps are primary; `.05` displays curvature and `1` is descriptive. Measure the same no-grad unpatched reference and uniform edit in FP32; repeat `α=0` three times per fit context and require identical prompt token IDs, hook count one, and no edit norm. A score difference larger than `1e-4` at `α=0` is an invariant failure. The fit numerical floor per site is `max(1e-4, 5 × max absolute repeated-zero score departure from its three-run mean)` across all 48 fit contexts, using the primary V2 score. Freeze it before development. Report effective edit norms and all six row lists. Do not remove effects below the floor from MAE.

## One primary scalar and distinct behavioral endpoints

At any terminal residual `h`, apply the pinned language-model final norm and output head. Let `A_w` be the frozen V2 first-token ID set for word `w` from the tokenizer's deterministic encodings of exactly four predeclared surfaces (bare/space × lowercase/titlecase). Require `A_recipient ∩ A_donor = ∅` for every pair. The primary scalar is donor-oriented **V2 prefix log odds**

`S₂(h)=logsumexp(logits(h)[A_donor])−logsumexp(logits(h)[A_recipient])`.

It is a first-token score; a shared initial token can start an unrelated word. It does **not** claim to predict a complete answer. The same formula with original single-token V1 alias IDs is a named secondary replication. Save the full-vocabulary top token, V1/V2 token sets and mass, raw generated token IDs, decoded text, EOS flag, strict one-word exactness, and case-folded semantic correctness for every unpatched and patched run. The complete-sequence+EOS log-probability contrast over the frozen V2 sequences is a separate behavioral endpoint, requiring teacher-forced continuations; it must not enter prompt-last map MAE. Report prefix coverage and purity separately: (a) fraction of generated first tokens lying in either pair class, and (b) among such classified outputs, fraction whose **complete** answer+EOS is exactly the word indicated by that class. Require at least **72/96** classified clean first tokens and at least **75%** purity among those classified. Report the unclassified count separately. This is a fit-informed task-fidelity condition, not a guarantee that prefixes uniquely name words.

For source site `s`, map `J_s` is `[6,16,width_s]`, target basis `U` is `[2048,16]`, and the predicted residual after the uniform edit is `ĥ(α)=h_clean+α U Σ_b J_{s,b}δ_b`. The predicted score change is `S₂(ĥ(α))−S₂(h_clean)`. The measured change is `S₂(h_uniform(α))−S₂(h_clean)`. The recipient anchor is the **actual no-grad clean residual for that context**; no test gradient or donor terminal state enters prediction. Save residual projection coverage `||UUᵀ Δh_actual||² / ||Δh_actual||²` for each nonzero edit, and also for the natural donor-minus-recipient terminal difference; report zero-denominator cases separately.

## Fit-only calibration and fair comparators

Before development, measure the uniform edit at **α=.025** for all 48 map-fit contexts, both sites. This uses the same `δ_b`, hook, terminal residual, and primary score as development. Store every measured target residual difference `y_i=(h_uniform(.025)−h_clean)/.025` and six-bin input `x_i=[δ_0,...,δ_5]`; retain failures, do not substitute another alpha. Train each baseline separately per site, with the same 48 contexts and rank-16 output `Uᵀy_i`:

- **Zero:** predict no terminal or score change.
- **Global ridge:** use the **recipient-row-count-weighted** mean `Σ_b n_b δ_b/Σ_b n_b`, where `n_b` is the number of source rows in bin `b`, as input. Require donor and recipient row sets to match exactly; otherwise the planned context is invalid. Fit a no-intercept rank-16 ridge map.
- **Six-bin ridge:** concatenate all six `δ_b` vectors and fit a no-intercept rank-16 ridge map. This baseline has more feature capacity than the corpus Jacobian; report that difference.

For both ridge maps, divide every input by the FIT-only global RMS of the corresponding 48×feature matrix (one scalar per site/baseline; if zero, fail). Use float64 dual ridge `K=XXᵀ/d` and `A=(K+λI)^{-1}Y`, with `λ=γ trace(K)/48`, `γ∈{1e-4,1e-3,1e-2,1e-1,1,10}`. Choose γ by leave-one-**pair**-out RMSE of projected terminal target on the 12 map-fit pairs; four related contexts never cross a fold. Ties choose the smaller γ. Refit on all 48. No intercept, per-item scale, hand-picked coefficient, or development tuning. Save inputs, targets, fold errors, chosen γ, dual coefficients, hashes, and measured memory. Both comparators predict `ĥ=h_clean+α U Ŷ(x)` at development, passed through the same final norm/head and V2 score. Thus their training target and alpha are the same uniform intervention as the corpus Jacobian; a larger capacity does not grant them extra examples. Also compare the absolute category-centered affine readout with its same-category constant anchor, separately from this recipient-anchored primary test.

## Development decision, then locked test

Run development once with frozen code/artifacts, then evaluate locked test only if both primary sites pass development. For each site, primary MAE is mean `|ΔS_pred−ΔS_measured|` across **96 directions × three small alphas**; invalid planned conditions count as failures of the gate and remain in the planned count. Report per-category, voice, template, and pair-level rows. A site passes only if:

1. At least **72/96** clean unpatched answers are semantically correct, one-word, and end on EOS; at least **72/96** clean first tokens are classified by one of the two V2 prefix sets, with at least 75% purity among classified outputs.
2. At least **48/288** measured small-step effects exceed the frozen fit floor, and signs match in at least **75%** of those determinate effects. This minimum demands roughly one determinate condition per two planned directions; it prevents a small easy subset from defining the sign result. A zero predicted effect mismatches any determinate measured effect.
3. All 288 measurements and predictions are valid, and map MAE is **≤.75×** each of zero, global ridge, and six-bin ridge MAE. If any comparator MAE is zero, the gate fails; ratios are then undefined, not infinite success.
4. For the absolute readout, use the frozen word-pair category `c` as an **oracle metadata label**, supplied equally to the lens and constant comparator: `ĥ_abs=μ_T,c + U Σ_b J_b(z_recipient,b−μ_source,c,b)` and `ĥ_const=μ_T,c`. Score each as expected-word versus paired-foil V2 prefix log odds. `S₂(ĥ_abs)>S₂(ĥ_const)` on **at least 68/96** planned contexts (the integer realization of ≥70%); exact ties, invalid cases, and wrong clean answers remain in the 96 denominator and receive no improvement credit. This is a separate required usefulness check, and it does not establish an answer was correct.

Pair-level bootstrap: resample the 12 held-out word pairs with replacement for 10,000 replicates using NumPy seed 20261118; retain all eight voice/direction/template observations within a selected pair. Report 2.5/97.5 percentile intervals for MAE ratios, sign rate, complete-answer rate, and absolute-anchor improvement. The point gates above do not use confidence bounds, but bounds prevent pseudo-replication of 96 dependent directions. Do not claim a pass if any invalid condition is silently dropped. Report clean-eligible subsets only as secondary.

Time controls at `.025` on all planned directions: self edit, six-bin reversal permutation `(5,4,3,2,1,0)` of the six `δ` vectors, word-bin-only edit `(1,2,3,4)`, preword-only and postword-only edits rescaled to the word-bin edit Frobenius norm (record zero-norm ineligibility), and same-row Gaussian norm-matched edits with seeds 0,1,2. Compare measured V2 score and full answer+EOS. Label time selectivity only if the word-bin-only edit has larger absolute score change than **each** available preword/postword/reversed-bin control in at least 75% of clean-eligible directions, and fewer than 10% of those controls yield an exact donor answer. This is a secondary attribution label; it cannot rescue a failed primary gate. Because later encoder rows have attention context, time bins are locations of intervention, not proof that information originated exclusively at those acoustic times.

Separately report natural donor-audio change and full rowwise donor patch at α=1, including complete answers. Compare their terminal/score changes with uniform-map prediction only as **approximations**. Never count them as primary calibration hits. The earlier Qwen local derivative and Voxtral frontend findings are prior observations, not outcomes of this prospective corpus.

On a development pass, commit the fitted map, calibration, code, thresholds, input hashes, and full development outputs before any locked-test model inference. Use the identical scoring and gates once on locked test. A passing result supports a reusable task-specific audio transport, not a security exploit; a separate frozen authorization task is needed for a security claim.
