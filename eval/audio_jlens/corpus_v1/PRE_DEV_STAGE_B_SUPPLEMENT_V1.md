# Prospective Stage B supplement, version 1

**Status: proposed freeze before Qwen development candidate outputs.** This document specifies conditional Stage B checks for `PRE_DEV_EVAL_PROTOCOL_V1.md`. It does not change that document, its hash, the Stage A script, the Stage A primary gates, or the locked-test rule. Run Stage B only if **both** sites pass Stage A. If Stage A fails, stop and report it; no Stage B run is needed. All threshold and control definitions below are judgment calls made without development or locked-test model outputs. Freeze this document and the Stage B code by hash before using either split. Any later change is a new version and cannot reclassify v1.

## Population, model, and measurement

Use the same fixed 96 directional contexts per split, two sites, matched donor, six frozen row bins, prompt, FP32 Qwen Thinker revision, V2 policy, and 30 GiB MPS bound as the parent protocol. A planned case remains in the denominator even if its clean answer is wrong, a control is invalid, or inference aborts. The complete condition grid and all invalid rows must be saved. Bind the parent protocol, this supplement, Stage A result, corpus spec/manifest, lens, FIT calibration/baselines, model/Transformers revisions, and Stage B implementation by SHA-256. No development case or control is chosen using an answer.

Define a **clean-eligible direction** as one in which *both* unpatched recipient and matched donor generated the correct respective one-word answer with terminal EOS and no nonterminal special token. This is stricter than the Stage A clean fidelity gate. Require at least **72/96 clean-eligible directions per site** for a time-selectivity label; report the count over all 96. If fewer qualify, the time-selectivity label is unavailable/failed. This threshold is a judgment call.

For a site and a control, measure donor-oriented V2 prefix movement `ΔS₂ = S₂(h_control)−S₂(h_clean)` with the same no-grad clean recipient anchor as Stage A. Record complete generated IDs, decoded answer, EOS/special-token validity, terminal state change, support mask, hook call count, and effective source edit Frobenius norm. A patched call must fire exactly one source hook. The self control must have zero effective edit and match clean `|ΔS₂|≤1e−4`, terminal residual within `1e−3` max absolute, and identical generated IDs in **all 96 directions at both sites**; any failure invalidates the site's Stage B interpretation.

## α=.025 time-control construction

For each recipient, let `δ_b` be the already frozen donor-minus-recipient source mean in bin `b`; `n_b` is that bin's row count. Apply each intervention to a fresh clean recipient forward. Never compound controls. The following eight controls are fixed per direction and site:

| Name | Edit on recipient source rows |
| --- | --- |
| `self` | Six zero vectors, same selected rows. |
| `reverse` | Add `.025 δ_(5−b)` to every row in bin `b`, for `b=0…5`. No row relocation. |
| `word` | Add `.025 δ_b` to bins `1,2,3,4` only. |
| `pre` | Add `.025 c_pre δ_0` to bin `0` only, where `c_pre=N_word/N_pre`, `N_word=.025 sqrt(Σ_{b=1}^4 n_b||δ_b||²)`, and `N_pre=.025 sqrt(n_0||δ_0||²)`. |
| `post` | Analogously scale bin `5` to `N_word`. |
| `gaussian_0/1/2` | Add zero-mean unit normal values to **the same union of six selected bins** as the full uniform edit, with exactly the full uniform edit norm `N_full=.025 sqrt(Σ_{b=0}^5 n_b||δ_b||²)`. |

For each Gaussian, create a CPU `torch.Generator` and seed it with the unsigned low 63 bits of `SHA256("stage-b-v1|" + case_id + "|" + site + "|" + seed)` for seed `0`, `1`, or `2`. Draw one FP32 normal tensor in row-order and width-order, subtract its mean over all selected elements, and scale it by `N_full/||G||_F`; copy it to the model device without changing its values. Save seed string, tensor SHA-256, target and realized effective norms. If `N_full=0` or sampled norm is zero, mark that control invalid; do not redraw. The choice of full-six-bin support/norm is a judgment call that resolves the parent protocol's unspecified Gaussian reference.

If `N_word`, `N_pre`, or `N_post` is zero, record the affected pre/post control as **zero-norm ineligible**; do not invent a scale. A direction enters the time-selectivity comparison only if it is clean-eligible and word, reverse, pre, and post controls all produced valid scores and complete outputs. Require at least **72/96 such comparison-eligible directions per site**; the remaining directions stay visible in the 96 planned count. For each comparison-eligible direction, word `|ΔS₂|` must be *strictly* greater than **each** of reverse, pre, and post `|ΔS₂|`; ties fail. Require at least **75%** of the comparison-eligible directions to pass. Do not silently drop changes below the frozen FIT V2 numerical floor: report their count, but compare them as measured. These minimum-coverage and tie rules are judgment calls.

For each of reverse, pre, and post **separately**, require an exact donor answer with valid terminal EOS and no nonterminal special token on **strictly fewer than 10%** of comparison-eligible directions. At `N` eligible directions this means donor count `<0.1N`, not `≤`. Report Gaussian and self donor-answer rates separately but do not include them in this label. A site earns the secondary **time-selectivity label** only if self invariance, both ≥72 coverage requirements, ≥75% word dominance, and all three `<10%` negative-control rates hold. This label concerns intervention location; it does not establish acoustic origin because later encoder rows can contain context from earlier audio.

## Canonical complete-sequence-plus-EOS endpoint

For every one of the 96 planned directions, compute a teacher-forced complete-sequence score on the following **four** conditions per site: unpatched recipient, uniform six-bin edit at α=.025, natural donor WAV, and full rowwise donor patch at α=1. Clean and natural donor scores may be shared across sites only if the exact prompt/input/state is hash-identical. Time controls need generated full answers and V2 prefix scores but **do not** require teacher-forced complete-sequence scoring. This four-condition scope is a judgment call resolving the parent protocol's otherwise unspecified condition matrix; the six other Stage A alphas remain outside this canonical gate.

Use only the unique `SCORING_V2.json` canonical answer-token sequences plus EOS. For candidate `c_0…c_(n−1)`, append `c_0…c_(n−2)` to the prompt, take causal logits at `[prompt_len−1 : prompt_len−1+n]`, and sum `log P(c_i)` including EOS. Apply any audio hook only to the prompt audio pathway, exactly once per candidate forward. Combine each word's variant log probabilities with `logsumexp`, with no length normalization or variant chosen from generated output. Define donor-oriented complete contrast `C = logsumexp(log P(donor variants+EOS)) − logsumexp(log P(recipient variants+EOS))`. Save every variant score, both class scores, `C`, and all full generated answers. A first-token prefix score cannot substitute for `C`.

Before development, derive a FIT-only canonical numerical floor for each site: repeat the α=0 patched teacher-forced score three times on **all 48 map-fit contexts**, then set `f_C=max(1e−4, 5×max|C_zero_repeat−mean(C_three_zeros)|)`. Freeze the floor artifact and its code/input hashes. An α=0 complete-score drift above `1e−4` from the clean reference is an invariant failure; do not adjust the floor to excuse it. This FIT floor is an additional judgment call. For a **positive complete-score directional-effect label**, require valid canonical scores for **96/96** directions per site and `C_uniform(.025)−C_clean > f_C` on at least **72/96** directions per site. Opposite-sign and sub-floor changes remain in all 96. This is an explicitly conservative, newly chosen threshold; it assesses an **observed** complete-sequence probability movement, not a fitted-map prediction of later decoder tokens or generated-answer flips.

Report exact donor-word+EOS generations for the Stage A α=.025 and α=1 uniform edits separately, over all 96 directions and over clean-eligible directions. A separate **full-answer causal-effect label** requires at least **24/96** exact donor-word+EOS outputs under the α=1 uniform edit at each site; this is a judgment-call threshold and must never be conflated with the small-step transport gate. If this label fails, report probability movement without claiming that the edited model changed complete answers reliably.

## Natural donor and full rowwise patch

The natural donor condition is the matched donor WAV, same prompt and decoding settings; save its full answer/EOS, terminal residual and V2/complete scores. Its difference from the recipient is descriptive and never enters uniform-map MAE. The **full rowwise donor patch** replaces **every row of the site's entire recipient source tensor** with the saved donor source tensor, not only the six bins. Require identical full shapes and prompt token IDs; use one source hook and no other edit. Save source tensor/hash, full replacement mask and Frobenius norm, terminal residual, V2/complete scores, and generated answer. Compare full patch with natural donor, recording terminal max-absolute and norm differences, V2 and canonical contrast differences, and exact generated-ID equality. A site earns a **full-source boundary replay/equivalence label** only if all 96 valid full patches reproduce natural-donor generated IDs and terminal states within `1e−3` max absolute, and V2 score within `1e−4`; otherwise report the failure. This checks downstream pipeline consistency at the chosen boundary; it does not identify a localized lexical circuit. A narrower lexical-task sufficiency claim additionally requires all 96 natural donor answers to be the correct donor word with terminal EOS and no nonterminal special token. These exact rules are judgment calls. Neither natural donor nor full rowwise patch counts toward the uniform-map MAE or time-selectivity gate.

## Decision and reporting

Keep three separate labels per site: Stage A primary **prefix-map transport** gate, Stage B secondary time-selectivity label, and Stage B **observed complete-score directional-effect** label; report the full-answer causal-effect and full-source boundary replay/equivalence labels separately. A **positive development claim about reusable audio-to-text prefix transport with an observed complete-sequence effect** requires both sites to have passed Stage A and the complete-score directional-effect label, plus 96/96 case records and valid canonical scores for all four conditions. Time-control invalidity is governed by its separate ≥72/96 comparison-eligible rule; it does not silently remove cases from the 96 planned rows. The time-selectivity label supports a narrower location claim only when it passes. A claim of reliable changed full answers requires the separate full-answer label. No combination of these labels establishes a security violation; that needs a separately frozen authorization endpoint. If either Stage B site's complete-score directional-effect label fails, report the negative result and do not advance to locked test under this v1 claim. This stricter advancement rule is a judgment call made before development outcomes; it cannot be used to erase Stage A results.

Report raw 96-direction denominators, invalid counts, score distributions, all four canonical-condition scores, complete answers, per-control donor rates, time-selectivity components, full-patch/natural differences, category/voice/template/pair breakdowns, and pair-clustered 95% intervals. Freeze the exact same Stage A/B rules for a one-shot locked-test evaluation only after prospective development passes.
