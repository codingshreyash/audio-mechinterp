# Independent audit: FIT local-Jacobian first-context smoke

**18 November 2026.** Read-only CPU audit of `fit_jacobian_heterogeneity_v1.smoke.json`, its checkpoint and MPS memory log. I did not run Qwen inference or open development/locked-test audio, activations, or answers. The smoke is a method/plumbing check, not a heterogeneity or security finding.

All SHA-256 fields in smoke metadata match the current frozen script, protocol, FIT report, rank-16 lens, corpus spec/manifest, stage-1 tensor, FIT calibration tensor/report, and V2 scoring policy. The smoke's checkpoint SHA-256 is `8d942779855530f38192b7406ee676838d3af97add12371691ed5ee3e7195b44`; memory-log SHA-256 is `6d08e5ee28c6357f3480e2400bff105701dc40ae27ff31af34d012576517629d`. Checkpoint metadata exactly matches the smoke JSON. It contains **one** record, the first frozen FIT context `animal_06/fit_chosen/kokoro/deer`, with the same audio hash, case ID, source shapes, and six row counts as stage 1. Its grad/no-grad terminal maximum difference is **0.000412**, below the frozen **0.001** tolerance.

The record has exactly **16 VJP times**, one for each fixed target coordinate. Both local matrices are FP32, finite, and nonzero: encoder31 `[6,16,1280]`, norm **70.0445**; connector `[6,16,2048]`, norm **96.1115**. Every one of their six bins and 16 coordinate slices has nonzero norm. The saved matrix shapes, norms, and VJP times agree with the smoke JSON. The 18 memory entries are `after_model_load`, consecutive coordinate **0–15**, and `after_case_1_checkpoint`; none reports over limit. Observed peak driver allocation is **21,734,621,184 bytes**, below **32,212,254,720 bytes** (30 GiB). The logged post-load span is **3.46 s**; the runner also checks the 1,200-second invocation deadline at operation boundaries, including before/after each VJP. The artifact does not separately record pre-load elapsed time, so the log alone cannot independently time that portion.

**Verdict: no smoke blocker for the planned 48-context FIT run.** This verifies one retained-graph 16-VJP context and its provenance/resource checks. It does not validate the eventual 48-context statistics, the negative Stage A result, or any development/locked-test generalization.
