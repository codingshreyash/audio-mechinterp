# FIT-only local-Jacobian heterogeneity diagnostic, v1

**Scope:** Diagnostic following the frozen negative Stage A v1 result. Use only the original 48 `map_fit` FIT contexts, saved rank-16 basis/lens, stage-1 states and rows, and measured α=.025 uniform edits from FIT calibration. The frozen corpus spec/manifest contain metadata for all splits, but this assay opens no development/test WAV, candidate model output, or activation. Results cannot rescue or relabel Stage A v1.

For each FIT context, recompute the local derivative of the 16 target coordinates at the prompt-last post-block35 residual with respect to the six *uniform* source-bin edits at post-encoder31 and post-connector. Use the pinned FP32 model and Transformers revision, the original no-grad/grad parity check, exactly 16 VJPs on one retained graph, one source/target hook pass, and six source row sets from frozen stage 1. Each local matrix is `[6,16,width]`, with a bin gradient equal to the **sum** over that bin's rows. Requiring the mean instead would change the edit derivative. Save every local matrix and per-coordinate timing; cap MPS driver allocation at 30 GiB, check a 20-minute invocation deadline before and after each VJP and during final score analysis, and checkpoint after each completed context for a hash-bound resume.

For the same donor-minus-recipient six-bin `δ` and α=.025 calibration target, compare three maps at each context: (1) its own local Jacobian, an **in-sample oracle diagnostic**; (2) the previously frozen 48-context corpus mean; (3) a **leave-one-pair-out** mean of the other 44 local Jacobians, excluding all four related contexts of its pair. Use the same saved target basis and clean recipient residual for all three. Report predicted terminal change in the fixed rank-16 span, full-terminal and projected-terminal error/cosine, captured terminal-energy fraction, and donor-oriented V2 prefix score prediction versus the saved measured FIT change. Recompute the corpus mean from local matrices and compare with the frozen lens. Report mean absolute V2 score error and terminal metrics over all 48, plus 12 pair means; no answer-based filtering. The leave-one-pair-out map is **conditional on a basis fitted on all 48 FIT contexts**, so it is not a fully held-out representation estimate or an efficacy test.

For each site, compute Frobenius cosine between every unordered pair of 48 local matrices (1,128 pairs). Report the raw uniform-edit derivative and a secondary per-row-mean-gradient version that divides each bin by its recipient row count, because bin duration can affect raw derivative magnitude. Report fixed strata: within lexical pair with same voice (24), within lexical pair across voices (48), between lexical pairs in the same category (192), and across categories (864), plus all same-voice versus cross-voice pairs (552 and 576, respectively). These overlap in voice but partition by pair/category as stated. Report counts, mean, median, and 10th/90th percentiles, and the complete 12-pair table; do not select a favorable subgroup. Save hashes of the pinned input artifacts, script/protocol, checkpoint, memory log, and result. All score predictions must use the frozen V2 first-token sets and pinned final norm/head; complete-answer behavior is outside this assay.

Preflight with CPU toy derivatives and saved-metadata validation; then run a **first-context smoke** with all 16 VJPs and no full result. Only after independent review of the exact code and smoke should the 48-context MPS run start. A failed context is retained as a failed diagnostic, not replaced. No development or locked-test model inference is permitted.
