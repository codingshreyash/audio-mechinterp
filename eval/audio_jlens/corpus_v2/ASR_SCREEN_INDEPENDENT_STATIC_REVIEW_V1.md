# Independent static review of prospective v2 ASR screen

**18 November 2026.** I reviewed the committed prospective runner `40c52a6` against `ASR_LISTENING_QA_PROTOCOL_PROSPECTIVE_V1.md`, the frozen rendered-v2 manifest and technical binding, and the v1 Whisper audit. This review covers source and CPU-only preflight. **No v2 ASR model was loaded and no v2 ASR inference was run.** The ongoing Voxtral development run was not inspected or disturbed.

## Result

The ASR runner has no identified source-level blocker for its narrow job: collect raw output from both recognizers over the exact frozen 480-clip set. Its `--run` modes remain **blocked** by the deliberately absent `ASR_SCREEN_FREEZE_V1.json`. The broader QA protocol has another unmet pre-outcome gate: the independent outcome auditor that will compare all 960 raw transcripts with references and audit blinded listening is not yet committed. The technical WAV auditor `audit_wavs_v2.py` does not perform that job. Do not issue the freeze receipt or run either recognizer until the outcome auditor is committed and independently reviewed.

## Checks

- `--validate-only` completed with `clips: 480` and no output transcript. It rehashed all 480 WAV files, decoded and rehashed their int16 PCM, and confirmed one-to-one coverage of the manifest. The runner's `ASR_INPUTS_PROSPECTIVE_V1.json` has only opaque ID, path, WAV/PCM hashes, and frame count. The synthetic test independently compared it with the frozen private case-map projection. Source hashes match the manifest `15395c7d…`, binding `858f8f68…`, case map `d9a08a61…`, inputs `74f38f67…`, and pins `1136baf1…`.
- Both cached models resolved by exact revision, with every listed weight, processor, tokenizer, and config file rehashed. Whisper is `openai/whisper-tiny.en@87c7102498dcde7456f24cfd30239ca606ed9063`, safetensors `db596959…`, matching the v1 independent audit. Wav2Vec2 is `facebook/wav2vec2-base-960h@22aad52d435eb6dbaf354bdad9b0da84ce7d6156`, safetensors `8aa76ab2…`. The runner checks the pinned runtime versions and nine installed Transformers source files. The two use different decoding architectures: greedy Whisper generation and framewise argmax with CTC collapse.
- At the model call, each recognizer receives a single 16 kHz waveform. Neither call receives a reference transcript, target word, candidate list, Qwen result, or filename. The host reads the full manifest to verify input identity, but passes only audio to the recognizer. `--run` sets CPU execution and four intra-op threads, processes one clip at a time, and uses offline local checkpoints. It refuses an existing output directory; there is no resume path.
- The runner writes the raw transcript and token IDs for each clip to `raw.jsonl`, flushing and syncing each row. It performs no reference comparison or normalization. It requires 480 ordered, unique, hash-matched rows before writing `complete.json` with the raw file SHA-256. Exceptions produce an incomplete receipt; a hard termination leaves no complete receipt. The separate auditor must verify the complete receipt and raw SHA before comparison. A 128-token Whisper cap and EOS status are logged so truncated outputs can be identified downstream.
- `test_asr_screen_v2.py` passed: **3 tests, 2 subtests**. These cover the fixed input projection and model-cache preflight, missing-freeze rejection, and malformed raw-log rejection. The tests do not establish ASR quality, human intelligibility, or a Qwen mechanism.

## Required before any v2 ASR outcome

1. Commit and independently review the outcome auditor specified by the QA protocol. It must verify both full 480-row raw logs and hashes, recompute normalization, WER and every prescribed stratum, preserve failures, then audit listener coverage and the final go/stop rule. Its source must be frozen before outcomes. This is the current protocol blocker.
2. Issue a separate `ASR_SCREEN_FREEZE_V1.json` only after that review. It must bind the exact prospective runner SHA-256 `7df490c768d929e63845e00397ae1f0f77ba5b7f03722479fa8f5826527b4b78` and the already pinned protocol/input/model hashes. The current runner checks these values but does **not** itself bind the future auditor or listening-interface source; the independent freeze process must record those source hashes as part of the QA audit trail.
3. Run Whisper and Wav2Vec2 serially with fresh output directories after the active Voxtral run is clear. A complete pair of ASR passes is **480 + 480 = 960** raw outcomes. Neither ASR agreement nor a completed ASR screen substitutes for the required blinded human review of all 480 clips.

This review approves only the prospective ASR collection design, conditional on those pre-outcome gates. It reports no ASR result, input-quality pass, security finding, or model-mechanism claim.
