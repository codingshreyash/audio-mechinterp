# Prospective amendment: ASR middle-slot review flag

**18 November 2026. Before any v2 ASR or human-listening result.** This amendment clarifies the already frozen [480-clip quality protocol](ASR_LISTENING_QA_PROTOCOL_PROSPECTIVE_V1.md). It does not change the corpus, references, opaque IDs, blind queue, model pins, normalization, or quality-confirmation vote rule. It is a conservative addition to the *second-listener flag*: each recognizer's normalized full-script tokens must exactly match the normalized reference tokens to avoid an ASR flag. Any mismatch triggers a second blinded listener, even when the intended middle word appears once elsewhere in the transcript. The original whole-token occurrence and WER remain descriptive metrics, not proof that the word occupied the fixed middle slot.

For example, if the reference is “Say otter now” and an ASR returns “Otter say other now”, the token `otter` occurs once but the spoken middle slot was transcribed as `other`. The case must be flagged. The existing first-listener and ASR-disagreement flags still apply; the new condition can only add human review. ASR disagreement is still not proof of unintelligibility, and a flagged clip can still be quality-confirmed by the original human-vote rule.

An independently reviewed outcome auditor must check this condition for all 480 cases, preserve every raw transcript, and include this amendment's SHA-256 in the ASR/listening freeze receipt before any ASR inference. This amendment is versioned separately because the original protocol SHA-256 is embedded in the frozen private case map and public blind queue; changing that file would invalidate their provenance without changing any stimulus.
