## Pre-freeze blocker

The second-listener trigger is **too weak for a word in a fixed sentence slot**. `compare_asr` defines `target_exactly_once` as a count over the *entire* transcript ([auditor lines 360–377](audit_asr_listening_v1.py#L360-L377)). `audit` flags a target miss only when this count is false ([lines 422–446](audit_asr_listening_v1.py#L422-L446)). For reference `Say otter now.`, both synthetic ASRs can return `Otter say other now.` and the synthetic primary listener can answer `otter`, clear, confidence 5. The auditor returns `go`, no flag, and no second review even though both ASRs put `other` in the intended middle slot (normalized script mismatch; WER 2/3). I reproduced that return from `audit()` without any recognizer or real response. The planned trigger says a second listener reviews a clip when either ASR fails the middle-word identity. Before freezing sources, add a prospective flag for at least any normalized full-script mismatch, or explicitly revise the protocol to accept this weaker test. Keep whole-token occurrence as a descriptive metric. This is a potential **false go** in an otherwise complete 480-case receipt; it does not show a bad real clip.

## Checks that passed

- `audit_asr_listening_v1.py --validate-only` independently reconstructed 480 unique cases/queue entries and verified frozen manifest, case, queue, runner, protocol and WAV/PCM hashes. The private cases represent 60 pairs, 288 fit, 96 development, and 96 locked-test clips. The public queue remains opaque IDs in fixed order. [Auditor lines 70–169](audit_asr_listening_v1.py#L70-L169).
- The outcome path requires two externally sealed completion hashes and exact ordered 480-row raw logs, with matching WAV/PCM hashes, raw transcripts and decoder metadata. It compares transcripts only after reading the raw files. The code computes NFKC → casefold → Unicode word extraction, literal and normalized script equality, token-level Levenshtein WER, target/alternative occurrence, empty output and Whisper cap truncation. Aggregate tables cover total, split, category, engine, template and pair. [Auditor lines 190–263](audit_asr_listening_v1.py#L190-L263), [360–391](audit_asr_listening_v1.py#L360-L391), [394–496](audit_asr_listening_v1.py#L394-L496).
- Primary responses are checked as an exact prefix of the blind queue; each stage has one owner, each clip gets at most one initial per stage, and no reviewer can supply two stages for the same clip. Secondary and tertiary prerequisites are enforced. The auditor requires a second response on flags, a third on first/second word or clarity disagreement, and two independent clear target votes for a flagged clip. Missing/extra stages stop. [Auditor lines 279–357](audit_asr_listening_v1.py#L279-L357), [422–464](audit_asr_listening_v1.py#L422-L464).
- Append-only corrections and adjudications retain original answers, have prior-row links and reasons, and force `stop` pending separate review. This conservative ambiguity treatment matches the [source handoff](ASR_LISTENING_AUDITOR_SOURCE_HANDOFF_V1.md); it cannot silently turn an answer into a pass. The response log has a SHA-256 chain, externally sealed final response hash, source/version hashes, timestamps, and a recorded HTTP User-Agent. Browser User-Agent and reviewer IDs are **provenance assertions, not proof of a human or independent people**; the handoff recognizes the need for operational verification. [Listener source lines 115–259](listening_server_v1.py#L115-L259), [auditor lines 266–357](audit_asr_listening_v1.py#L266-L357).
- The auditor's full gate can return `go` only when no clip has a problem; all 480 initial primary responses and both 480-row ASR logs are required by the verified production path. Invalid, absent, or changed evidence writes a `stop` receipt. The independent freeze file `ASR_SCREEN_FREEZE_V1.json` is currently absent, so actual ASR inference remains blocked. [Auditor lines 171–263](audit_asr_listening_v1.py#L171-L263), [488–561](audit_asr_listening_v1.py#L488-L561).

## Verification and limits

`python3.12 -m unittest discover -s eval/audio_jlens/corpus_v2 -p 'test_*v1.py' -v` passed **14 source/synthetic tests**; `--validate-only` returned 480/480. A direct synthetic `audit()` call reproduced the false go in the attached receipt. The ASR-runner test module needs its pinned NumPy/Transformers environment; the system Python 3.12 here lacks NumPy, so its preflight could not be rerun from this interpreter. The committed [source handoff](ASR_LISTENING_AUDITOR_SOURCE_HANDOFF_V1.md) reports prior runner tests in the pinned environment. The auditor's response reader also emits an unclosed-file `ResourceWarning` in tests; this is a cleanup item, not a gate bypass.

Update the prospective flag rule and auditor together, rerun the synthetic counterexample and full source tests, re-hash all changed files, and obtain a second review before freezing.
